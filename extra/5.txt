## Architecture

### Component Layers

```
╔══════════════════════════════════════════════════════════════════╗
║  PRESENTATION LAYER                                              ║
║                                                                  ║
║   application/app.py  (Streamlit)                                ║
║   • LLM Configuration page — test & persist DLH credentials      ║
║   • Chat page — conversational NL2SQL with stage-pill trace      ║
║   • Session state stores processor & chat history                ║
╠══════════════════════════════════════════════════════════════════╣
║  ORCHESTRATION LAYER                                             ║
║                                                                  ║
║   ComplianceProcessor  (genai/core/processor.py)                 ║
║   • Builds AgentState from the user question                     ║
║   • Calls compiled LangGraph graph                               ║
║   • Maps final AgentState → response                             ║
╠══════════════════════════════════════════════════════════════════╣
║  PIPELINE LAYER  (LangGraph StateGraph)                          ║
║                                                                  ║
║   Node 1   IntentChecker    rule-based, no LLM                   ║
║   Node 2   SchemaChecker    rule-based, no LLM                   ║
║   Node 3   SQLWriterAgent   ★ only LLM call in the pipeline      ║
║   Node 4   SQLReviewer      rule-based, no LLM                   ║
║   Node 4.5 SQLValidator     sqlglot AST, no LLM                  ║
║   Node 5   ExecutorAgent    rule-based, no LLM                   ║
╠══════════════════════════════════════════════════════════════════╣
║  INFRASTRUCTURE LAYER                                            ║
║                                                                  ║
║   utils/config.py    Pydantic Settings — reads .env              ║
║   utils/logger.py    get_logger() — reads logging.toml           ║
║   utils/registry.py  YAML loader + SQLite helpers + DB registry  ║
║   utils/helpers.py   stateless stdlib helpers                    ║
║                                                                  ║
║   genai/config/*.toml   TOML config (no secrets)                 ║
║   genai/prompt/*.yaml   YAML prompt files (LLM wording)          ║
╠══════════════════════════════════════════════════════════════════╣
║  STORAGE LAYER                                                   ║
║                                                                  ║
║   data/comp_db/COMP_REPORTS.db   SQLite — read-only at runtime   ║
║   data/logs/compliance_bot.log   Rotating log file               ║
║   llm_config.json                Persisted LLM credentials       ║
╚══════════════════════════════════════════════════════════════════╝
```


```
[START]
   │
   ▼
intent_checker  ──(intent_ok=False)──► clarify_node ──► [END]
   │ (intent_ok=True)
   ▼
schema_checker
   │
   ▼
sql_writer_agent  ◄──────────────────────────────────────────┐
   │                                                         │ retry
   ▼                                                         │
sql_reviewer ──(passed)──► sql_validator ────────────────────┤
   │                            │                            │
   │ (max retries / error)      │ (valid)    (invalid → retry)
   ▼                            ▼
executor_agent ◄──────── executor_agent ──► [END]
```

| Node | Module | LLM? | Role |
|---|---|---|---|
| `intent_checker` | `genai/nl2sql_agent/intent_checker.py` | ✗ | Rule-based intent gate + normalisation |
| `schema_checker` | `genai/nl2sql_agent/schema_checker.py` | ✗ | Live PRAGMA schema + TOML descriptions |
| `sql_writer_agent` | `genai/nl2sql_agent/sql_writer_agent.py` | ✓ | Single LLM call — SQL generation |
| `sql_reviewer` | `genai/nl2sql_agent/sql_reviewer.py` | ✗ | Safety + structural + table existence |
| `sql_validator` | `genai/nl2sql_agent/sql_validator.py` | ✗ | sqlglot AST + dialect check |
| `executor_agent` | `genai/nl2sql_agent/executor_agent.py` | ✗ | Read-only SQLite execution |

### Workflow

1. Open the **LLM Configuration** page in the sidebar.
2. Enter your **Model Name**, **DLH Base URL**, and **API Key**, then click **Test & Save**.
3. On success the sidebar shows **● Backend Active** and you are redirected to **Chat**.
4. Type a compliance question (e.g. *"How many accounts from Mumbai circle have KYC flag N?"*) and press **Enter**.
5. The six LangGraph nodes run; stage pills light up as each node completes.
6. Results are displayed with the SQL query, agent trace, and a **Download as CSV** button.

## Design Principles

* **One LLM call per query** — only `SQLWriterAgent` calls the LLM; all other nodes are deterministic and fast.
* **YAML-first prompts** — all LLM wording lives in `genai/prompt/*.yaml`; change messages without touching Python.
* **Zero-code database adds** — add a new database by editing `databases.toml` only.
* **Read-only safety** — every SQL execution is wrapped in a `BEGIN DEFERRED` transaction that is unconditionally rolled back.
* **Defence in depth** — SQL passes through three independent validation layers (regex review → sqlglot AST → SQLite error handling) before results are returned.
* **Persistent LLM config** — credentials entered in the UI are saved to `llm_config.json` and survive Streamlit restarts.

"""
dlh_ai — root package for the SBI Compliance Chatbot.

Configures the package-level logger (``dlh_ai``) on import using a
``RichHandler`` for the console and a plain ``FileHandler`` for disk.
Both handlers are attached only once; repeated imports are safe because
the logger level is checked before adding handlers.

Sub-packages
------------
* :mod:`dlh_ai.genai`         — GenAI / NL2SQL pipeline.
* :mod:`dlh_ai.data`          — Data-engine backends (Pandas, Polars, Spark).
* :mod:`dlh_ai.utils`         — Shared helpers, settings, registry, and logging.
* :mod:`dlh_ai.application`   — Streamlit application entry point.

Logging
-------
The ``dlh_ai`` logger is initialised at import time.  Downstream modules
should obtain a child logger with::

    import logging
    LOGGER = logging.getLogger("dlh_ai.<module>")

Constants exported
------------------
``LOG_DIR``
    Default directory for rotating log files.
``LOG_FILENAME``
    Default log filename.
``LOG_LEVEL``
    Package-level logging threshold (``logging.DEBUG``).

Examples
--------
>>> import dlh_ai
>>> import logging
>>> logger = logging.getLogger("dlh_ai.my_module")
>>> logger.info("Logger ready.")
"""

import logging
import os
from logging import Formatter, Logger

from rich.console import Console
from rich.logging import RichHandler

LOG_DIR: str = "logs"
LOG_FILENAME: str = "app.log"
LOG_LEVEL: int = logging.DEBUG

_LOG_FORMAT_CONSOLE: str = "%(message)s"
_LOG_FORMAT_FILE: str = (
    "%(asctime)s | %(levelname)s | %(name)s | "
    "%(module)s:%(filename)s:%(lineno)d | %(funcName)s | %(message)s"
)
_DATE_FORMAT: str = "%d-%b-%y %H:%M:%S"


def _build_logger() -> Logger:
    """Construct and return the ``dlh_ai`` package logger.

    Attaches a :class:`~rich.logging.RichHandler` for console output and a
    plain :class:`logging.FileHandler` for disk persistence.  Handlers are
    only added when the logger has no existing handlers, ensuring that
    repeated imports remain idempotent.

    Returns
    -------
    logging.Logger
        Configured ``dlh_ai`` logger instance.

    Raises
    ------
    OSError
        Raised when ``LOG_DIR`` cannot be created due to permission issues.
    """
    _logger: Logger = logging.getLogger("dlh_ai")
    _logger.setLevel(LOG_LEVEL)

    # Guard: skip handler registration if already configured.
    if _logger.handlers:
        return _logger

    # Console handler — uses Rich for colour and formatting.
    console_handler = RichHandler(
        markup=True,
        show_path=False,
        console=Console(),
        locals_max_string=150,
    )
    console_handler.setFormatter(Formatter(_LOG_FORMAT_CONSOLE, datefmt=_DATE_FORMAT))
    _logger.addHandler(console_handler)

    # File handler — plain text, appends across restarts.
    os.makedirs(LOG_DIR, exist_ok=True)
    file_handler = logging.FileHandler(
        filename=os.path.join(LOG_DIR, LOG_FILENAME),
        mode="a",
        encoding="utf-8",
    )
    file_handler.setFormatter(Formatter(_LOG_FORMAT_FILE))
    _logger.addHandler(file_handler)

    return _logger


# Initialise at import time; ``logger`` is the canonical package logger.
logger: Logger = _build_logger()

__all__: list[str] = [
    "LOG_DIR",
    "LOG_FILENAME",
    "LOG_LEVEL",
    "logger",
]

class AppSettings(BaseSettings):
    """Root application settings — aggregates all sub-models.

    Loads configuration in priority order:

    1. Environment variables (highest priority).
    2. ``.env`` file entries.
    3. ``config.toml`` defaults.
    4. Pydantic field defaults (lowest priority).

    Nested sub-model fields can be overridden using the ``__`` delimiter,
    e.g. ``MODEL__MODEL_NAME=gemma-4-26b-a4b-it``.

    Attributes
    ----------
    application_name : str
        Display name shown in the Streamlit page title.
    page_config : str
        Streamlit ``st.set_page_config`` title string.
    log_level : str
        Root log level.  One of ``DEBUG``, ``INFO``, ``WARNING``,
        ``ERROR``, ``CRITICAL``.  Default is ``"INFO"``.
    log_dir : str
        Directory (relative to project root) for rotating log files.
    host : str
        HTTP server bind address (used outside Streamlit).
    port : int
        HTTP server port.
    debug : bool
        Enable debug mode.
    database : DatabaseSettings
        Iceberg / Hive connection settings.
    model : ModelSettings
        LLM provider and generation settings.
    query : QuerySettings
        SQL query execution limits.
    nl2sql : NL2SqlSettings
        NL2SQL agent pipeline settings.

    Examples
    --------
    >>> from dlh_ai.utils.config import get_settings
    >>> cfg = get_settings()
    >>> cfg.application_name
    'COMPLIANCE-CHATBOT (UI + LLM Hybrid)'
    >>> cfg.model.dlh.base_url
    'http://10.190.236.15:9000/api/v1'
    """

    model_config = SettingsConfigDict(
        # Load from .env if the file exists; silently skip if absent.
        env_file=".env",
        env_file_encoding="utf-8",
        # Nested delimiter: MODEL__MODEL_NAME overrides model.model_name.
        env_nested_delimiter="__",
        # Ignore unknown env vars to avoid noise from unrelated shell vars.
        extra="ignore",
        populate_by_name=True,
        # config.toml path — set at class body level via _CONFIG_TOML.
        toml_file=str(_CONFIG_TOML),
    )

    # Application display metadata.
    application_name: str = Field(
        default="COMPLIANCE-CHATBOT (UI + LLM Hybrid)",
        description="Display name shown in the Streamlit page title.",
    )
    page_config: str = Field(
        default="SBI COMPLIANCE-CHATBOT",
        description="Streamlit st.set_page_config title string.",
    )

    # Logging overrides.
    log_level: str = Field(default="INFO", description="Root log level.")
    log_dir: str = Field(default="data/logs", description="Log file directory.")

    # HTTP server (non-Streamlit deployments).
    host: str = Field(default="0.0.0.0", description="Server bind address.")  # noqa: S104
    port: int = Field(default=8000, description="Server port.")
    debug: bool = Field(default=False, description="Enable debug mode.")

    # Nested sub-models.
    database: DatabaseSettings = Field(
        default_factory=DatabaseSettings,
        description="Iceberg / Hive connection settings.",
    )
    model: ModelSettings = Field(
        default_factory=ModelSettings,
        description="LLM provider and generation settings.",
    )
    query: QuerySettings = Field(
        default_factory=QuerySettings,
        description="SQL query execution limits.",
    )
    nl2sql: NL2SqlSettings = Field(
        default_factory=NL2SqlSettings,
        description="NL2SQL agent pipeline settings.",
    )

    @classmethod
    def settings_customise_sources(
        cls,
        settings_cls: type[BaseSettings],
        init_settings: PydanticBaseSettingsSource,
        env_settings: PydanticBaseSettingsSource,
        dotenv_settings: PydanticBaseSettingsSource,
        file_secret_settings: PydanticBaseSettingsSource,
    ) -> tuple[PydanticBaseSettingsSource, ...]:
        """Define the ordered settings source priority.

        Parameters
        ----------
        settings_cls : type[BaseSettings]
            The settings class being configured.
        init_settings : PydanticBaseSettingsSource
            Constructor keyword arguments.
        env_settings : PydanticBaseSettingsSource
            Operating-system environment variables.
        dotenv_settings : PydanticBaseSettingsSource
            ``.env`` file entries.
        file_secret_settings : PydanticBaseSettingsSource
            Docker / Kubernetes secret-file source (unused).

        Returns
        -------
        tuple[PydanticBaseSettingsSource, ...]
            Ordered tuple of sources from highest to lowest priority.
        """
        return (
            env_settings,  # 1st — environment variables
            dotenv_settings,  # 2nd — .env file
            TomlConfigSettingsSource(settings_cls),  # 3rd — config.toml
            init_settings,  # 4th — constructor kwargs
        )


# Singleton accessor

# Instantiated once at import time; subsequent calls return the cached object.
_settings: AppSettings = AppSettings()

    AppSettings
        The application-wide settings object.

    --------
    >>> from dlh_ai.utils.config import get_settings
    >>> settings = get_settings()
    >>> settings.database.connection_name
    'DLH-DEV-UAT - Hive on Tez'
    """
    return _settings

LOGGER = logging.getLogger("dlh_ai")


def save_config_to_disk(model_name: str, base_url: str, api_key: str) -> None:
    """Write LLM credentials to llm_config.json next to the workspace root."""
    try:
        # Build the config dict with the three user-supplied values
        config = {
            "model_name": model_name,
            "base_url": base_url,
            "api_key": api_key,
        }
        # Overwrite (or create) the file - no sensitive data in git
        with open(CONFIG_FILE, "w") as f:
            json.dump(config, f)
        LOGGER.info("Configuration saved to disk successfully.")
    except Exception as e:
        # Log the error but never crash the UI - the user can retry
        LOGGER.error(f"Failed to save config to disk: {e}")


def load_config_from_disk() -> dict | None:
    """Read and return the saved LLM credentials, or None if the file is missing."""
    try:
        if CONFIG_FILE.exists():
            # Open the file and parse JSON into a plain dict
            with open(CONFIG_FILE) as f:
                return json.load(f)
    except Exception as e:
        # If the file is corrupt or unreadable, return None gracefully
        LOGGER.error(f"Failed to load config from disk: {e}")
    return None


def get_font_base64(font_path: Path) -> str | None:
    """Read a .ttf font file and return it as a base64 string for CSS injection."""
    try:
        with open(font_path, "rb") as f:
            data = f.read()
        # base64-encode the raw bytes and decode to a plain string
        return base64.b64encode(data).decode()
    except Exception as e:
        # Font is cosmetic - log and fall back to the system sans-serif
        LOGGER.error(f"Could not load font at {font_path}: {e}")
        return None

def _font_face(b64: str | None, weight: int) -> str:
    """Return a @font-face rule for Urbanist at the given weight."""
    if not b64:
        return ""

        f"@font-face {{ font-family: 'Urbanist'; "
        f"src: url(data:font/truetype;base64,{b64}) format('truetype'); "
        f"font-weight: {weight}; font-style: normal; font-display: swap; }}"
    )

def initialize_pipeline(model_name: str, base_url: str, api_key: str):
    """
    Build and connect the full NL2SQL pipeline.

    Steps:
      1. Copy default ModelSettings and override with user-supplied values.
      2. Create a ModelLoaderService and call load() to init the HTTP client.
      3. Call test_connection() - sends a tiny "Reply with OK." request.
      4. Build the compiled LangGraph from build_nl2sql_graph().
      5. Wrap in a ComplianceProcessor and return (service, processor).
    """
    try:
        # Start from defaults defined in utils/config.py ModelSettings
        base_settings = get_settings().model.model_copy(deep=True)

        # Override only the values the user supplied in the form
        model_settings = base_settings.model_copy(
            update={
                "provider": "dlh",
                "model_name": model_name,
                "dlh_base_url": base_url,
                "dlh_api_key": api_key,
                "dlh_verify_ssl": True,
            }
        )

        # Create the HTTP client wrapper for the DLH inference server
        model_service = ModelLoaderService(settings=model_settings)
        model_service.load()  # initialises the OpenAI-compatible client
        model_service.test_connection()  # sends "Reply with OK." to verify auth

        # Resolve the SQLite database path from settings
        db_path = get_settings().database.db_path

        # Build and compile the 6-node LangGraph StateGraph
        compiled_graph = build_nl2sql_graph(
            model_service=model_service, db_path=db_path
        )

        # Wrap the graph in the thin orchestrator that maps API models ↔ AgentState
        processor = ComplianceProcessor(compiled_graph=compiled_graph)

        return model_service, processor

    except Exception as e:
        # Log full traceback for debugging, then re-raise so the UI shows an error
        LOGGER.exception("Pipeline initialization failed")
        raise e

"""
application/launcher.py — entry point for launching the Streamlit application.

Run this module directly to start the Streamlit server:

    python -m dlh_ai.application.launcher

The server address defaults to ``127.0.0.1`` and the port is read from the
``CDSW_APP_PORT`` environment variable (fallback: ``8551``).
"""

import os
import subprocess
from pathlib import Path

__all__ = ["run_streamlit"]

_APP_FILE: Path = Path(__file__).resolve().parent / "app.py"
_DEFAULT_PORT: str = "8551"
_ADDRESS: str = "127.0.0.1"


def run_streamlit() -> None:
    """Launch the Streamlit application server.

    Reads the server port from the ``CDSW_APP_PORT`` environment variable and
    falls back to ``8551`` when it is not set.  The process blocks until the
    server exits or a ``KeyboardInterrupt`` is received.

    Raises
    ------
    subprocess.CalledProcessError
        When the ``streamlit`` subprocess exits with a non-zero return code.
    """
    port: str = os.environ.get("CDSW_APP_PORT", _DEFAULT_PORT)

    command: list[str] = [
        "streamlit",
        "run",
        str(_APP_FILE),
        f"--server.address={_ADDRESS}",
        f"--server.port={port}",
    ]

    try:
        subprocess.run(command, check=True)
    except KeyboardInterrupt:
        print("\nStopping the server...")


if __name__ == "__main__":
    run_streamlit()

    def __post_init__(self) -> None:
        """Initialise the HDFS client."""
        self.hdfs_client = HDFSClient()

    @property
    def cursor(self):  # type: ignore[return]
        """Get a database cursor for executing queries.

        Returns
        -------
        Any
            Database cursor from the underlying CML connection.

        Notes
        -----
        This property creates a **new** connection on every access.  The caller
        is responsible for closing the cursor after use.
        """
        conn = self._create_connection()
        return conn.get_cursor()

    def read_table(self, query: str) -> pd.DataFrame:
        """Read an Iceberg table on Hive OCP into a Pandas DataFrame.

        Parameters
        ----------
        query : str
            SQL ``SELECT`` query used to read the table.

        Returns
        -------
        pd.DataFrame
            DataFrame containing the query result.

        Notes
        -----
        Column names returned by the Hive on Tez driver are prefixed with the
        table name (e.g. ``"table.column"``).  This method strips those prefixes
        automatically for consistency with other engines.
        """
        self._verify_sql_query(query)

        with self._create_connection() as base_conn:
            with base_conn.cursor() as cursor:
                LOGGER.debug("Executing query to read the table")
                from impala.util import as_pandas  # type: ignore[import-untyped]

                cursor.execute(query)
                data: pd.DataFrame = as_pandas(cursor)
                LOGGER.info("Successfully read %d rows", len(data))

        return data.rename(
            columns={col: col.upper().split(".")[-1] for col in data.columns}
        )

    def read_csv_from_hdfs(self, path: str, **kwargs: object) -> pd.DataFrame:
        """Download a CSV file from HDFS and load it into a Pandas DataFrame.

        Parameters
        ----------
        path : str
            HDFS path to the CSV file.
        **kwargs : object
            Additional keyword arguments forwarded to :func:`pandas.read_csv`.

        pd.DataFrame

        """Read a Parquet dataset from HDFS into a Pandas DataFrame.

        path : str

        Returns
        -------
        pd.DataFrame
            DataFrame loaded from the Parquet data.
        """

        return data.to_table().to_pandas(
            split_blocks=True,
            self_destruct=True,
            zero_copy_only=False,
        )

    def save_table(
        self,
        df: pd.DataFrame,
        name: str,
        mode: Literal["overwrite", "append", "ignore", "error"] = "append",
        batch_size: int = 5000,
    ) -> None:
        """Insert data from a Pandas DataFrame into an Iceberg table.

        Parameters
        ----------
        df : pd.DataFrame
            Source data to insert.
        name : str
            Fully-qualified target table name (e.g. ``"schema.table"``).
        mode : {"overwrite", "append", "ignore", "error"}, optional
            Write mode. Only ``"append"`` is currently supported.
            Defaults to ``"append"``.
        batch_size : int, optional
            Number of rows per ``executemany`` call. Defaults to ``5000``.

        Raises
        ------
        NotImplementedError
            When *mode* is not ``"append"``.
        """
        if mode != "append":
            raise NotImplementedError(
                f"Mode '{mode}' not yet implemented for Pandas Engine"
            )
        if "." in name:
            db, tbl = name.split(".")
            formatted_table_name = f"`{db}`.`{tbl}`"
        else:
            formatted_table_name = f"`{name}`"

        col_names = ", ".join([f"`{c.split('.')[-1]}`" for c in df.columns])
        placeholders = ", ".join(["%s"] * len(df.columns))
        insert_sql_query = (
            f"INSERT INTO {formatted_table_name} ({col_names}) VALUES ({placeholders})"
        )

        no_of_batches = self._calculate_batch_size(df, batch_size)
        LOGGER.info(
            "Starting to load data into %s in batches of %d with total batches: %d",
            name,
            batch_size,
            no_of_batches,
        )

        with self._create_connection() as base_conn:
            with base_conn.cursor() as cursor:
                try:
                    for idx, offset in enumerate(
                        range(0, len(df), batch_size), start=1
                    ):
                        batch = df.iloc[offset : offset + batch_size]
                        LOGGER.debug("inserting batch %d out of %d", idx, no_of_batches)
                        cursor.executemany(
                            insert_sql_query, batch.to_dict(orient="records")
                        )
                        LOGGER.debug(
                            "successfully inserted batch %d with %d rows.",
                            idx,
                            len(batch),
                        )

                    LOGGER.info("Successfully loaded %d rows.", len(df))
                except Exception:
                    LOGGER.error("SQL Error: %s", insert_sql_query)
                    raise

    def save_csv_to_hdfs(
        self,
        df: pd.DataFrame,
        path: str,
        **kwargs: object,
    ) -> None:
        """Save a Pandas DataFrame as a CSV file to HDFS.

        Parameters
        ----------
        df : pd.DataFrame
            The DataFrame to save.
        path : str
            The HDFS destination path for the CSV file.
        **kwargs : object
            Additional keyword arguments forwarded to
            :meth:`pandas.DataFrame.to_csv`.
        """
        with tempfile.TemporaryDirectory() as temp_dir:
            df.to_csv(f"{temp_dir}/data.csv", **kwargs)
            self.hdfs_client.upload(f"{temp_dir}/data.csv", path)
        LOGGER.info("saved pandas dataframe to HDFS at %s", path)

    def save_parquet(self, df: pd.DataFrame, path: str, **kwargs: object) -> None:
        """Save a Pandas DataFrame as a Parquet file to HDFS.

        Parameters
        ----------
        df : pd.DataFrame
            The DataFrame to save.
        path : str
            The HDFS destination path for the Parquet file.
        **kwargs : object
            Additional keyword arguments forwarded to
            :meth:`pandas.DataFrame.to_parquet`.
        """
        with tempfile.TemporaryDirectory() as temp_dir:
            df.to_parquet(f"{temp_dir}/data.parquet", **kwargs)
            self.hdfs_client.upload(f"{temp_dir}/data.parquet", path)
        LOGGER.info("saved pandas dataframe to HDFS at %s", path)

    @retry(
        stop=stop_after_attempt(5),
        wait=wait_exponential(multiplier=1, max=10),
        retry=retry_if_exception_type(Exception),
        reraise=True,
        before_sleep=before_sleep_log(LOGGER, logging.WARNING),
    )
    def _create_connection(self):  # type: ignore[return]
        """Attempt to create and return the DB base connection (with retries).

        Returns
        -------
        Any
            CML base connection object.

        Notes
        -----
        A new connection is created on every call.  Connection pooling is not
        yet implemented; retries handle transient network failures.
        """
        self._base_conn = cmldata.get_connection(self.connection_name)
        LOGGER.info("Successfully established connection: %s", self.connection_name)
        return self._base_conn.get_base_connection()

    def _calculate_batch_size(self, df: pd.DataFrame, batch_size: int) -> int:
        """Calculate the total number of batches required for a DataFrame.

        Parameters
        ----------
        df : pd.DataFrame
            DataFrame whose rows will be batched.
        batch_size : int
            Maximum number of rows per batch.

        Returns
        -------
        int
            Total number of batches needed to process all rows.
        """
        return len(df) // batch_size + (1 if len(df) % batch_size > 0 else 0)

    def _verify_sql_query(self, query: str) -> Expression:
        """Parse and validate *query* using sqlglot.

        Parameters
        ----------
        query : str
            SQL statement to validate.

        Returns
        -------
        Expression
            sqlglot AST expression for the parsed query.

        Raises
        ------
        sqlglot.errors.ParseError
            When *query* is not valid SQL.
        """
        return parse_one(query)

"""
data/_spark_backend.py — Spark-backed data access and persistence engine.

Provides :class:`SparkEngine` for reading and writing Iceberg tables, CSV
files, and Parquet files via a PySpark session running on CML.
"""

import logging
from dataclasses import dataclass
from datetime import datetime
from typing import Literal
from zoneinfo import ZoneInfo

from pyspark.sql import SparkSession
from pyspark.sql.dataframe import DataFrame
from sqlglot import parse_one

LOGGER = logging.getLogger("dlh_ai")

__all__ = ["SparkEngine"]


@dataclass
class SparkEngine:
    """Spark-backed data access and persistence engine.

    Parameters
    ----------
    app_name_prefix : str
        Prefix used while constructing the Spark application name during
        session initialisation.

    Attributes
    ----------
    app_name_prefix : str
        Prefix for the Spark application name.
    spark : SparkSession
        Active Spark session created during post-init.
    """

    app_name_prefix: str

    def __post_init__(self) -> None:
        """Initialise the Spark session for the engine instance.

        Notes
        -----
        The Spark application name is built by combining :attr:`app_name_prefix`
        with the current timestamp in the ``Asia/Kolkata`` timezone.

        The session is created via ``SparkSession.builder.getOrCreate()``, which
        works correctly in CML Notebook sessions (where ``default-spark.conf`` is
        accessible).  CML Jobs require additional configuration.
        """
        LOGGER.debug("creating new spark session")
        sess_name = (
            f"{self.app_name_prefix}-"
            f"{datetime.now(ZoneInfo('Asia/Kolkata')).isoformat()}"
        )
        self.spark: SparkSession = SparkSession.builder.appName(sess_name).getOrCreate()
        LOGGER.debug("successfully created new spark session: %s", sess_name)

    def read_table(self, name: str) -> DataFrame:
        """Read a table from the Spark catalog.

        Parameters
        ----------
        name : str
            Fully qualified table name to read.

        Returns
        -------
        DataFrame
            Spark DataFrame loaded from the requested table.
        """
        return self.spark.read.table(name)

    def read_csv(self, path: str) -> DataFrame:
        """Read a CSV dataset from the provided path.

        Parameters
        ----------
        path : str
            Filesystem/Ozone path from which the CSV data should be loaded.

        Returns
        -------
        DataFrame
            Spark DataFrame created from the CSV input.
        """
        return self.spark.read.format("csv").option("path", path).load()

    def read_parquet(self, path: str) -> DataFrame:
        """Read a Parquet dataset from the provided path.

        Parameters
        ----------
        path : str
            Filesystem/Ozone path from which the Parquet data should be loaded.

        Returns
        -------
        DataFrame
            Spark DataFrame created from the Parquet input.
        """
        return self.spark.read.format("parquet").option("path", path).load()

    def save_table(
        self,
        df: DataFrame,
        name: str,
        path: str,
        mode: Literal["overwrite", "append", "ignore", "error"] = "append",
    ) -> None:
        """Persist a DataFrame as an Iceberg table.

        Parameters
        ----------
        df : DataFrame
            Spark DataFrame to be written.
        name : str
            Target table name for persistence.
        path : str
            Storage path associated with the table.
        mode : {"overwrite", "append", "ignore", "error"}, optional
            Write mode to use while saving the table. Defaults to ``"append"``.
        """
        df.write.mode(mode).format("iceberg").option("path", path).saveAsTable(name)

    def merge_table(self, df: DataFrame, merge_query: str) -> None:
        """Merge a DataFrame into a target Iceberg table using a SQL MERGE statement.

        Parameters
        ----------
        df : DataFrame
            Source Spark DataFrame that will be exposed as a temporary view for
            the merge operation.
        merge_query : str
            SQL MERGE statement used to perform the upsert or merge logic.
        """
        parsed_query = parse_one(merge_query)
        source: str = parsed_query.args.get("using").name

        df.createOrReplaceTempView(source)
        LOGGER.debug("created %s temp view", source)

        self.spark.sql(merge_query)
        LOGGER.info(
            "successfully merged into %s.%s",
            parsed_query.this.db,
            parsed_query.this.name,
        )

    def save_csv(
        self,
        df: DataFrame,
        path: str,
        mode: Literal["overwrite", "append", "ignore", "error"] = "append",
    ) -> None:
        """Write a DataFrame to CSV format.

        Parameters
        ----------
        df : DataFrame
            Spark DataFrame to be written.
        path : str
            Destination filesystem path for the CSV output.
        mode : {"overwrite", "append", "ignore", "error"}, optional
            Write mode to use while saving the CSV data. Defaults to ``"append"``.
        """
        df.write.mode(mode).format("csv").save(path)

    def save_parquet(
        self,
        df: DataFrame,
        path: str,
        mode: Literal["overwrite", "append", "ignore", "error"] = "append",
    ) -> None:
        """Write a DataFrame to Parquet format.

        Parameters
        ----------
        df : DataFrame
            Spark DataFrame to be written.
        path : str
            Destination filesystem path for the Parquet output.
        mode : {"overwrite", "append", "ignore", "error"}, optional
            Write mode to use while saving the Parquet data. Defaults to ``"append"``.
        """
        df.write.mode(mode).format("parquet").save(path)

    def close_spark_session(self) -> None:
        """Stop the current active Spark session.

        Notes
        -----
        After calling this method the :attr:`spark` attribute is no longer
        usable.  Create a new :class:`SparkEngine` instance if further Spark
        processing is required.
        """
        self.spark.stop()

def ensure_database(db_path: Path) -> None:
    """Create the parent directory and SQLite database file if they do not exist.

    This is a no-op when both already exist â€” SQLite creates the file on
    first ``connect()`` so the function just guarantees the directory is there.

    Parameters
    ----------
    db_path : Path
        Absolute or relative path to the ``.db`` file.
    """
    db_path.parent.mkdir(parents=True, exist_ok=True)
    existed = db_path.exists()
    sqlite3.connect(str(db_path)).close()
    if not existed:
        print(f"[create] Database file created: {db_path}")
    else:
        print(f"[ok]     Database file exists:  {db_path}")


def ensure_table(conn: sqlite3.Connection) -> None:
    """Create ``COMP_TBL`` with the full 25-column schema if it does not exist.

    If the table already exists but is missing required columns (stale schema),
    it is dropped and recreated so the seeder can always run safely.

    Parameters
    ----------
    conn : sqlite3.Connection
        Open SQLite connection to the target database.
    """
    table_exists = conn.execute(
        "SELECT name FROM sqlite_master WHERE type='table' AND name='COMP_TBL'"
    ).fetchone()

    if table_exists:
        existing_cols: set[str] = {
            row[1] for row in conn.execute("PRAGMA table_info(COMP_TBL)").fetchall()
        }
        if not _REQUIRED_COLUMNS.issubset(existing_cols):
            conn.execute("DROP TABLE COMP_TBL")
            conn.commit()
            print(
                "[migrate] COMP_TBL schema was stale â€” dropped and will be recreated."
            )
            table_exists = None  # fall through to CREATE

    if not table_exists:
        conn.execute(_CREATE_TABLE_SQL)
        conn.commit()
        print("[create] COMP_TBL created.")
    else:
        print("[ok]     COMP_TBL already exists with correct schema.")


def reset_table(conn: sqlite3.Connection) -> None:
    """Delete every row from ``COMP_TBL``.

    Parameters
    ----------
    conn : sqlite3.Connection
        Open SQLite connection to the target database.
    """
    deleted: int = conn.execute("DELETE FROM COMP_TBL").rowcount
    conn.commit()
    print(f"[reset]  Deleted {deleted:,} existing rows from COMP_TBL.")


def _rand_date(start: date, end: date) -> date:
    """Return a random date between *start* and *end* (inclusive)."""
    return start + timedelta(days=random.randint(0, (end - start).days))


def _fmt(d: date) -> str:
    """Format a date as ISO-8601 string (YYYY-MM-DD)."""
    return d.strftime("%Y-%m-%d")


def _rand_rate(base: float) -> float:
    """Return a rate within Â±0.75 pp of *base*, rounded to 2 dp."""
    return round(base + random.uniform(-0.75, 0.75), 2)


def _make_row(i: int) -> tuple[str, ...]:
    """Generate one synthetic COMP_TBL row."""
    circle_name, circle_cd = random.choice(_CIRCLES)
    branch_name = random.choice(_BRANCHES[circle_cd])
    prdct_id, product_name = random.choice(_PRODUCTS)

    age: int = random.randint(18, 85)
    sr_flag: int = 1 if age >= 60 else 0
    dob: str = _fmt(_rand_date(date(2025 - age - 1, 1, 1), date(2025 - age, 12, 31)))

    kyc: str = "Y" if random.random() < (0.80 if sr_flag else 0.90) else "N"
    balance: float = round(random.lognormvariate(11.5, 1.2), 2)
    balance = max(10_000.0, min(5_000_000.0, balance))

    open_dt: date = _rand_date(date(2005, 1, 1), date(2024, 6, 30))
    tenor_yr: int = random.choice([1, 2, 3, 5, 7, 10, 15])
    tenor_day: int = random.randint(0, 364)
    mat_dt_d: date = open_dt + timedelta(days=tenor_yr * 365 + tenor_day)
    mat_dt: str = _fmt(mat_dt_d)

    is_mod: str = "YES" if random.random() < 0.15 else "NO"
    mtrty_dt: str = (
        _fmt(mat_dt_d + timedelta(days=random.randint(-30, 30)))
        if is_mod == "YES"
        else mat_dt
    )

    base_rate: float = 7.0 if sr_flag else 6.5
    new_rate: float = _rand_rate(base_rate)
    exp_rate: float = _rand_rate(base_rate + 0.25)
    pf_fac: str = "Y" if random.random() < 0.30 else "N"
    brcd: str = f"{random.randint(1, 999):03d}"
    acct_brnch: str = f"M{random.randint(1, 99):03d}"

    return (

        str(random.randint(1, 9)),  # CUST_NBR_CHKDGT

def generate_rows(count: int, start_i: int) -> list[tuple[str, ...]]:
    """Generate *count* synthetic row tuples starting from index *start_i*.

    ``start_i`` is used for ``CUST_NBR`` / ``ACCT_NBR`` sequential IDs so
    appending rows never collides with existing ones.

    Parameters
    ----------
    count : int
        Number of rows to generate.
    start_i : int
        Index of the first new row (1-based).

    Returns
    -------
    list of tuple of str
        Row tuples ready for ``executemany``.
    """
    return [_make_row(start_i + i) for i in range(count)]


def insert_rows(conn: sqlite3.Connection, rows: list[tuple[str, ...]]) -> None:
    """Bulk-insert *rows* into ``COMP_TBL`` using a single ``executemany``.

    Parameters
    ----------
    conn : sqlite3.Connection
        Open SQLite connection (must already have ``COMP_TBL``).
    rows : list of tuple of str
        Row tuples as returned by :func:`generate_rows`.
    """
    conn.executemany(_INSERT_SQL, rows)
    conn.commit()
    print(f"[insert] {len(rows):,} rows inserted into COMP_TBL.")


def print_summary(conn: sqlite3.Connection, db_path: Path, inserted: int) -> None:
    """Print a statistics summary after the insert.

    Parameters

def seed(db_path: Path, count: int, reset: bool) -> None:
    """Run the full end-to-end database seeding pipeline.

    Steps:

    1. :func:`ensure_database` â€” create ``.db`` file and parent dirs if absent.
    2. :func:`ensure_table`    â€” create ``COMP_TBL`` if absent or stale.
    3. :func:`reset_table`     â€” (only when ``reset=True``) delete all rows.
    4. :func:`generate_rows`   â€” build synthetic row tuples in memory.
    5. :func:`insert_rows`     â€” bulk-insert into the database.
    6. :func:`print_summary`   â€” display post-insert statistics.

    Parameters
    ----------
    db_path : Path
        Path to the SQLite ``.db`` file.
    count : int
        Number of rows to insert (use ``0`` to create the DB/table only).
    reset : bool
        When ``True``, delete all existing rows before inserting.
    """
    ensure_database(db_path)

    conn = sqlite3.connect(str(db_path))

    try:
        ensure_table(conn)

        if reset:
            reset_table(conn)

        if count == 0:
            print("[info]   --count 0: skipping row insert.")
            print_summary(conn, db_path, inserted=0)
            return

        start_i: int = conn.execute("SELECT COUNT(*) FROM COMP_TBL").fetchone()[0] + 1
        rows = generate_rows(count, start_i)

        insert_rows(conn, rows)

        print_summary(conn, db_path, inserted=count)

    finally:
        conn.close()

class ModelLoaderService:
    """Manages the lifecycle of the configured remote LLM provider.

    Uses :class:`~langchain_openai.ChatOpenAI` as the underlying client so
    the rest of the pipeline can freely use LangChain primitives (chains,
    structured output, callbacks) without any changes here.

    Parameters
    ----------
    settings : ModelSettings
        Pydantic settings object carrying model name, endpoint URL, API key,
        SSL flag, temperature, and token limit.
    """

    def __init__(self, settings: ModelSettings) -> None:
        self.settings: ModelSettings = settings
        self._llm: ChatOpenAI | None = None

    def load(self) -> None:
        """Initialise the LangChain ChatOpenAI client.

        Must be called before :meth:`generate` or :meth:`extract_sql`.

        Raises
        ------
        ModelLoadError
            Raised when the client cannot be initialised (bad URL, auth
            failure, or unexpected exception).
        """
        http_client: httpx.Client | None = None
        if not self.settings.dlh.verify_ssl:
            # UAT environment uses self-signed TLS certificates.
            http_client = httpx.Client(verify=False)  # noqa: S501

        try:
            kwargs: dict[str, object] = {
                "model": self.settings.model_name,
                "openai_api_key": self.settings.dlh.api_key,
                "openai_api_base": self.settings.dlh.base_url,
                "temperature": self.settings.model_temperature,
                "max_tokens": self.settings.model_max_new_tokens,
                "timeout": 30,
            }
            if http_client is not None:
                kwargs["http_client"] = http_client

            self._llm = ChatOpenAI(**kwargs)  # type: ignore[arg-type]
            LOGGER.info(
                "ChatOpenAI client initialised — model=%s base_url=%s",
                self.settings.model_name,
                self.settings.dlh.base_url,
            )
        except Exception as exc:
            raise ModelLoadError(
                f"Failed to initialise ChatOpenAI client: {exc}",
                detail=str(exc),
            ) from exc

    def is_loaded(self) -> bool:
        """Return ``True`` when the client is initialised and ready.

        Returns
        -------
        bool
            ``True`` if :meth:`load` has been called successfully.
        """
        return self._llm is not None

    def test_connection(self) -> None:
        """Send a minimal request to verify the LLM endpoint is reachable.

        Raises
        ------
        ModelLoadError
            Raised when the client has not been initialised.
        ModelInferenceError
            Raised when the test request times out or returns an API error.
        """
        if self._llm is None:
            raise ModelLoadError("ChatOpenAI client is not initialised.")
        try:
            self._llm.invoke([HumanMessage(content="Reply with OK.")], max_tokens=8)
        except Exception as exc:
            raise ModelInferenceError(
                f"Connection test failed: {exc}", detail=str(exc)
            ) from exc

    def generate(
        self,
        prompt: str,
        max_new_tokens: int = DEFAULT_MAX_NEW_TOKENS,
        temperature: float = DEFAULT_TEMPERATURE,
    ) -> str:
        """Send the prompt to the LLM and return the raw text response.

        Parameters
        ----------
        prompt : str
            Full prompt string to send as a ``HumanMessage``.
        max_new_tokens : int, optional
            Token generation cap.  Defaults to ``DEFAULT_MAX_NEW_TOKENS``.
        temperature : float, optional
            Sampling temperature.  Defaults to ``DEFAULT_TEMPERATURE``.

        Returns
        -------
        str
            Raw text content from the first completion choice.

        Raises
        ------
        ModelInferenceError
            Raised when the client is not loaded or the API call fails.
        """
        if not self.is_loaded():
            raise ModelInferenceError(
                "Model is not loaded. Call ModelLoaderService.load() first."
            )
        try:
            response = self._llm.invoke(  # type: ignore[union-attr]
                [HumanMessage(content=prompt)],
                temperature=temperature,
                max_tokens=max_new_tokens,
            )
            return str(response.content)
        except Exception as exc:
            raise ModelInferenceError(
                f"Provider request failed: {exc}", detail=str(exc)
            ) from exc

    def extract_sql(self, prompt: str) -> str | None:
        """Extract a SQL SELECT statement from the LLM using structured output.

        Uses :meth:`~langchain_core.language_models.BaseChatModel.with_structured_output`
        bound to :class:`_SqlOutput` so the model returns a well-formed Pydantic
        object instead of free-form text.  This eliminates the need for regex
        tag-matching and makes the contract between the LLM and the pipeline
        explicit and verifiable.

        Parameters
        ----------
        prompt : str
            Full prompt string assembled by :class:`~.sql_writer_agent.ContextBuilder`.

        Returns
        -------
        str or None
            The extracted SQL string, or ``None`` when the model returns an
            empty or unparseable response.

        Raises
        ------
        ModelInferenceError
            Raised when the client is not loaded or the structured-output
            call fails.
        """
        if not self.is_loaded():
            raise ModelInferenceError(
                "Model is not loaded. Call ModelLoaderService.load() first."
            )
        try:
            structured_llm = self._llm.with_structured_output(_SqlOutput)  # type: ignore[union-attr]
            result: _SqlOutput = structured_llm.invoke(  # type: ignore[assignment]
                [HumanMessage(content=prompt)]
            )
            sql = result.sql.strip() if result and result.sql else None
            if sql:
                LOGGER.debug("extract_sql — structured output: %s", sql[:200])
            else:
                LOGGER.warning("extract_sql — structured output returned empty SQL.")
            return sql or None
        except Exception as exc:
            LOGGER.warning("extract_sql — structured output failed: %s", exc)
            return None

    def unload(self) -> None:
        """Release the client from memory.

        Safe to call multiple times.  Sets the internal client reference to
        ``None`` so the object can be garbage-collected.
        """
        LOGGER.info("Unloading ChatOpenAI client …")
        self._llm = None
        LOGGER.info("Client unloaded.")

def generate_with_retry(
    model_service: ModelLoaderService,
    prompt: str,
    max_new_tokens: int = DEFAULT_MAX_NEW_TOKENS,
    temperature: float = DEFAULT_TEMPERATURE,
    retries: int = 2,
    retry_delay: float = 1.0,
) -> str:
    """Call :meth:`ModelLoaderService.generate` with automatic retry on failure.

    Parameters
    ----------
    model_service : ModelLoaderService
        A loaded model service instance.
    prompt : str
        Full prompt string to send.
    max_new_tokens : int, optional
        Token generation cap.
    temperature : float, optional
        Sampling temperature.
    retries : int, optional
        Extra attempts after the first (total = ``retries + 1``).
    retry_delay : float, optional
        Seconds to wait between attempts.

    Returns
    -------
    str
        Raw text response from the first successful attempt.

    Raises
    ------
    ModelInferenceError
        Raised when every attempt fails.
    """
    last_exc: ModelInferenceError | None = None

    for attempt in range(retries + 1):
        try:
            return model_service.generate(
                prompt=prompt,
                max_new_tokens=max_new_tokens,
                temperature=temperature,
            )
        except ModelInferenceError as exc:
            last_exc = exc
            if attempt < retries:
                LOGGER.warning(
                    "generate_with_retry — attempt %d/%d failed: %s. Retrying in %.1fs…",
                    attempt + 1,
                    retries + 1,
                    exc,
                    retry_delay,
                )
                time.sleep(retry_delay)

    raise last_exc  # type: ignore[misc]


def truncate_prompt(prompt: str, max_chars: int = 8000) -> str:
    """Keep the prompt under ``max_chars`` by removing characters from the middle.

    Retaining the head (system role + rules) and tail (question) gives the
    LLM the most important context even when the schema block is very long.

    Parameters
    ----------
    prompt : str
        Full prompt string to truncate.
    max_chars : int, optional
        Maximum number of characters allowed.  Default is ``8000``.

    Returns
    -------
    str
        Truncated prompt, or the original string if already within budget.
    """
    if len(prompt) <= max_chars:
        return prompt

    half = max_chars // 2
    LOGGER.warning(
        "truncate_prompt — length %d > %d; cutting the middle.", len(prompt), max_chars
    )
    return prompt[:half] + "\n...[truncated]...\n" + prompt[-half:]


@dataclass
class ProviderManager:
    """Registry and lifecycle manager for multiple LLM provider services.

    Register provider configurations by name, then activate one to make it
    the live inference target.  Providers are loaded lazily on first
    :meth:`activate` call.

    Attributes
    ----------
    _registry : dict[str, ModelSettings]
        Maps provider name → :class:`ModelSettings` (config only, not loaded).
    _services : dict[str, ModelLoaderService]
        Maps provider name → loaded :class:`ModelLoaderService`.
    _active_name : str or None
        Name of the currently active provider, or ``None``.

    Examples
    --------
    >>> from dlh_ai.genai.core.model import ProviderManager
    >>> from dlh_ai.utils.config import get_settings
    >>> pm = ProviderManager()
    >>> pm.register("dlh", get_settings().model)
    >>> svc = pm.activate("dlh")
    >>> pm.active_name
    'dlh'
    """

    _registry: dict[str, ModelSettings] = field(default_factory=dict)
    _services: dict[str, ModelLoaderService] = field(default_factory=dict)
    _active_name: str | None = field(default=None)

    def register(self, name: str, settings: ModelSettings) -> None:
        """Store a provider configuration under ``name`` (not loaded until :meth:`activate`).

        Parameters
        ----------
        name : str
            Unique provider identifier.
        settings : ModelSettings
            Configuration for this provider.
        """
        self._registry[name] = settings
        LOGGER.info("ProviderManager — registered provider: %s", name)

    def activate(self, name: str) -> ModelLoaderService:
        """Make ``name`` the active provider, loading its client if not yet loaded.

        Parameters
        ----------
        name : str
            Provider name previously passed to :meth:`register`.

        Returns
        -------
        ModelLoaderService
            The loaded service for the activated provider.

        Raises
        ------
        UnknownProviderError
            Raised when ``name`` has not been registered.
        """
        if name not in self._registry:
            raise UnknownProviderError(
                f"Provider '{name}' is not registered. "
                f"Available: {list(self._registry)}"
            )
        if name not in self._services:
            service = ModelLoaderService(settings=self._registry[name])
            service.load()
            self._services[name] = service
            LOGGER.info("ProviderManager — loaded provider: %s", name)

        self._active_name = name
        LOGGER.info("ProviderManager — active provider: %s", name)
        return self._services[name]

    @property
    def active(self) -> ModelLoaderService:
        """Return the currently active service.

        Returns
        -------
        ModelLoaderService
            The active :class:`ModelLoaderService`.

        Raises
        ------
        RuntimeError
            Raised when no provider has been activated.
        """
        if self._active_name is None or self._active_name not in self._services:
            raise RuntimeError(
                "No active provider. Call ProviderManager.activate(name) first."
            )
        return self._services[self._active_name]

    @property
    def active_name(self) -> str | None:
        """Name of the currently active provider, or ``None`` if none activated.

        Returns
        -------
        str or None
        """
        return self._active_name

    def registered_names(self) -> list[str]:
        """Return a sorted list of all registered provider names.

        Returns
        -------
        list[str]
        """
        return sorted(self._registry)

    def unload(self, name: str) -> None:
        """Unload the named provider service and free its memory.

        Parameters
        ----------
        name : str
            Provider name to unload.
        """
        service = self._services.pop(name, None)
        if service is not None:
            service.unload()
            LOGGER.info("ProviderManager — unloaded provider: %s", name)
        if self._active_name == name:
            self._active_name = None

    def unload_all(self) -> None:
        """Unload every registered provider service — call on application shutdown."""
        for name in list(self._services):
            self.unload(name)

"""
genai/core/processor.py — compliance orchestration and legacy schema reference.

ComplianceProcessor is the single entry-point for all compliance queries:
it accepts a ComplianceChatRequest, invokes the compiled LangGraph graph,
and maps the resulting AgentState onto the Pydantic response models.

COMP_SCHEMA_DETAILS and COMP_FEW_SHOT_EXAMPLES are kept as a reference
copy of the table schema; the authoritative source is the ``[databases]``
section of the project-root ``config.toml``.
"""

import logging
import uuid
from typing import Any

from ..nl2sql_agent.state import AgentState
from .exceptions import ComplianceBotError
from .schemas import (
    ComplianceChatRequest,
    ComplianceChatResponse,
    ComplianceOrchestrationResponse,
)

LOGGER = logging.getLogger("dlh_ai")


class ComplianceProcessor:
    """
    Orchestrates the NL2SQL compliance query pipeline via LangGraph.

    Intentionally thin — all multi-agent logic lives inside the agent nodes
    and graph wiring.  This class maps between API models and AgentState.
    """

    def __init__(self, compiled_graph: Any) -> None:
        # Hold the compiled LangGraph StateGraph — ready to invoke()
        self._graph = compiled_graph

    def process_query(self, request: ComplianceChatRequest) -> ComplianceChatResponse:
        """Run the pipeline and return the simplified chat response (no stage trail)."""
        # Delegate to the full orchestration path, then strip stage details
        orchestration = self.process_query_with_orchestration(request)
        return ComplianceChatResponse(
            question_id=orchestration.question_id,
            sql_query=orchestration.sql_query,
            df_output=orchestration.df_output,
            result_columns=orchestration.result_columns,
            result_summary=orchestration.result_summary,
            # Merge error and clarification into a single error field
            error=orchestration.error or orchestration.clarification_question,
        )

    def process_query_with_orchestration(
        self,
        request: ComplianceChatRequest,
    ) -> ComplianceOrchestrationResponse:
        """Run the full LangGraph pipeline and return the detailed response."""
        # Use the caller-supplied ID or generate a UUID for this request
        question_id = request.question_id or str(uuid.uuid4())
        question = (request.question or "").strip()

        # Early exit if the question is empty — no need to invoke the graph
        if not question:
            LOGGER.warning("[%s] Empty question received.", question_id)
            return ComplianceOrchestrationResponse(
                question_id=question_id,
                error="No question was provided in the request.",
                stages=["validation:empty_question"],
            )

        LOGGER.info("[%s] Invoking NL2SQL LangGraph for: %r", question_id, question)

        # Build the initial AgentState — the graph nodes fill in the rest
        initial_state: AgentState = AgentState(  # type: ignore[misc]
            question=question,
            question_id=question_id,
            stages=[],  # starts empty; each node appends its own tag
        )

        try:
            # Run the compiled StateGraph; returns the final merged AgentState
            final_state: AgentState = self._graph.invoke(initial_state)
        except ComplianceBotError:
            # Let known domain errors propagate to the caller unchanged
            raise
        except Exception:  # noqa: BLE001
            # Catch any unexpected error, log the full traceback, return a safe response
            LOGGER.exception("[%s] Unexpected graph error", question_id)
            return ComplianceOrchestrationResponse(
                question_id=question_id,
                error="Unexpected pipeline error — see server logs for details.",
                stages=["graph:unexpected_error"],
            )

        # Convert the final AgentState dict into the Pydantic response model
        return self._map_state_to_response(question_id, final_state)

    @staticmethod
    def _map_state_to_response(
        question_id: str,
        state: AgentState,
    ) -> ComplianceOrchestrationResponse:
        """Convert the final AgentState dict into a ComplianceOrchestrationResponse."""
        # Extract each field from the state dict — use or None to normalise empty strings
        clarification = state.get("clarification_needed")
        sql_query = state.get("sql_query") or None
        result_rows = state.get("result_rows") or None
        result_columns = list(state.get("result_columns") or [])
        result_summary = state.get("result_summary") or None
        error = state.get("error") or None
        stages = list(state.get("stages", []))
        # Prefer the normalised question; fall back to the original
        interpreted = state.get("interpreted_question") or state.get("question", "")

        LOGGER.info(
            "[%s] Pipeline complete — stages=%s rows=%s error=%s",
            question_id,
            stages,
            len(result_rows) if result_rows else 0,
            error,
        )

        return ComplianceOrchestrationResponse(
            question_id=question_id,
            interpreted_question=interpreted,
            needs_clarification=bool(clarification),  # True when intent was ambiguous
            clarification_question=clarification,
            sql_query=sql_query,
            df_output=result_rows,
            result_columns=result_columns,
            result_summary=result_summary,
            stages=stages,
            error=error,
        )

"""
Executor Agent — Node 5 of the NL2SQL LangGraph pipeline.

Executes the validated SQL SELECT statement against the Iceberg table
``dev_feature_store.COMP_TBL`` via ``PandasEngine`` (Hive on Tez / CML Data
connection) and produces a concise human-readable summary.

Result rendering is handled by the Streamlit UI via ``st.dataframe`` — this
module only returns rows, column names, and a one-sentence summary string.

Row-limit policy (controlled via ``[query]`` in ``config.toml``)
----------------------------------------------------------------
``enforce_default_limit = true``
    If the SQL has no LIMIT clause, append ``LIMIT <default_limit>`` before
    executing so unintentionally large result sets are never returned.

``enforce_default_limit = false``
    Execute the SQL exactly as written — no automatic LIMIT is added.

``max_display_rows``
    Hard ceiling on rows returned to the UI regardless of any LIMIT in the SQL.
"""

import logging
import re

from ...config import get_settings
from ...data._pandas_backend import PandasEngine
from .state import AgentState

LOGGER = logging.getLogger("dlh_ai")

_LIMIT_RE: re.Pattern[str] = re.compile(r"\bLIMIT\b", re.IGNORECASE)

# Load query limits once at import time from the unified config.toml.
_cfg = get_settings()
_ENFORCE_LIMIT: bool = _cfg.query.enforce_default_limit
_DEFAULT_LIMIT: int = _cfg.query.default_limit
_MAX_DISPLAY_ROWS: int = _cfg.query.max_display_rows or 500


def _ensure_limit(sql: str) -> tuple[str, bool]:
    """
    Apply the row-limit policy from query.toml.

    Returns *(effective_sql, injected)* where *injected* is True when
    ``LIMIT <default_limit>`` was automatically appended.

    When ``enforce_default_limit = false`` this is a no-op.
    """
    if not _ENFORCE_LIMIT:
        return sql, False
    stripped = sql.rstrip("; \t\n")
    if _LIMIT_RE.search(stripped):
        return sql, False  # SQL already has a LIMIT — leave it alone.
    return f"{stripped} LIMIT {_DEFAULT_LIMIT}", True


def format_summary(
    rows: list[dict[str, object]],
    columns: list[str],
    limit_injected: bool = False,
    default_limit: int = _DEFAULT_LIMIT,
    max_display_rows: int = _MAX_DISPLAY_ROWS,
) -> str:
    """
    Build a one-sentence result summary shown to the user.

    Handles three cases:
    - No rows → tells the user nothing matched.
    - Single-cell aggregate (COUNT, SUM …) → highlights the value.
    - Multi-row result → reports count and column names.
    """
    count = len(rows)

    if count == 0:
        return "The query executed successfully but returned no matching records."

    # Single row, single column — probably an aggregate like COUNT(*).
    if count == 1 and len(rows[0]) == 1:
        col, val = next(iter(rows[0].items()))
        return f"Result: **{col}** = `{val}`"

    if count >= max_display_rows:
        limit_note = (
            f" (first {max_display_rows} shown — add a LIMIT clause to narrow results)"
        )
    elif limit_injected:
        limit_note = (
            f" (showing first {default_limit} rows — "
            f"ask for more with 'show top N' or set enforce_default_limit=false in query.toml)"
        )
    else:
        limit_note = ""

    col_list = ", ".join(columns) if columns else ""
    return f"Query returned **{count} record(s)**{limit_note}. Columns: {col_list}."


class ExecutorAgent:
    """
    LangGraph node that executes the approved SQL query against the Iceberg
    table ``dev_feature_store.COMP_TBL`` via ``PandasEngine`` and formats
    the results.

    Row-limit behaviour is driven entirely by the ``[query]`` section of
    ``config.toml`` — no code changes needed to adjust limits.

    Parameters
    ----------
    connection_name : str
        CML Data connection name used by ``PandasEngine`` to reach Hive / Iceberg.
        Defaults to the same value set in ``PandasEngine``.
    """

    def __init__(self, connection_name: str = "DLH-DEV-UAT - Hive on Tez") -> None:
        self._engine = PandasEngine(connection_name=connection_name)

    def run(self, state: AgentState) -> AgentState:
        """Execute the SQL query against the Iceberg table and return formatted results."""
        sql: str = state.get("sql_query", "").strip()

        LOGGER.info("ExecutorAgent — executing SQL on Iceberg: %s", sql)

        if not sql:
            msg = "ExecutorAgent received an empty SQL query."
            LOGGER.error(msg)
            return AgentState(  # type: ignore[return-value]
                result_rows=[],
                result_columns=[],
                result_summary="No query to execute.",
                error=msg,
                stages=["executor_agent:empty_sql"],
            )

        rows, columns, error_msg, limit_injected = self._execute(sql)

        if error_msg:
            LOGGER.error("ExecutorAgent — SQL execution error: %s", error_msg)
            return AgentState(  # type: ignore[return-value]
                result_rows=[],
                result_columns=[],
                result_summary="Query execution failed.",
                error=error_msg,
                stages=["executor_agent:error"],
            )

        summary = format_summary(rows, columns, limit_injected)
        LOGGER.info("ExecutorAgent — %d rows returned.", len(rows))

        return AgentState(  # type: ignore[return-value]
            result_rows=rows,
            result_columns=columns,
            result_summary=summary,
            error=None,
            stages=[f"executor_agent:ok rows={len(rows)}"],
        )

    def _execute(
        self,
        sql: str,
    ) -> tuple[list[dict[str, object]], list[str], str | None, bool]:
        """
        Run *sql* via ``PandasEngine.read_table()`` (Iceberg / Hive on Tez).

        Returns ``(rows, column_names, error_message, limit_injected)``.
        """
        effective_sql, limit_injected = _ensure_limit(sql)
        if limit_injected:
            LOGGER.info(
                "ExecutorAgent — no LIMIT in SQL; auto-applied LIMIT %d (query.toml).",
                _DEFAULT_LIMIT,
            )

        try:
            df = self._engine.read_table(effective_sql)
            # Trim to the hard ceiling
            if len(df) > _MAX_DISPLAY_ROWS:
                df = df.iloc[:_MAX_DISPLAY_ROWS]

            col_names: list[str] = list(df.columns)
            rows: list[dict[str, object]] = df.to_dict(orient="records")
            return rows, col_names, None, limit_injected

        except Exception as exc:  # noqa: BLE001
            return [], [], f"Iceberg query error: {exc} | Query: {effective_sql}", False

"""
genai/nl2sql_agent/graph.py — LangGraph NL2SQL StateGraph factory.

Wires the six pipeline nodes and exposes:
  - build_nl2sql_graph — full constructor, all parameters explicit
  - create_graph       — convenience wrapper using AppSettings defaults

Pipeline topology:
  [START] → intent_checker
               ├─(intent_ok=False)→ clarify_node → [END]
               └─(intent_ok=True) → schema_checker
                                      └→ sql_writer_agent ←──────────────┐
                                           └→ sql_reviewer                │ retry
                                                ├─(passed)→ sql_validator─┤
                                                ├─(error) → executor      │
                                                └─(fail)  → sql_writer ───┘
                                                    │
                                           sql_validator
                                                ├─(valid)  → executor_agent → [END]
                                                └─(invalid)→ sql_writer_agent (retry)

The graph targets the Iceberg table ``dev_feature_store.COMP_TBL`` on Hive.
No SQLite database path is required — ``SchemaChecker`` and ``ExecutorAgent``
both connect to Iceberg directly.
"""

import logging
from typing import TYPE_CHECKING, Literal

from langgraph.graph import END, START, StateGraph

if TYPE_CHECKING:
    from langgraph.graph.state import CompiledStateGraph

from ..core.model import ModelLoaderService
from .executor_agent import ExecutorAgent
from .intent_checker import IntentChecker
from .schema_checker import SchemaChecker
from .sql_reviewer import SQLReviewer
from .sql_validator import SQLValidator
from .sql_writer_agent import SQLWriterAgent
from .state import AgentState

LOGGER = logging.getLogger("dlh_ai")

NODE_INTENT: str = "intent_checker"
NODE_SCHEMA: str = "schema_checker"
NODE_WRITER: str = "sql_writer_agent"
NODE_REVIEWER: str = "sql_reviewer"
NODE_VALIDATOR: str = "sql_validator"
NODE_EXECUTOR: str = "executor_agent"
NODE_CLARIFY: str = "clarify_node"


def _route_after_intent(state: AgentState) -> Literal["schema_checker", "clarify_node"]:
    """After IntentChecker: clear intent → schema; unclear/blocked → clarify."""
    return "schema_checker" if state.get("intent_ok", False) else "clarify_node"


def _route_after_reviewer(
    state: AgentState,
) -> Literal["sql_validator", "sql_writer_agent", "executor_agent"]:
    """After SQLReviewer:
    - Hard error (max retries hit) → executor surfaces the error message.
    - Passed all checks            → hand off to AST validator.
    - Failed but retries left      → send back to SQL writer with feedback.
    """
    if state.get("error"):
        return "executor_agent"
    if state.get("sql_review_passed", False):
        return "sql_validator"
    return "sql_writer_agent"


def _route_after_validator(
    state: AgentState,
) -> Literal["executor_agent", "sql_writer_agent"]:
    """After SQLValidator: valid AST → executor; invalid → retry the writer."""
    return "executor_agent" if state.get("sqlglot_valid", False) else "sql_writer_agent"


def _clarify_node(state: AgentState) -> AgentState:
    """
    Terminal node reached when intent is too ambiguous to process.

    Appends a stage tag and returns — the graph then routes to END.
    """
    LOGGER.info("ClarifyNode — ending graph (clarification requested).")
    return AgentState(stages=["clarify_node:terminal"])  # type: ignore[return-value]


def build_nl2sql_graph(
    model_service: ModelLoaderService,
    iceberg_table: str = "dev_feature_store.COMP_TBL",
    connection_name: str = "DLH-DEV-UAT - Hive on Tez",
    max_review_retries: int = 3,
    sqlglot_dialect: str = "hive",
) -> CompiledStateGraph:  # type: ignore[name-defined]
    """
    Construct and compile the six-node NL2SQL StateGraph.

    All nodes run queries against the Iceberg table on Hive — no local SQLite
    file is required.

    Args:
        model_service      — loaded ModelLoaderService for LLM inference
        iceberg_table      — fully-qualified Iceberg table (default: dev_feature_store.COMP_TBL)
        connection_name    — CML Data connection name for PandasEngine / ExecutorAgent
        max_review_retries — maximum writer → reviewer retry cycles (default 3)
        sqlglot_dialect    — sqlglot dialect for AST parsing (default "hive")

    Returns:
        A compiled LangGraph StateGraph ready to call .invoke() or .stream() on.
    """
    LOGGER.info(
        "Building NL2SQL LangGraph — table=%s retries=%d dialect=%s",
        iceberg_table,
        max_review_retries,
        sqlglot_dialect,
    )

    intent_checker = IntentChecker()
    schema_checker = SchemaChecker(iceberg_table=iceberg_table)
    sql_writer = SQLWriterAgent(model_service=model_service)
    sql_reviewer = SQLReviewer(max_retries=max_review_retries)
    sql_validator = SQLValidator(dialect=sqlglot_dialect)
    executor = ExecutorAgent(connection_name=connection_name)

    graph = StateGraph(AgentState)

    graph.add_node(NODE_INTENT, intent_checker.run)
    graph.add_node(NODE_SCHEMA, schema_checker.run)
    graph.add_node(NODE_WRITER, sql_writer.run)
    graph.add_node(NODE_REVIEWER, sql_reviewer.run)
    graph.add_node(NODE_VALIDATOR, sql_validator.run)
    graph.add_node(NODE_EXECUTOR, executor.run)
    graph.add_node(NODE_CLARIFY, _clarify_node)

    graph.add_edge(START, NODE_INTENT)

    graph.add_conditional_edges(
        NODE_INTENT,
        _route_after_intent,
        {NODE_SCHEMA: NODE_SCHEMA, NODE_CLARIFY: NODE_CLARIFY},
    )

    graph.add_edge(NODE_SCHEMA, NODE_WRITER)
    graph.add_edge(NODE_WRITER, NODE_REVIEWER)

    graph.add_conditional_edges(
        NODE_REVIEWER,
        _route_after_reviewer,
        {
            NODE_VALIDATOR: NODE_VALIDATOR,
            NODE_EXECUTOR: NODE_EXECUTOR,
            NODE_WRITER: NODE_WRITER,
        },
    )

    graph.add_conditional_edges(
        NODE_VALIDATOR,
        _route_after_validator,
        {NODE_EXECUTOR: NODE_EXECUTOR, NODE_WRITER: NODE_WRITER},
    )

    graph.add_edge(NODE_EXECUTOR, END)
    graph.add_edge(NODE_CLARIFY, END)

    compiled = graph.compile()
    LOGGER.info("NL2SQL LangGraph compiled successfully.")
    return compiled


def create_graph(
    model_service: ModelLoaderService,
    iceberg_table: str | None = None,
    connection_name: str | None = None,
    max_review_retries: int = 3,
    sqlglot_dialect: str = "hive",
) -> CompiledStateGraph:  # type: ignore[name-defined]
    """
    Convenience wrapper — iceberg_table and connection_name default to the
    values configured in AppSettings / PandasEngine.

    Use this when you don't need to override the Iceberg table explicitly.
    """
    from ...config import get_settings  # noqa: PLC0415

    settings = get_settings()

    resolved_table: str = iceberg_table or settings.database.iceberg_table
    resolved_conn: str = connection_name or settings.database.connection_name

    LOGGER.info(
        "create_graph — table=%s retries=%d", resolved_table, max_review_retries
    )
    return build_nl2sql_graph(
        model_service=model_service,
        iceberg_table=resolved_table,
        connection_name=resolved_conn,
        max_review_retries=max_review_retries,
        sqlglot_dialect=sqlglot_dialect,
    )

        "hi",

        "ok",
        "okay",
        "thanks",
        "thank",

)

_PUNCT_STRIP: re.Pattern[str] = re.compile(r"[^\w]")

_DISALLOWED_ACTION_WORDS: Final[frozenset[str]] = frozenset(
    {
        "delete",
        "drop",
        "insert",
        "update",
        "truncate",
        "alter",
        "create",

class IntentChecker:
    """
    LangGraph node that classifies user intent.

    All messages sourced from intent_checker.yaml — edit that file to change
    the wording shown to users without touching Python code.
    """

    def run(self, state: AgentState) -> AgentState:
        """Classify intent through four sequential rule-based checks."""
        question: str = state.get("question", "").strip()
        LOGGER.info("IntentChecker — analysing: %r", question)

        # ── Check 1: empty question ────────────────────────────────────────
        if not question:
            LOGGER.warning("IntentChecker — empty question.")
            return AgentState(  # type: ignore[return-value]
                interpreted_question="",
                intent_ok=False,
                clarification_needed=get_prompt(
                    _YAML,
                    "messages",
                    "empty_question",
                    default=(
                        "No question was provided. Please ask a compliance query, "
                        'for example: "How many accounts have KYC flag N?"'
                    ),
                ),
                stages=["intent_checker:empty"],
            )

        lower_q = question.lower()
        raw_tokens = lower_q.split()
        clean_tokens = {
            _PUNCT_STRIP.sub("", t) for t in raw_tokens if _PUNCT_STRIP.sub("", t)
        }

        # ── Check 2: disallowed action words ──────────────────────────────
        matched = _DISALLOWED_ACTION_WORDS & clean_tokens
        if matched:
            blocked_word = min(matched).upper()
            LOGGER.warning("IntentChecker — disallowed action word: %s", blocked_word)
            template = get_prompt(_YAML, "messages", "disallowed_action", default="")
            msg = (
                template.format(blocked_word=blocked_word)
                if template
                else (
                    f"Sorry, the keyword <strong>{blocked_word}</strong> is not permitted. "
                    "This system is <strong>read-only</strong> — only SELECT queries are supported."
                )
            )
            return AgentState(  # type: ignore[return-value]
                interpreted_question=self._normalise(question),
                intent_ok=False,
                clarification_needed=msg,
                stages=[f"intent_checker:disallowed_action_word={blocked_word}"],
            )

        # ── Check 3: too short / meaningless ──────────────────────────────
        has_metric = bool(_METRIC_TERMS & clean_tokens) or any(
            m in lower_q for m in _METRIC_TERMS
        )
        meaningful = {
            t
            for t in clean_tokens
            if t not in _STOP_WORDS and len(t) >= _MIN_TOKEN_LEN and not t.isdigit()
        }
        if len(meaningful) < _MIN_MEANINGFUL_TOKENS and not has_metric:
            LOGGER.info(
                "IntentChecker — too short (%d tokens): %r", len(meaningful), question
            )
            return AgentState(  # type: ignore[return-value]
                interpreted_question=self._normalise(question),
                intent_ok=False,
                clarification_needed=get_prompt(
                    _YAML,
                    "messages",
                    "too_short",
                    default="Your question is too short or unclear to process.",
                ),
                stages=["intent_checker:too_short"],
            )

        # ── Check 4: vague / ambiguous phrasing ───────────────────────────
        is_pure_vague = lower_q.strip("?. ") in _VAGUE_PHRASES
        has_ambiguous = bool(_AMBIGUOUS_TOKENS & clean_tokens)
        rich_question = len(meaningful) > _RICH_QUESTION_THRESHOLD
        needs_clarification = is_pure_vague or (
            has_ambiguous and not has_metric and not rich_question
        )

        interpreted = self._normalise(question)

        if needs_clarification:
            LOGGER.info("IntentChecker — clarification required: %r", question)
            return AgentState(  # type: ignore[return-value]
                interpreted_question=interpreted,
                intent_ok=False,
                clarification_needed=get_prompt(
                    _YAML,
                    "messages",
                    "clarification",
                    default="Your question is unclear. Please rephrase with more detail.",
                ),
                stages=["intent_checker:clarification_required"],
            )

        LOGGER.info("IntentChecker — intent OK: %r", interpreted)
        return AgentState(  # type: ignore[return-value]
            interpreted_question=interpreted,
            intent_ok=True,
            clarification_needed=None,
            stages=["intent_checker:ok"],
        )

    @staticmethod
    def _normalise(question: str) -> str:
        """Strip whitespace and ensure a trailing question mark."""
        q = question.strip()
        if q and not q.endswith("?"):
            q = q.rstrip(".") + "?"
        return q

"""
genai/nl2sql_agent/schema_checker.py — Node 2 of the NL2SQL pipeline.

Builds a Markdown-formatted schema context string for the SQL Writer to
embed in its LLM prompt.  The authoritative schema comes from two sources:

1. ``[databases]`` section of the project-root ``config.toml`` — table
   descriptions, column descriptions, and few-shot examples (loaded via
   the registry).
2. ``data/iceberg_schema.txt`` — Iceberg DDL types used to annotate each
   column with its exact Hive/Iceberg data type.

No live database connection is made here — all introspection has been
replaced with static metadata from the configuration sources above.  This is
correct because the target store is an Iceberg table on Hive (not a local
SQLite file) and schema reads against the live cluster are unnecessary.

Configuration (header templates) is loaded from
``genai/prompt/schema_checker.yaml``.  The target Iceberg table and bare
table name are read from ``[nl2sql]`` in ``config.toml`` via
:func:`~dlh_ai.utils.config.get_settings`.
"""

import logging
import re
from pathlib import Path
from typing import Any

from ...config import get_settings
from ...utils.registry import get_prompt, get_table_meta, load_prompt
from .state import AgentState

LOGGER = logging.getLogger("dlh_ai")

_YAML = "schema_checker.yaml"
_CFG = load_prompt(_YAML)

# Path to the Iceberg DDL file — used to extract Hive column types
_ICEBERG_SCHEMA_FILE = (
    Path(__file__).resolve().parents[3] / "data" / "iceberg_schema.txt"
)

# Table identifiers loaded from config.toml once at import time.
_nl2sql_cfg = get_settings().nl2sql
_ICEBERG_TABLE: str = _nl2sql_cfg.iceberg_table
_TABLE_NAME: str = _nl2sql_cfg.compliance_table_name

# Pre-compiled pattern to extract  <col_name>  <TYPE>  from the DDL
_COL_TYPE_RE = re.compile(
    r"^\s{4}(\w+)\s+(STRING|DATE|INT|DECIMAL\(\d+,\s*\d+\))",
    re.IGNORECASE | re.MULTILINE,
)


def _load_iceberg_types() -> dict[str, str]:
    """
    Parse ``data/iceberg_schema.txt`` and return {COLUMN_NAME: HIVE_TYPE}.

    Returns an empty dict if the file is missing or unparseable — the schema
    context will still be built from databases.toml alone.
    """
    if not _ICEBERG_SCHEMA_FILE.exists():
        LOGGER.warning(
            "SchemaChecker — iceberg_schema.txt not found at %s; skipping type annotations.",
            _ICEBERG_SCHEMA_FILE,
        )
        return {}
    try:
        text = _ICEBERG_SCHEMA_FILE.read_text(encoding="utf-8")
        return {
            m.group(1).upper(): m.group(2).upper() for m in _COL_TYPE_RE.finditer(text)
        }
    except Exception:  # noqa: BLE001
        LOGGER.exception("SchemaChecker — failed to parse iceberg_schema.txt")
        return {}


# Module-level cache — parse once on first import
_ICEBERG_TYPES: dict[str, str] = _load_iceberg_types()


class SchemaChecker:
    """
    LangGraph node — builds the Markdown schema context for the SQL Writer.

    The schema is constructed entirely from static config files:
      - ``databases.toml``      → column business descriptions + few-shots
      - ``iceberg_schema.txt``  → Hive/Iceberg column data types

    Parameters
    ----------
    iceberg_table : str
        Fully qualified Iceberg table name written into ``db_path`` on the
        state so downstream nodes (reviewer, etc.) know the target table.
        Defaults to ``dev_feature_store.COMP_TBL``.
    """

    def __init__(self, iceberg_table: str = _ICEBERG_TABLE) -> None:
        self._iceberg_table = iceberg_table

    def run(self, state: AgentState) -> AgentState:
        """Build the Iceberg schema context string and inject it into state."""
        question: str = state.get("interpreted_question", state.get("question", ""))
        LOGGER.info("SchemaChecker — building Iceberg schema context for: %r", question)

        context = self._build_context()

        LOGGER.info("SchemaChecker — using Iceberg table=%s", self._iceberg_table)
        return AgentState(  # type: ignore[return-value]
            db_path=self._iceberg_table,  # downstream nodes read this as the target table
            schema_context=context,
            stages=[f"schema_checker:table={self._iceberg_table}"],
        )

    def _build_context(self) -> str:
        """Build the Markdown schema context block for LLM injection."""
        schema_header = get_prompt(
            _YAML, "messages", "schema_header", default="## Database: `{db_stem}`"
        )
        table_header = get_prompt(
            _YAML, "messages", "table_header", default="### Table: `{table_name}`"
        )
        col_desc_header = get_prompt(
            _YAML,
            "messages",
            "col_desc_header",
            default="**Column descriptions for `{table_name}` (from databases.toml):**",
        )

        lines: list[str] = [
            schema_header.format(db_stem="dev_feature_store"),  # type: ignore[arg-type]
            "",
            f"> Target Iceberg table: `{self._iceberg_table}`",
            "",
        ]

        # ── Schema table: column name + Hive type ────────────────────────────
        lines.append(table_header.format(table_name=_TABLE_NAME))  # type: ignore[arg-type]
        lines.append("")
        lines.append("| # | Column | Hive/Iceberg Type |")
        lines.append("|---|--------|-------------------|")

        toml_meta: dict[str, Any] = get_table_meta(_TABLE_NAME)
        toml_cols: dict[str, str] = toml_meta.get("columns", {})

        for idx, col_name in enumerate(toml_cols):
            col_type = _ICEBERG_TYPES.get(col_name.upper(), "STRING")
            lines.append(f"| {idx} | `{col_name}` | {col_type} |")

        lines.append("")

        # ── Business descriptions from databases.toml ─────────────────────────
        if toml_cols:
            lines.append(col_desc_header.format(table_name=_TABLE_NAME))  # type: ignore[arg-type]
            lines.append("")
            for col_name, col_desc in toml_cols.items():
                lines.append(f"- `{col_name}`: {col_desc}")
            lines.append("")

        # ── Table-level description ───────────────────────────────────────────
        tbl_desc: str = toml_meta.get("description", "")
        if tbl_desc:
            lines.append(f"**Table description:** {tbl_desc}")
            lines.append("")

        return "\n".join(lines)

"""
genai/nl2sql_agent/sql_reviewer.py — Node 4 of the NL2SQL pipeline.

Validates the SQL statement produced by the SQL Writer before it reaches
the SQL Validator (Node 4.5) and the Executor.

ALL user-facing and reviewer feedback strings are loaded from
genai/prompt/sql_review.yaml — no message strings are hardcoded here.

Also contains RetryHandler (retry count management).

Four validation checks:
  1. Safety    — retry ceiling guard
  2. Safety    — disallowed DML/DDL keywords
  3. Structure — must start with SELECT and contain FROM
  4. Schema    — every referenced table must exist in the live database

The max-retry ceiling is read from ``[nl2sql]`` in ``config.toml`` via
:func:`~dlh_ai.utils.config.get_settings`.
"""

import logging
import re
from typing import Final

from ...config import get_settings
from ...utils.registry import get_all_tables, get_prompt
from .state import AgentState

LOGGER = logging.getLogger("dlh_ai")

_YAML = "sql_review.yaml"

# Max retries loaded from config.toml once at import time.
_MAX_ALLOWED_RETRIES: Final[int] = get_settings().nl2sql.max_retries

_DISALLOWED_KEYWORDS: Final[frozenset[str]] = frozenset(
    {
        "INSERT",
        "UPDATE",
        "DELETE",
        "DROP",
        "TRUNCATE",
        "ALTER",
        "CREATE",
        "REPLACE",
        "PRAGMA",
        "ATTACH",
        "DETACH",
        "VACUUM",
    }
)

_FROM_PATTERN: Final[re.Pattern[str]] = re.compile(r"\bFROM\b", re.IGNORECASE)
_TABLE_PATTERN: Final[re.Pattern[str]] = re.compile(
    r"\bFROM\s+([`\"\[]?[\w.]+[`\"\]]?)"
    r"|\bJOIN\s+([`\"\[]?[\w.]+[`\"\]]?)",
    re.IGNORECASE,
)
# Known Iceberg tables — sourced from databases.toml at import time.
# The reviewer uses this set instead of live SQLite PRAGMA queries.
_KNOWN_TABLES: frozenset[str] = frozenset(t.upper() for t in get_all_tables())


class RetryHandler:
    """Keeps retry count and enforces the ceiling."""

    def __init__(self, max_retries: int = _MAX_ALLOWED_RETRIES) -> None:
        self._max = max_retries

    @property
    def max_retries(self) -> int:
        return self._max

    def current_count(self, state: AgentState) -> int:
        return int(state.get("retry_count", 0))

    def should_retry(self, state: AgentState) -> bool:
        return self.current_count(state) < self._max

    def increment(self, state: AgentState) -> AgentState:
        n = self.current_count(state) + 1
        LOGGER.info("RetryHandler — retry_count → %d (max=%d)", n, self._max)
        return AgentState(retry_count=n)  # type: ignore[return-value]


class SQLReviewer:
    """
    LangGraph node — safety and schema validation on generated SQL.

    All feedback/error messages come from sql_review.yaml.
    max_retries — maximum writer → reviewer cycles before giving up.
    """

    def __init__(self, max_retries: int = _MAX_ALLOWED_RETRIES) -> None:
        self._max_retries = max_retries

    def run(self, state: AgentState) -> AgentState:
        """Validate the generated SQL through four sequential checks."""
        sql: str = state.get("sql_query", "").strip()
        retry: int = state.get("retry_count", 0)

        LOGGER.info("SQLReviewer — reviewing SQL (retry=%d): %s", retry, sql)

        # ── Guard: retry ceiling ───────────────────────────────────────────
        if retry >= self._max_retries:
            msg = get_prompt(
                _YAML,
                "feedback",
                "max_retries",
                default=(
                    f"⚠ The request could not be completed after {self._max_retries} attempts. "
                    "Please rephrase your question and try again."
                ),
            )
            msg = msg.format(max_retries=self._max_retries)  # type: ignore[union-attr]
            LOGGER.error("SQLReviewer — max retries exceeded.")
            return AgentState(  # type: ignore[return-value]
                sql_review_passed=False,
                review_feedback=msg,
                retry_count=retry,
                stages=["sql_reviewer:max_retries_exceeded"],
                error=msg,
            )

        # ── Guard: empty SQL ───────────────────────────────────────────────
        if not sql:
            return AgentState(  # type: ignore[return-value]
                sql_review_passed=False,
                review_feedback=get_prompt(
                    _YAML,
                    "feedback",
                    "empty_sql",
                    default="The SQL Writer returned an empty query.",
                ),
                retry_count=retry + 1,
                stages=["sql_reviewer:empty_sql"],
            )

        # ── Check 1: disallowed keywords ──────────────────────────────────
        upper_sql = sql.upper()
        for kw in _DISALLOWED_KEYWORDS:
            if re.search(rf"\b{kw}\b", upper_sql):
                LOGGER.warning("SQLReviewer — disallowed keyword: %s", kw)
                feedback_tpl = get_prompt(
                    _YAML, "feedback", "disallowed_kw", default=""
                )
                error_tpl = get_prompt(_YAML, "user_error", "disallowed_kw", default="")
                return AgentState(  # type: ignore[return-value]
                    sql_review_passed=False,
                    review_feedback=(feedback_tpl or "").format(kw=kw),
                    retry_count=retry + 1,
                    stages=[f"sql_reviewer:disallowed_keyword={kw}"],
                    error=(error_tpl or "").format(kw=kw),
                )

        # ── Check 2: must start with SELECT ───────────────────────────────
        if not upper_sql.strip().startswith("SELECT"):
            LOGGER.warning("SQLReviewer — no SELECT prefix.")
            return AgentState(  # type: ignore[return-value]
                sql_review_passed=False,
                review_feedback=get_prompt(
                    _YAML,
                    "feedback",
                    "no_select",
                    default="The query must begin with SELECT.",
                ),
                retry_count=retry + 1,
                stages=["sql_reviewer:no_select"],
            )

        # ── Check 3: must contain FROM ────────────────────────────────────
        if not _FROM_PATTERN.search(sql):
            LOGGER.warning("SQLReviewer — missing FROM clause.")
            return AgentState(  # type: ignore[return-value]
                sql_review_passed=False,
                review_feedback=get_prompt(
                    _YAML,
                    "feedback",
                    "missing_from",
                    default="The query is missing a FROM clause.",
                ),
                retry_count=retry + 1,
                stages=["sql_reviewer:missing_from"],
            )

        # ── Check 4: all referenced tables must exist in databases.toml ──────
        invalid = self._check_tables(sql)
        if invalid:
            LOGGER.warning("SQLReviewer — unknown tables: %s", invalid)
            tpl = get_prompt(_YAML, "feedback", "unknown_tables", default="")
            return AgentState(  # type: ignore[return-value]
                sql_review_passed=False,
                review_feedback=(tpl or "").format(tables=", ".join(invalid)),
                retry_count=retry + 1,
                stages=[f"sql_reviewer:unknown_tables={invalid}"],
            )

        LOGGER.info("SQLReviewer — SQL passed all checks.")
        return AgentState(  # type: ignore[return-value]
            sql_review_passed=True,
            review_feedback=None,
            retry_count=retry,
            stages=["sql_reviewer:passed"],
        )

    @staticmethod
    def _check_tables(sql: str) -> list[str]:
        """
        Return table names referenced in *sql* that are not registered in
        databases.toml.

        Fully-qualified Iceberg names (``db.table``) are checked against both
        their bare table name and the full qualified form so that queries like
        ``SELECT … FROM dev_feature_store.COMP_TBL`` pass validation.
        """
        referenced: set[str] = set()
        for m in _TABLE_PATTERN.finditer(sql):
            name = (m.group(1) or m.group(2) or "").strip('`"[]')
            if name:
                # Accept both qualified (db.table) and bare (table) forms
                bare = name.upper().split(".")[-1]
                referenced.add(bare)
        if not referenced:
            return []
        return sorted(referenced - _KNOWN_TABLES)

"""
genai/nl2sql_agent/sql_validator.py — Node 4.5 of the NL2SQL pipeline.

Uses sqlglot to parse the generated SQL at the AST level before it
reaches the database.  Catches syntax errors and non-SELECT statements
that slipped past the regex-based SQL Reviewer.

Three checks:
  1. Parse validity  — sqlglot must build an AST without errors.
  2. Statement type  — only SELECT statements are allowed.
  3. Dialect round-trip — canonicalise to the configured dialect.

No prompt file needed — all output is structural pass/fail, no user messages.

The default SQL dialect is read from ``[nl2sql]`` in ``config.toml`` via
:func:`~dlh_ai.utils.config.get_settings`.
"""

import logging

from ...config import get_settings
from .state import AgentState

LOGGER = logging.getLogger("dlh_ai")

_ALLOWED_STMT_TYPES: frozenset[str] = frozenset({"select"})

# Default dialect loaded from config.toml once at import time.
_DEFAULT_DIALECT: str = get_settings().nl2sql.sql_dialect


class SQLValidator:
    """
    LangGraph node — AST-level SQL validation via sqlglot.

    Parameters
    ----------
    dialect : str, optional
        sqlglot dialect for parsing and canonicalisation.
        Defaults to the value of ``[nl2sql].sql_dialect`` in ``config.toml``.
    strict_mode : bool, optional
        Reserved for future use.  Defaults to ``False``.
    """

    def __init__(self, dialect: str = "", strict_mode: bool = False) -> None:
        # Fall back to the config.toml value when no dialect is explicitly passed.
        self._dialect: str = dialect if dialect else _DEFAULT_DIALECT
        self._strict_mode = strict_mode

    def run(self, state: AgentState) -> AgentState:
        """Parse the SQL in state['sql_query'] and decide pass or retry."""
        sql: str = state.get("sql_query", "").strip()
        retry: int = state.get("retry_count", 0)

        LOGGER.info("SQLValidator — validating: %s", sql)

        # If sqlglot isn't installed, skip and let the executor handle it.
        try:
            import sqlglot
            import sqlglot.errors
        except ImportError:
            LOGGER.warning("SQLValidator — sqlglot not installed; skipping AST check.")
            return AgentState(  # type: ignore[return-value]
                sqlglot_valid=True,
                sqlglot_error=None,
                stages=["sql_validator:skipped_no_sqlglot"],
            )

        # Check 1: parse.
        parse_error: str | None = None
        parsed = []
        try:
            parsed = sqlglot.parse(
                sql,
                dialect=self._dialect,
                error_level=sqlglot.errors.ErrorLevel.RAISE,
            )
        except sqlglot.errors.ParseError as exc:
            parse_error = str(exc)
            LOGGER.warning("SQLValidator — ParseError: %s", parse_error)

        if parse_error:
            return self._fail(
                retry,
                stage_tag="parse_error",
                reason=f"sqlglot could not parse the SQL: {parse_error}. Use standard Hive/Iceberg SQL syntax.",
            )

        if not parsed or parsed[0] is None:
            return self._fail(
                retry,
                stage_tag="empty_ast",
                reason="sqlglot returned an empty parse tree. Ensure the query is a valid SELECT.",
            )

        stmt = parsed[0]

        # Check 2: only SELECT allowed.
        stmt_type = type(stmt).__name__.lower()
        if stmt_type not in _ALLOWED_STMT_TYPES:
            LOGGER.warning("SQLValidator — non-SELECT type: %s", stmt_type)
            return self._fail(
                retry,
                stage_tag=f"disallowed_stmt_type={stmt_type}",
                reason=f"sqlglot identified this as '{stmt_type.upper()}'. Only SELECT is permitted.",
            )

        # Check 3: canonicalise to SQLite dialect.
        try:
            canonical: str = stmt.sql(dialect=self._dialect, pretty=False)
        except Exception:  # noqa: BLE001
            canonical = sql

        if canonical and canonical.strip() != sql.strip():
            LOGGER.info(
                "SQLValidator — SQL normalised.\n  Before: %s\n  After : %s",
                sql,
                canonical,
            )

        LOGGER.info("SQLValidator — passed AST validation.")
        return AgentState(  # type: ignore[return-value]
            sqlglot_valid=True,
            sqlglot_error=None,
            sql_query=canonical or sql,
            stages=[f"sql_validator:passed dialect={self._dialect}"],
        )

    @staticmethod
    def _fail(retry: int, reason: str, stage_tag: str) -> AgentState:
        """Return a partial AgentState marking validation as failed."""
        return AgentState(  # type: ignore[return-value]
            sqlglot_valid=False,
            sqlglot_error=reason,
            sql_review_passed=False,
            review_feedback=reason,
            retry_count=retry + 1,
            stages=[f"sql_validator:{stage_tag}"],
        )

"""
genai/nl2sql_agent/sql_writer_agent.py — Node 3 of the NL2SQL pipeline.

by calling the configured LLM provider.

The system role, generation rules, and prompt template are loaded from

_INLINE_COMMENT_RE: re.Pattern[str] = re.compile(r"--[^\n]*", re.MULTILINE)
_BLOCK_COMMENT_RE: re.Pattern[str] = re.compile(r"/\*.*?\*/", re.DOTALL)
_WHITESPACE_RE: re.Pattern[str] = re.compile(r"[ \t]+")


def strip_comments(sql: str) -> str:
    """Remove all -- inline and /* */ block comments from sql."""
    sql = _BLOCK_COMMENT_RE.sub(" ", sql)
    return _INLINE_COMMENT_RE.sub("", sql).strip()


def normalise_whitespace(sql: str) -> str:
    """Collapse horizontal whitespace runs to a single space on each line."""
    lines = [_WHITESPACE_RE.sub(" ", line).strip() for line in sql.splitlines()]
    return "\n".join(line for line in lines if line)


def strip_trailing_semicolon(sql: str) -> str:
    """Remove trailing semicolons and whitespace."""
    return sql.rstrip("; \t\n")


def optimise(sql: str) -> str:
    """
    Strip comments → normalise whitespace → remove trailing semicolons.
    Never changes query semantics.
    """
    sql = strip_comments(sql)
    sql = normalise_whitespace(sql)
    sql = strip_trailing_semicolon(sql)
    LOGGER.debug("optimise — result: %s", sql[:200])
    return sql

class ContextBuilder:
    """
    Builds the full LLM prompt for the SQL Writer Agent.

    System role, rules, and template are loaded from sql_writer.yaml.
    Table metadata and few-shot examples come from databases.toml via registry.
    Zero hardcoded strings — edit the YAML files to change prompt wording.
    """

    def __init__(self, table_name: str) -> None:
        self._table_name = table_name

    def build(
        self,
        question: str,
        schema_context: str,
        feedback: str | None = None,
    ) -> str:
        """
        Assemble and return the full prompt string.

        question       — normalised question from IntentChecker
        schema_context — Markdown schema block from SchemaChecker
        feedback       — reviewer feedback on retry path (None on first attempt)
        """
        meta = get_table_meta(self._table_name)
        table_desc = meta.get("description", "")
        col_desc: dict[str, str] = meta.get("columns", {})
        few_shots = get_few_shots(self._table_name)

        # Format column block and rules
        column_block = "\n".join(
            f"  - **{col}**: {desc}" for col, desc in col_desc.items()
        )
        rules_block = "\n".join(f"  {i + 1}. {rule}" for i, rule in enumerate(_RULES))
        retry_section = f"\n{_RETRY_HEADER}\n{feedback}\n" if feedback else ""

        LOGGER.debug(
            "ContextBuilder — table=%s question=%r retry=%s",
            self._table_name,
            question[:80],
            bool(feedback),
        )

        # Use the TOML template when available; fall back to inline format
        if _TEMPLATE:
            return _TEMPLATE.format(
                system_role=_SYSTEM_ROLE,
                rules_block=rules_block,
                table_name=self._table_name,
                table_description=table_desc,
                column_block=column_block,
                schema_context=schema_context,
                few_shots=few_shots,
                retry_section=retry_section,
                question=question,
            )

        # Fallback (shouldn't normally be reached)
        return (
            f"[INST] <<SYS>>\n{_SYSTEM_ROLE}\n\nRules:\n{rules_block}\n<</SYS>>\n\n"
            f"=== Table Metadata: {self._table_name} ===\n"
            f"Description: {table_desc}\n\nColumns:\n{column_block}\n\n"
            f"=== Live Database Schema ===\n{schema_context}\n\n"
            f"=== Few-shot Examples ===\n{few_shots}\n"
            f"{retry_section}\n"
            f"Question: {question}\nResponse:\n[/INST]"
        )


class SQLWriterAgent:
    """
    LangGraph node — calls the LLM to generate a SQLite SELECT statement.

    Prompt is built by ContextBuilder (YAML-driven, no hardcoded strings).
    Table metadata comes from databases.toml — add new databases/tables there.
    """

    def __init__(
        self,
        model_service: ModelLoaderService,
        table_name: str = "",
    ) -> None:
        self._model_service = model_service
        self._context_builder = ContextBuilder(
            table_name=table_name or _DEFAULT_TABLE_NAME
        )

    def run(self, state: AgentState) -> AgentState:
        """Generate a SQL SELECT query for the current pipeline state.

        Uses :meth:`~ModelLoaderService.extract_sql` which calls the LLM
        via structured output — no regex tag-matching required.
        """
        question: str = state.get("interpreted_question", state.get("question", ""))
        schema_context: str = state.get("schema_context", "")
        feedback: str | None = state.get("review_feedback")
        retry: int = state.get("retry_count", 0)

        LOGGER.info(
            "SQLWriterAgent — generating SQL (retry=%d) for: %r", retry, question
        )

        # Build the full prompt and pass it directly to extract_sql which
        # uses with_structured_output — a single LLM call returns parsed SQL.
        prompt = self._context_builder.build(question, schema_context, feedback)
        sql = self._model_service.extract_sql(prompt)

        if not sql:
            LOGGER.warning("SQLWriterAgent — structured output returned no SQL.")
            return AgentState(  # type: ignore[return-value]
                sql_query="",
                retry_count=retry,
                stages=["sql_writer_agent:extraction_failed"],
                error="LLM structured output did not return a valid SQL statement.",
            )

        LOGGER.info("SQLWriterAgent — LLM SQL: %s", sql)
        return AgentState(  # type: ignore[return-value]
            sql_query=sql,
            retry_count=retry,
            stages=[f"sql_writer_agent:llm_generated retry={retry}"],
        )

    The ``stages`` list uses an ``Annotated`` reducer so LangGraph appends
    entries from each node rather than overwriting the whole list.

    Attributes
    ----------
    question : str
        Raw user question from the Streamlit chat input.
        Set by ``ComplianceProcessor`` before invoking the graph.
    question_id : str or None
        Optional caller-supplied idempotency key.

    intent_ok : bool

        ``False`` when the question needs clarification or should be blocked.

"""
genai/prompt/_manager.py — YAML prompt loading and Jinja2 template rendering.

:class:`PromptManager` eagerly loads all ``*.yaml`` files from the prompt
directory on construction, registers them by agent name (file stem), and
renders individual prompts via Jinja2 at call time.
"""

import logging
from dataclasses import dataclass, field
from pathlib import Path
from typing import Any

import yaml
from jinja2 import Environment, StrictUndefined, Undefined

LOGGER = logging.getLogger("dlh_ai")

__all__ = ["PromptManager"]


@dataclass
class PromptManager:
    """Load and render agent prompts from YAML files in the prompt directory.

    Prompts are eagerly loaded from all ``*.yaml`` files found in the same
    directory as this module.  Each file's stem becomes the *agent name* key
    and the file must contain a YAML mapping at root level.

    Parameters
    ----------
    strict_templates : bool, optional
        When ``True`` (default), Jinja2 raises ``UndefinedError`` for any
        variable referenced in a template but not supplied at render time.
        Set to ``False`` to silently produce empty strings for missing variables.

    Attributes
    ----------
    strict_templates : bool
        Controls Jinja2 undefined-variable behaviour.

    Examples
    --------
    >>> manager = PromptManager()
    >>> prompt = manager.get_prompt("intent_checker", "system")
    """

    strict_templates: bool = True
    _prompt_dir: Path = field(init=False, repr=False)
    _prompt_registry: dict[str, dict[str, Any]] = field(
        init=False, repr=False, default_factory=dict
    )
    _jinja_env: Environment = field(init=False, repr=False)

    def __post_init__(self) -> None:
        """Initialise the prompt directory, Jinja2 environment, and prompt cache."""
        self._prompt_dir = Path(__file__).parent
        self._jinja_env = Environment(
            undefined=StrictUndefined if self.strict_templates else Undefined
        )
        self._load_all_prompts()

    def _load_all_prompts(self) -> None:
        """Eagerly load all YAML prompt files from the prompt directory.

        Iterates over every ``*.yaml`` file in :attr:`_prompt_dir`, parses
        each as a YAML mapping, and stores it in :attr:`_prompt_registry` keyed
        by the file stem.  Files that fail to parse are logged and stored as an
        empty dict so subsequent lookups degrade gracefully.
        """
        self._prompt_registry.clear()

        for file_path in self._prompt_dir.glob("*.yaml"):
            agent_name = file_path.stem
            try:
                with file_path.open("r", encoding="utf-8") as fh:
                    prompts: Any = yaml.safe_load(fh) or {}

                if not isinstance(prompts, dict):
                    LOGGER.error(
                        "Prompt file for agent %s must contain a YAML mapping at root. "
                        "Got: %s",
                        agent_name,
                        type(prompts).__name__,
                    )
                    prompts = {}

                self._prompt_registry[agent_name] = prompts
            except Exception:  # noqa: BLE001
                LOGGER.exception(
                    "Error loading prompts for agent %s from %s",
                    agent_name,
                    file_path,
                )
                self._prompt_registry[agent_name] = {}

    def get_prompt(self, agent_name: str, prompt_key: str, **kwargs: Any) -> str:
        """Retrieve a prompt template and render it with the supplied keyword arguments.

        Parameters
        ----------
        agent_name : str
            Name of the agent; must match the stem of a YAML file in the prompt
            directory (e.g. ``"intent_checker"`` → ``intent_checker.yaml``).
        prompt_key : str
            Key of the prompt within the agent's YAML mapping
            (e.g. ``"system"`` or ``"instructions"``).
        **kwargs : Any
            Variables substituted into the Jinja2 template at render time.

        Returns
        -------
        str
            The fully rendered prompt string.

        Raises
        ------
        ValueError
            When the ``agent_name`` / ``prompt_key`` combination is not found or
            when the template rendering fails due to a missing variable.

        Examples
        --------
        >>> pm = PromptManager()
        >>> prompt = pm.get_prompt("intent_checker", "system", question="What is KYC?")
        >>> prompt2 = pm.get_prompt("sql_writer", "instructions", columns=["col1", "col2"])

        Notes
        -----
        Template rendering errors (e.g. ``UndefinedError`` when
        ``strict_templates=True``) are re-raised as :class:`ValueError` so
        callers receive a consistent exception type.
        """
        prompts = self._prompt_registry.get(agent_name, {})
        template_str = prompts.get(prompt_key, "")
        if not isinstance(template_str, str) or not template_str:
            raise ValueError(f"Prompt not found: {agent_name}.{prompt_key}")

        template = self._jinja_env.from_string(template_str)
        return template.render(**kwargs)

    def clear_cache(self, agent_name: str | None = None) -> None:
        """Remove one or all entries from the in-memory prompt registry.

        Parameters
        ----------
        agent_name : str or None, optional
            When provided, only the entry for that agent is removed.
            When ``None`` (default), the entire registry is cleared.
        """
        if agent_name is None:
            self._prompt_registry.clear()
        else:
            self._prompt_registry.pop(agent_name, None)

    def reload(self) -> None:
        """Reload all prompt YAML files from disk, replacing the current cache."""
        self._load_all_prompts()

RUNTIME_IDENTIFIER: list[str] = [

"""

Provides :class:`HDFSClient` for listing, uploading, downloading, and reading

import logging

from dataclasses import dataclass

import pyarrow.dataset as ds
import pyarrow.fs as fs

LOGGER = logging.getLogger("dlh_ai")

__all__ = ["HDFSClient"]


@dataclass
class HDFSClient:
    """HDFS client for interacting with Hadoop Distributed File System.

    Provides file operations, data reading, and model loading from HDFS using
    the PyArrow filesystem interface and HDFS CLI commands.

    Parameters
    ----------
    host : str, optional
        HDFS host connection string. Use ``"default"`` to connect to the default
        filesystem configured in Hadoop settings. Defaults to ``"default"``.

    Attributes
    ----------

    --------
    >>> client = HDFSClient()
    >>> files = client.list_files("/user/some_folder/data")

    >>> client.download("/user/data/remote_file.csv", "local_file.csv")
    >>> dataset = client.read_parquet_table("/user/data/parquet_files")
    """

    host: str = "default"

    def __post_init__(self) -> None:
        """Configure the HDFS environment variables required by the HDFS CLI.

        Notes
        -----
        Sets ``CLASSPATH`` via ``hdfs classpath`` and configures
        ``HADOOP_OPTS`` with the Cloudera cluster trust-store path and
        password.
        """
        LOGGER.debug("setting env variable for hdfs client")
        os.environ["CLASSPATH"] = os.popen("hdfs classpath").read().strip()
        os.environ["HADOOP_OPTS"] = (
            "-Djavax.net.ssl.trustStore="
            "/var/lib/cloudera-scm-agent/agent-cert/cm-auto-global_truststore.jks "
            "-Djavax.net.ssl.trustStorePassword=Sbi@123"
        )

    @property
    def hdfs_filesystem(self) -> fs.HadoopFileSystem:
        """Get a PyArrow :class:`~pyarrow.fs.HadoopFileSystem` instance.

        Returns
        -------
        fs.HadoopFileSystem
            Configured HadoopFileSystem for HDFS operations.

        Examples
        --------
        >>> client = HDFSClient()
        >>> file_info = client.hdfs_filesystem.get_file_info("/user/data")
        """
        config: dict[str, str] = {
            "ssl.client.truststore.location": (
                "/var/lib/cloudera-scm-agent/agent-cert/cm-auto-global_truststore.jks"
            ),
            "ssl.client.truststore.password": "Sbi@123",
            "ssl.client.truststore.type": "jks",
            "hadoop.rpc.socket.factory.class.default": (
                "org.apache.hadoop.net.StandardSocketFactory"
            ),
        }
        return fs.HadoopFileSystem(host=self.host, extra_conf=config)

    def list_files(self, path: str) -> list[fs.FileInfo]:
        """List all files in the specified HDFS path recursively.

        Parameters
        ----------
        path : str
            HDFS path to list files from.

        Returns
        -------
        list of fs.FileInfo
            List of :class:`~pyarrow.fs.FileInfo` objects containing file metadata.

        Examples
        --------
        >>> client = HDFSClient()
        >>> for f in client.list_files("/user/data"):
        ...     print(f"{f.path}: {f.size} bytes")
        """
        selector = fs.FileSelector(path, recursive=True)
        return list(self.hdfs_filesystem.get_file_info(selector))

    def upload(
        self, source_path: str, destination_path: str, overwrite: bool = True
    ) -> None:
        """Upload a file from the local filesystem to HDFS.

        Parameters
        ----------
        source_path : str
            Local file path to upload.
        destination_path : str
            HDFS destination path.
        overwrite : bool, optional
            When ``True`` (default), overwrite an existing file at the destination.

        Notes
        -----
        Uses the HDFS CLI (``hdfs dfs -put``) rather than the PyArrow filesystem
        due to current authentication limitations with PyArrow on this cluster.

        Examples
        --------
        >>> client = HDFSClient()
        >>> client.upload("local_data.csv", "/user/data/remote_data.csv")
        >>> client.upload("model.pkl", "/user/models/model.pkl", overwrite=False)
        """

            subprocess.run(
                ["hdfs", "dfs", "-put", "-f", source_path, destination_path],
                check=False,
            )
        else:
            subprocess.run(
                ["hdfs", "dfs", "-put", source_path, destination_path], check=False
            )

        Parameters

        source_path : str

        >>> client.download("/user/models/model.pkl", "./models/model.pkl")

    def load_model_sentence_transformer(
        self, model_path: str, **kwargs: object
    ) -> object:
        """Load a SentenceTransformer model from HDFS.

        Downloads the model from HDFS to a temporary directory and loads it
        using the ``sentence-transformers`` library.

        Parameters

        model_path : str
            HDFS path to the SentenceTransformer model directory.
        **kwargs : object
            Additional keyword arguments forwarded to the

        Returns
        -------
        object
            Loaded :class:`~sentence_transformers.SentenceTransformer` model instance.

        Raises
        ------
        ImportError
            When the ``sentence-transformers`` library is not installed.

        Notes
        -----
        The model is downloaded to a temporary directory which is automatically

        try:
            from sentence_transformers import (

        except ImportError as exc:
            raise ImportError(

            self.download(model_path, local_model_path)

                    model = SentenceTransformer(
                        local_model_path, trust_remote_code=True, **kwargs

                else:
                    raise

def truncate(text: str, max_len: int = 300, suffix: str = "…") -> str:
    """Shorten *text* to *max_len* characters and append *suffix* if it was cut.

    Parameters
    ----------
    text : str
        Input string to truncate.
    max_len : int, optional
        Maximum length of the returned string (including suffix).
        Defaults to ``300``.
    suffix : str, optional
        String appended when truncation occurs. Defaults to ``"…"``.

    Returns
    -------
    str
        Truncated (or original) string.
    """
    if len(text) <= max_len:
        return text
    return text[: max_len - len(suffix)] + suffix


def normalise_whitespace(text: str) -> str:
    """Collapse any run of whitespace (spaces, tabs, newlines) into a single space.

    Parameters
    ----------
    text : str
        Input string to normalise.

    Returns
    -------
    str
        String with all whitespace runs replaced by a single space and leading /
        trailing whitespace stripped.
    """
    return re.sub(r"\s+", " ", text).strip()


def flatten_list(nested: list[Any]) -> list[Any]:
    """Flatten exactly one level of nesting in a list.

    Parameters
    ----------
    nested : list of Any
        Potentially nested list.

    Returns
    -------
    list of Any
        Flattened list with one level of nesting removed.

    Examples
    --------
    >>> flatten_list([[1, 2], [3], 4])
    [1, 2, 3, 4]
    """
    result: list[Any] = []
    for item in nested:
        if isinstance(item, list):
            result.extend(item)
        else:
            result.append(item)
    return result

def safe_delete(path: str | Path) -> bool:
    """Delete a file or entire directory tree without raising if it does not exist.

    Parameters
    ----------
    path : str or Path
        File or directory to delete.

    Returns
    -------
    bool
        ``True`` if something was deleted, ``False`` if the path was already gone.
    """
    target = Path(path)
    if not target.exists():
        return False
    if target.is_dir():
        shutil.rmtree(target)
    else:
        target.unlink()
    return True


def list_files(
    directory: str | Path,
    pattern: str = "*",
    recursive: bool = False,
) -> list[Path]:
    """Return a sorted list of files matching *pattern* inside *directory*.

    Parameters
    ----------
    directory : str or Path
        Root directory to search.
    pattern : str, optional
        Glob pattern to match against file names. Defaults to ``"*"``.
    recursive : bool, optional
        When ``True``, search all subdirectories as well. Defaults to ``False``.

    Returns
    -------
    list of Path
        Sorted list of matching file paths.
    """
    root = Path(directory)
    globber = root.rglob if recursive else root.glob
    return sorted(p for p in globber(pattern) if p.is_file())


def file_size(path: str | Path) -> int:
    """Return the byte size of a file, or ``0`` if the file does not exist.

    Parameters
    ----------
    path : str or Path
        Path to the file.

    Returns
    -------
    int
        File size in bytes, or ``0`` when the file is absent.
    """
    target = Path(path)
    return target.stat().st_size if target.exists() else 0


def resolve_project_path(*parts: str) -> Path:
    """Build an absolute path relative to the project root.

    The project root is resolved as two levels above this file
    (``utils/ → dlh_ai/ → src/`` … i.e. the ``src/dlh_ai`` parent).

    Parameters
    ----------
    *parts : str
        Path components to join onto the project root.

    Returns
    -------
    Path
        Absolute path composed of the project root and *parts*.

    Examples
    --------
    >>> resolve_project_path("data", "comp_db", "COMP_REPORTS.db")
    PosixPath('/…/src/dlh_ai/data/comp_db/COMP_REPORTS.db')
    """
    project_root = Path(__file__).resolve().parents[1]
    return project_root.joinpath(*parts)


_JSON_OBJECT_PATTERN: re.Pattern[str] = re.compile(r"(\{.*?\}|\[.*?\])", re.DOTALL)


def safe_loads(text: str) -> Any:
    """Parse *text* as JSON; return ``None`` instead of raising on bad input.

    Parameters
    ----------
    text : str
        Raw string to parse.

    Returns
    -------
    Any
        Parsed Python object, or ``None`` when the input is not valid JSON.
    """
    try:
        return json.loads(text)
    except (json.JSONDecodeError, TypeError):
        return None


def safe_dumps(obj: Any, indent: int = 2, default: Any = str) -> str:
    """Serialise *obj* to JSON, converting un-serialisable values with ``str()``.

    Parameters
    ----------
    obj : Any
        Python object to serialise.
    indent : int, optional
        Number of spaces for indentation. Defaults to ``2``.
    default : Any, optional
        Fallback serialiser for objects that are not JSON-serialisable.
        Defaults to :class:`str`.

    Returns
    -------
    str
        JSON-encoded string.
    """
    return json.dumps(obj, indent=indent, default=default, ensure_ascii=False)


def extract_json_from_text(text: str) -> Any:
    """Scan free-form text for the first valid JSON object or array and return it.

    Useful when the LLM wraps its JSON answer in explanatory prose.

    Parameters
    ----------
    text : str
        Free-form text that may contain embedded JSON.

    Returns
    -------
    Any
        First valid parsed JSON value found in *text*, or ``None`` when no
        valid JSON block is present.
    """
    for match in _JSON_OBJECT_PATTERN.finditer(text):
        parsed = safe_loads(match.group(0))
        if parsed is not None:
            return parsed
    return None


def extract_json_array(text: str) -> list[Any]:
    """Return the first JSON array found in *text*, or ``[]`` if none exists.

    Parameters
    ----------
    text : str
        Free-form text that may contain an embedded JSON array.

    Returns
    -------
    list of Any
        Parsed array, or an empty list when none is found.
    """
    result = extract_json_from_text(text)
    if isinstance(result, list):
        return result
    return []


def extract_json_object(text: str) -> dict[str, Any]:
    """Return the first JSON object found in *text*, or ``{}`` if none exists.

    Parameters
    ----------
    text : str
        Free-form text that may contain an embedded JSON object.

    Returns
    -------
    dict of str to Any
        Parsed object, or an empty dict when none is found.
    """
    result = extract_json_from_text(text)
    if isinstance(result, dict):
        return result
    return {}


def pretty_print(obj: Any) -> str:
    """Return a nicely indented JSON string for *obj*.

    Parameters
    ----------
    obj : Any
        Python object to format.

    Returns
    -------
    str
        Pretty-printed JSON string with two-space indentation.
    """
    return safe_dumps(obj, indent=2)


def is_valid_json(text: str) -> bool:
    """Return ``True`` if *text* is syntactically valid JSON, ``False`` otherwise.

    Parameters
    ----------
    text : str
        String to validate.

    Returns
    -------
    bool
        ``True`` when *text* parses as valid JSON.
    """
    return safe_loads(text) is not None

"""
utils/registry.py — data-access registries: databases, prompts, and SQLite helpers.

Three responsibilities:

* **Database registry** — parses the ``[databases]`` section of the
  project-root ``config.toml`` and builds a flat
  ``{table_name: metadata}`` lookup used by the NL2SQL agents.
* **Read-only SQLite helpers** — ``open_readonly``, ``fetch_all``,
  ``fetch_scalar``, ``list_tables``, ``table_exists``, ``get_column_names``,
  ``row_count``.
* **YAML prompt loader** — loads and caches prompt template files from
  ``genai/prompt/``.

All three share the same concern: reading persistent stores (TOML / SQLite /
YAML) and caching the results in memory to avoid repeated I/O.
"""

import contextlib
import logging
import sqlite3
from collections.abc import Generator
from contextlib import contextmanager
from pathlib import Path
from typing import Any

import yaml

LOGGER = logging.getLogger("dlh_ai")


def _load_toml_file(path: Path) -> dict[str, Any]:
    """Open and parse a TOML file; return {} on any failure."""
    try:
        try:
            import tomllib  # built-in Python 3.11+
        except ImportError:
            import tomli as tomllib  # type: ignore[no-redef]
        with path.open("rb") as fh:
            return tomllib.load(fh)
    except Exception as exc:  # noqa: BLE001
        LOGGER.warning("registry._load_toml_file — failed to load %s: %s", path, exc)
        return {}


# config.toml lives at src/config.toml — two levels above src/dlh_ai/utils/:
#   src/dlh_ai/utils/registry.py  →  parents[2]  =  src/  →  src/config.toml
_CONFIG_TOML: Path = Path(__file__).resolve().parents[2] / "config.toml"

_db_registry: dict[str, Any] | None = None


def _build_db_registry() -> dict[str, Any]:
    """Parse the ``[databases]`` section of ``config.toml`` and return a flat
    ``{table_name: metadata}`` dict.
    """
    if not _CONFIG_TOML.exists():
        LOGGER.warning("registry: config.toml not found at %s", _CONFIG_TOML)
        return {}

    raw = _load_toml_file(_CONFIG_TOML)
    registry: dict[str, Any] = {}

    for db_stem, db_data in raw.get("databases", {}).items():
        db_file = db_data.get("db_file", "")
        for table_name, table_data in db_data.get("tables", {}).items():
            few_shots_raw = table_data.get("few_shots", {})
            few_shots_str = (
                few_shots_raw.get("examples", "").strip()
                if isinstance(few_shots_raw, dict)
                else ""
            )
            registry[table_name] = {
                "db_stem": db_stem,
                "db_file": db_file,
                "description": table_data.get("description", ""),
                "filter_query": table_data.get("filter_query", ""),
                "columns": table_data.get("columns", {}),
                "few_shots": few_shots_str,
            }
            LOGGER.debug("registry: registered table %s (db=%s)", table_name, db_stem)

    LOGGER.info("registry: loaded %d table(s) from databases.toml", len(registry))
    return registry


def _get_db_registry() -> dict[str, Any]:
    """Return the cached registry, building it on first call."""
    global _db_registry
    if _db_registry is None:
        _db_registry = _build_db_registry()
    return _db_registry


def reload() -> None:
    """Clear the database registry cache so the next access re-reads databases.toml."""
    global _db_registry
    _db_registry = None
    LOGGER.info("registry: db cache cleared — will reload on next access.")


def get_table_meta(table_name: str) -> dict[str, Any]:
    """Return the full metadata dict for a registered table, or {} if unknown."""
    return _get_db_registry().get(table_name, {})


def get_few_shots(table_name: str) -> str:
    """Return the few-shot example block for a table, or '' if not registered."""
    return _get_db_registry().get(table_name, {}).get("few_shots", "")


def get_all_tables() -> list[str]:
    """Return a sorted list of every registered table name."""
    return sorted(_get_db_registry().keys())


def list_databases() -> list[str]:
    """Return a sorted list of every registered database stem name."""
    reg = _get_db_registry()
    return sorted({meta["db_stem"] for meta in reg.values()})


@contextmanager
def open_readonly(db_path: str | Path) -> Generator[sqlite3.Connection, None, None]:
    """
    Context manager: open a SQLite file in deferred read-only mode.

    Always rolls back and closes the connection on exit — even on error.
    Usage:
        with open_readonly("data/comp_db/COMP_REPORTS.db") as conn:
            rows = conn.execute("SELECT COUNT(*) FROM COMP_TBL").fetchone()
    """
    path = Path(db_path)
    conn: sqlite3.Connection | None = None
    try:
        conn = sqlite3.connect(str(path), check_same_thread=False)
        conn.row_factory = sqlite3.Row
        conn.execute("BEGIN DEFERRED")
        yield conn
    finally:
        if conn is not None:
            with contextlib.suppress(sqlite3.Error):
                conn.rollback()
            conn.close()


def fetch_all(
    db_path: str | Path,
    sql: str,
    params: tuple[Any, ...] = (),
) -> list[dict[str, Any]]:
    """Run sql and return every result row as a list of {column: value} dicts."""
    with open_readonly(db_path) as conn:
        cursor = conn.execute(sql, params)
        col_names: list[str] = [d[0] for d in (cursor.description or [])]
        return [dict(zip(col_names, row, strict=False)) for row in cursor.fetchall()]


def fetch_scalar(
    db_path: str | Path,
    sql: str,
    params: tuple[Any, ...] = (),
    default: Any = None,
) -> Any:
    """Run sql and return just the first column of the first row (e.g. COUNT(*))."""
    with open_readonly(db_path) as conn:
        row = conn.execute(sql, params).fetchone()
    return row[0] if row else default


def list_tables(db_path: str | Path) -> list[str]:
    """Return a sorted list of all table names in the database."""
    sql = "SELECT name FROM sqlite_master WHERE type='table' ORDER BY name"
    with open_readonly(db_path) as conn:
        rows = conn.execute(sql).fetchall()
    return [row[0] for row in rows]


def table_exists(db_path: str | Path, table_name: str) -> bool:
    """Return True if table_name exists in the database (case-insensitive check)."""
    sql = "SELECT 1 FROM sqlite_master WHERE type='table' AND UPPER(name)=UPPER(?)"
    return fetch_scalar(db_path, sql, (table_name,)) is not None


def get_column_names(db_path: str | Path, table_name: str) -> list[str]:
    """Return the ordered column names for a table via PRAGMA table_info."""
    with open_readonly(db_path) as conn:
        rows = conn.execute(f"PRAGMA table_info('{table_name}')").fetchall()
    return [row[1] for row in rows]


def row_count(db_path: str | Path, table_name: str) -> int:
    """Return how many rows are in the table; returns 0 on any error."""
    try:
        return fetch_scalar(db_path, f"SELECT COUNT(*) FROM '{table_name}'", default=0)  # noqa: S608
    except sqlite3.Error as err:
        LOGGER.warning(
            "registry.row_count — error on %s.%s: %s", db_path, table_name, err
        )
        return 0


_PROMPTS_DIR: Path = Path(__file__).resolve().parents[1] / "genai" / "prompt"

_prompt_cache: dict[str, dict[str, Any]] = {}


def _load_yaml_file(path: Path) -> dict[str, Any]:
    """Open and parse a YAML file; return {} on any failure."""
    try:
        with path.open("r", encoding="utf-8") as fh:
            return yaml.safe_load(fh) or {}
    except Exception as exc:  # noqa: BLE001
        LOGGER.warning("registry._load_yaml_file — failed to load %s: %s", path, exc)
        return {}


def load_prompt(filename: str) -> dict[str, Any]:
    """
    Load and cache a YAML prompt file from genai/prompt/.

    filename — e.g. "sql_writer.yaml" (or bare stem "sql_writer")
    Returns the full parsed dict, or {} on error.
    Raises FileNotFoundError if the file does not exist.
    """
    stem = filename.removesuffix(".yaml").removesuffix(".toml")

    if stem in _prompt_cache:
        return _prompt_cache[stem]

    path = _PROMPTS_DIR / (stem + ".yaml")
    if not path.exists():
        raise FileNotFoundError(f"Prompt file not found: {path}")

    data = _load_yaml_file(path)
    _prompt_cache[stem] = data
    LOGGER.debug("registry: loaded prompt file: %s", path)
    return data


def get_prompt(filename: str, *keys: str, default: str | None = None) -> str | None:
    """
    Retrieve a nested string value from a YAML prompt file.

    Example: get_prompt("intent_checker.yaml", "messages", "clarification")

    Walks the key path and returns the string at that location,
    or default if any key is missing.
    """
    data = load_prompt(filename)
    node: Any = data
    for key in keys:
        if not isinstance(node, dict):
            return default
        node = node.get(key)
        if node is None:
            return default
    return str(node) if node is not None else default
