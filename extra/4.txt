# How to Run - YONO Retail RAG Chatbot

This guide covers every way to start the application: backend only, UI only, or both together via the Launcher.

---

## Prerequisites

| Requirement | Minimum | Notes |
|---|---|---|
| Python | 3.11+ | Check with `python --version` |
| pip | latest | `pip install --upgrade pip` |
| Elasticsearch | 8.x or 9.x | Must be reachable from your machine |
| HDFS access | - | Required for loading the embedding model at startup |
| DLH vLLM endpoint | - | `http://10.190.236.15:9000/api/v1` or equivalent |
| SBI internal network | - | VPN / intranet required |

---

## 1. Install Dependencies

### Option A - pip (recommended)

```bash
# From the project root (v1/)
pip install -r requirements.txt
```

### Option B - editable install (development)

```bash
pip install -e .
# Also install dev tools (ruff, pytest, pyrefly)
pip install -e ".[dev]"
```

---

## 2. Configure Environment

Copy the example env file and fill in your secrets:

```bash
cp .env.example .env
```

Open `.env` and set at minimum:

```bash
# Required - Elasticsearch API key
RAG__ELASTICSEARCH_API_KEY=<your-elasticsearch-api-key>

# Required - DLH LLM API key (use EMPTY for unauthenticated endpoints)
LLM__API_KEY=EMPTY
```

All other settings have defaults in `src/config.toml`. Override them in `.env` if needed:

```bash
# Optional overrides
RAG__ELASTICSEARCH_HOST=https://uateladata02.dlhdevuat.sbi.bank.in:9201/
LLM__BASE_URL=http://10.190.236.15:9000/api/v1
LLM__MODEL_NAME=gemma-4-26b-a4b-it
LOGGING__LOG_LEVEL=INFO
```

> **Never commit `.env` to version control.** It is already listed in `.gitignore`.

---

## 3. Set PYTHONPATH

The `dlh_ai` package lives under `src/`. Add it to your Python path before running anything:

**Linux / macOS:**
```bash
export PYTHONPATH=src:$PYTHONPATH
```

**Windows (PowerShell):**
```powershell
$env:PYTHONPATH = "src;$env:PYTHONPATH"
```

---

## 4. Run Method A - Backend Only (FastAPI)

Use this when you want to test the API without the Gradio UI, or use the built-in HTML frontend.

```bash
uvicorn dlh_ai.genai.application.backend.main:app \
    --host 0.0.0.0 \
    --port 8008 \
    --reload
```

**Windows PowerShell:**
```powershell
uvicorn dlh_ai.genai.application.backend.main:app --host 0.0.0.0 --port 8008 --reload
```

Once running:

| URL | Description |
|---|---|
| `http://localhost:8008/` | Static HTML chatbot frontend |
| `http://localhost:8008/health` | Health check - returns `{"status":"ok"}` |
| `http://localhost:8008/docs` | Swagger UI - interactive API explorer |
| `http://localhost:8008/redoc` | ReDoc API documentation |
| `http://localhost:8008/api/v1/chat` | Chat endpoint (POST) |

**First-time only - ingest the knowledge base:**
```bash
curl -X POST http://localhost:8008/api/v1/admin/ingest
```

---

## 5. Run Method B - Gradio UI Only

Use this when the backend is already running elsewhere and you only want the Gradio interface.

```bash
# Point the UI at your running backend
export CB_BACKEND_URL=http://127.0.0.1:8008
export CDSW_APP_PORT=8100

python src/dlh_ai/genai/application/ui.py
```

**Windows PowerShell:**
```powershell
$env:CB_BACKEND_URL = "http://127.0.0.1:8008"
$env:CDSW_APP_PORT = "8100"
python src/dlh_ai/genai/application/ui.py
```

Open `http://localhost:8100` in your browser.

---

## 6. Run Method C - Both Together via Launcher (Recommended)

The Launcher starts the FastAPI backend and the Gradio UI as separate processes, wires them together, and monitors both. Press `Ctrl+C` to stop both cleanly.

```bash
python src/dlh_ai/genai/application/Launcher.py
```

The Launcher will:
1. Check that `backend/main.py` and `ui.py` exist.
2. Start the FastAPI backend on port `8008` (default).
3. Wait 10 seconds for the backend to finish loading the embedding model.
4. Start the Gradio UI on port `8100` (default).
5. Print the URLs and monitor both processes.

Expected output:
```
 Checking environment...

 Starting YONO Retail Chatbot Suite
============================================================
 Launching Backend (FastAPI) on port 8008...
 Waiting 10 seconds for backend to initialise...
 Launching UI (Gradio) on port 8100...

============================================================
 YONO RETAIL CHATBOT - SYSTEMS STARTED
  Backend API : http://127.0.0.1:8008
  API Docs    : http://127.0.0.1:8008/docs
  Frontend UI : http://127.0.0.1:8100
============================================================

 Open the Frontend UI link above (or the CML app link) to use the chatbot.
 Press Ctrl+C to stop both servers.
```

### Override ports (optional)

```bash
# Linux / macOS
CB_BACKEND_PORT=9000 CDSW_APP_PORT=9001 python src/dlh_ai/genai/application/Launcher.py

# Windows PowerShell
$env:CB_BACKEND_PORT = "9000"
$env:CDSW_APP_PORT = "9001"
python src/dlh_ai/genai/application/Launcher.py
```

---

## 7. Run Method D - Production (Gunicorn + Uvicorn Workers)

For production deployments, use Gunicorn with multiple Uvicorn worker processes:

```bash
gunicorn dlh_ai.genai.application.backend.main:app \
    -k uvicorn.workers.UvicornWorker \
    --workers 4 \
    --bind 0.0.0.0:8008 \
    --timeout 120
```

> Gunicorn is not included in `requirements.txt` by default. Install it with: `pip install gunicorn`

---

## 8. Ingest the Knowledge Base

The knowledge base must be ingested into Elasticsearch before the chatbot can answer questions. This is a one-time operation (or re-run whenever the CSV is updated).

**Via curl:**
```bash
curl -X POST http://localhost:8008/api/v1/admin/ingest
```

**Via Python:**
```python
import httpx
r = httpx.post("http://localhost:8008/api/v1/admin/ingest")
print(r.json())
# {"total_rows": 1039, "successful": 1039, "failed": 0}
```

## 11. Troubleshooting

**Backend fails to start - `ModuleNotFoundError: No module named 'dlh_ai'`**
```bash
# Make sure PYTHONPATH includes src/
export PYTHONPATH=src:$PYTHONPATH
```

**Elasticsearch connection refused**
- Confirm `RAG__ELASTICSEARCH_HOST` and `RAG__ELASTICSEARCH_API_KEY` are set correctly in `.env`.
- Check VPN / intranet connectivity to the Elasticsearch cluster.

**Embedding model load fails**
- Confirm HDFS is accessible and the model path in `src/config.toml` is correct.
- Check `logs/app.log` for the full traceback.

**`Backend not responding` warning in Launcher**
- The backend may still be loading the embedding model (can take 30-60 seconds on first start).
- Check the backend terminal window for errors.

**UI shows `Backend Offline` badge**
- The Gradio UI cannot reach `CB_BACKEND_URL`. Make sure the backend is running and the URL is correct.

# YONO Retail RAG Chatbot

> **Enterprise-grade Retrieval-Augmented Generation chatbot for the YONO Retail digital banking platform — State Bank of India.**
> Designed to handle **10 million concurrent users** via Elasticsearch kNN vector search, DLH self-hosted Gemma-4 LLM, and a FastAPI async backend.

---

## Overview

YONO Retail Assistant answers customer banking questions by retrieving the most relevant passages from a structured FAQ knowledge base and synthesising a coherent answer using the DLH self-hosted Gemma-4-26b language model.

```
Customer query
    │
    ▼  encode (all-MiniLM-L12-v2 · 384-dim)
    │
    ▼  kNN search  ─────► Elasticsearch
    │                     yono_retail_knowledge_base
    ▼  render (Jinja2 prompts)
    │
    ▼  generate ──────────► DLH vLLM  (Gemma-4-26b-a4b-it)
    │
    ▼
ChatResponse  ──────────► Browser SPA
```

---

## Features

| Capability | Detail |
|---|---|
| **RAG Pipeline** | 4-step: encode → kNN search → prompt render → LLM generate |
| **Vector Search** | Elasticsearch 8.x kNN cosine similarity (384-dim dense vectors) |
| **Hybrid Search** | kNN + BM25 combined for improved recall on uncommon terms |
| **Embedding Model** | `all-MiniLM-L12-v2` (384-dim) loaded from HDFS at startup |
| **LLM** | DLH self-hosted Gemma-4-26b-a4b-it via OpenAI-compatible vLLM API |
| **Backend** | FastAPI + Uvicorn, async with `run_in_executor` for blocking I/O |
| **Frontend** | Full-window dark enterprise SPA — confidence bar, sources accordion, suggestion chips |
| **Config** | `pydantic-settings` — env vars → `.env` → `config.toml` → defaults |
| **Logging** | `rich` RichHandler (console) + rotating `FileHandler` (`logs/app.log`) |
| **Scale** | Gunicorn multi-worker + Nginx reverse proxy for horizontal scale |
| **Standards** | NumPy docstrings · type hints · Ruff lint · Pyrefly type checking |

---

## Prerequisites

| Requirement | Minimum |
|---|---|
| Python | ≥ 3.11 |

| HDFS access | `/dev/aiml/models/sentence-transformers/…` |
| DLH vLLM endpoint | `http://10.190.236.15:9000/api/v1` (or equivalent) |
| Network | SBI internal VPN / intranet access |

class Settings(BaseSettings):
    """Application settings loaded from env vars, .env, and config.toml.

    Nested fields can be overridden from environment variables by using the
    ``env_nested_delimiter="__"`` separator.

    Environment variable examples
    -----------------------------
    * ``COMMON__PROJECT_ID=yono-chatbot-prod``
    * ``RAG__ELASTICSEARCH_HOST=https://host:9201``
    * ``RAG__ELASTICSEARCH_API_KEY=<secret-key>``   ← required, set in .env
    * ``RAG__VERIFY_CERTS=true``
    * ``LLM__API_KEY=EMPTY``                        ← required, set in .env
    * ``LLM__BASE_URL=http://10.190.236.15:9000/api/v1``
    * ``LLM__MODEL_NAME=gemma-4-26b-a4b-it``
    * ``LOGGING__LOG_LEVEL=INFO``

    Priority order (highest → lowest)
    ----------------------------------
    1. Environment variables
    2. ``.env`` file
    3. ``config.toml`` defaults
    4. Constructor arguments
    """

    common: Common
    data: Data
    training: Training
    inference: Inference
    rag: RagSettings = Field(default_factory=RagSettings)
    llm: LlmSettings = Field(default_factory=LlmSettings)
    logging: LoggingSettings = Field(default_factory=LoggingSettings)

    model_config = SettingsConfigDict(env_nested_delimiter="__")

    @classmethod
    def settings_customise_sources(
        cls,
        settings_cls: type[BaseSettings],
        init_settings: PydanticBaseSettingsSource,
        env_settings: PydanticBaseSettingsSource,
        dotenv_settings: PydanticBaseSettingsSource,
        file_secret_settings: PydanticBaseSettingsSource,
    ) -> tuple[PydanticBaseSettingsSource, ...]:
        """Define settings source priority.

        Returns
        -------
        tuple[PydanticBaseSettingsSource, ...]
            Ordered tuple of sources from highest to lowest priority.
        """
        return (
            env_settings,           # 1st priority — environment variables
            dotenv_settings,        # 2nd priority — .env file
            TomlConfigSettingsSource(settings_cls),  # 3rd priority — config.toml
            init_settings,          # 4th priority — constructor kwargs
        )

    def save_as_toml(self) -> None:
        """Persist current settings back to the TOML configuration file.

        Raises
        ------
        KeyError
            Raised when ``toml_file`` is not set in ``model_config``.
        OSError
            Raised when the file cannot be written due to permission or
            disk-space issues.
        """
        import toml  # noqa: PLC0415 — optional dependency, imported lazily

        _file: Any = self.model_config.get("toml_file")
        if not _file:
            raise KeyError(
                "Settings.save_as_toml() requires 'toml_file' to be set in "
                "model_config before calling. Use get_settings() to initialise."
            )
        with open(_file, "w", encoding="utf-8") as f:
            toml.dump(self.model_dump(), f)


# Helpers


def ensure_config_env(config_path: Path | str | None = None) -> Path:
    """Resolve and validate the configuration file path.

    Parameters
    ----------
    config_path : pathlib.Path or str or None, optional
        Path to ``config.toml``. When ``None``, defaults to
        ``<project_root>/src/config.toml``.

    Returns
    -------
    pathlib.Path
        Resolved absolute path to the configuration file.

    Raises
    ------
    FileNotFoundError
        Raised when the resolved path does not point to an existing file.

    Examples
    --------
    >>> path = ensure_config_env()
    >>> print(path)
    /workspace/src/config.toml
    """
    if not config_path:
        # Default: two levels up from this file → project root / src / config.toml
        p = Path(__file__).parent.parent / "config.toml"
    else:
        p = Path(config_path)

    if p.is_file():
        return p.resolve()

    raise FileNotFoundError(
        f"Configuration file not found at '{p.resolve()}'. "
        "Ensure 'src/config.toml' exists or pass an explicit path to get_settings()."
    )

    @property
    def cursor(self):
        """Property to get a database cursor for executing queries
        NOTE - This will create a new connection & manually it must be closed after use.
        """
        # TODO - check if this is needed or if we can just use self._create_connection.get_cursor()
        conn = self._create_connection()
        return conn.get_cursor()

    def read_table(self, query: str) -> pd.DataFrame:
        """Read a Iceberg table on Hive OCP into a Pandas DataFrame using provided sql query

        Parameters
        ----------
        query : str
            SQL query to read the table

        Returns
        -------
        pd.DataFrame
            Pandas DataFrame containing the data from the specified SQL table
        """
        # verifying the read query
        self._verify_sql_query(query)

        with self._create_connection() as base_conn:
            with base_conn.cursor() as cursor:
                logger.debug("Executing query to read the table")
                from impala.util import as_pandas

                cursor.execute(query)
                data = as_pandas(cursor)
                logger.info(f"Successfully read {len(data)} rows")

        # NOTE - reading from 'Hive on Tez' also add table name as prefix to column names,
        # so we remove it here for consistency with other engines
        return data.rename(
            columns={col: col.upper().split(".")[-1] for col in data.columns}
        )

    def read_csv_from_hdfs(self, path: str) -> pd.DataFrame:
        data = self.hdfs_client.read_csv_file(path)
        return data.to_table().to_pandas(
            split_blocks=True,
            self_destruct=True,  # frees Arrow buffers after conversion
            zero_copy_only=False,
        )

    def read_parquet_from_hdfs(self, path: str) -> pd.DataFrame:
        data = self.hdfs_client.read_parquet_table(path)
        return data.to_table().to_pandas(
            split_blocks=True,
            self_destruct=True,  # frees Arrow buffers after conversion
            zero_copy_only=False,
        )

    def save_table(
        self,
        df: pd.DataFrame,
        name: str,
        mode: Literal["overwrite", "append", "ignore", "error"] = "append",
        batch_size: int = 5000,
    ):
        """Function to insert data from a Pandas DataFrame into a Iceberg table

        Parameters
        ----------
        df : pd.DataFrame
            table data in the form of pandas dataframe
        name : str
            table name to write/append DEPRECATED -
        mode : Literal["overwrite", "append", "ignore", "error"], optional
            how to write data, by default "append"
        """
        if mode != "append":
            raise NotImplementedError(
                f"Mode '{mode}' not yet implemented for Pandas Engine"
            )
        # Prepare Query with Backticks
        # NOTE - splitting by '.' to backtick the schema and table separately: `db`.`table`
        if "." in name:
            db, tbl = name.split(".")
            formatted_table_name = f"`{db}`.`{tbl}`"
        else:
            formatted_table_name = f"`{name}`"

        # Backtick every column name to be safe
        col_names = ", ".join([f"`{c.split('.')[-1]}`" for c in df.columns])
        placeholders = ", ".join(["%s"] * len(df.columns))

        insert_sql_query = (
            f"INSERT INTO {formatted_table_name} ({col_names}) VALUES ({placeholders})"
        )

        no_of_batches = self._calculate_batch_size(df, batch_size)
        logger.info(
            f"Starting to load data into {name} in batches of {batch_size} with total batches: {no_of_batches}"
        )

        with self._create_connection() as base_conn:
            with base_conn.cursor() as cursor:
                try:
                    # cursor loop
                    for idx, offset in enumerate(
                        range(0, len(df), batch_size), start=1
                    ):
                        batch = df.iloc[offset : offset + batch_size]
                        logger.debug(f"inserting batch {idx}: out of {no_of_batches}")
                        cursor.executemany(
                            insert_sql_query, batch.to_dict(orient="records")
                        )
                        logger.debug(
                            f"successfully inserted batch {idx} with {len(batch)} rows."
                        )

                    logger.info(f"Successfully loaded {len(df)} rows.")
                except Exception as e:
                    logger.error(f"SQL Error: {insert_sql_query}")
                    logger.error(f"Details: {e}")
                    # FIXME - use precise exception chaining rather than generic. then use it below with `from e`
                    # raise from e
                    raise  # this is temporary until we fix the above

    def save_csv_to_hdfs(
        self,

    ):

        """

        with tempfile.TemporaryDirectory() as temp_dir:
            df.to_csv(f"{temp_dir}/data.csv", **kwargs)
            self.upload(f"{temp_dir}/data.csv", path)
        logger.info(f"saved pandas dataframe to HDFS at {path}")

    def save_parquet(self, df: pd.DataFrame, path: str, **kwargs):
        """Save a pandas DataFrame as a Parquet file to HDFS.

        Parameters
        ----------
        df : pd.DataFrame
            The DataFrame to save.
        path : str
            The HDFS path where the Parquet file will be saved.
        **kwargs : dict
            Additional keyword arguments to pass to `pd.DataFrame.to_parquet()`.

        # REVIEW - Check if instead of local copy, we can directly use pyarrow table to write to hdfs
        with tempfile.TemporaryDirectory() as temp_dir:
            df.to_parquet(f"{temp_dir}/data.parquet", **kwargs)
            self.upload(f"{temp_dir}/data.parquet", path)
        logger.info(f"saved pandas dataframe to HDFS at {path}")

    @retry(
        stop=stop_after_attempt(5),
        wait=wait_exponential(multiplier=1, max=10),
        retry=retry_if_exception_type(Exception),
        reraise=True,
        before_sleep=before_sleep_log(logger, logging.WARNING),
    )
    def _create_connection(self):
        """Attempt to create and return the DB base connection (with retries)."""
        # TODO - we should explore connection pooling or reuse to avoid the overhead of creating

        # if not hasattr(self, "_base_conn") or self._base_conn is None:
        self._base_conn = cmldata.get_connection(self.connection_name)

        return self._base_conn.get_base_connection()

import logging
from dataclasses import dataclass
from datetime import datetime
from typing import Literal
from zoneinfo import ZoneInfo

from pyspark.sql import SparkSession
from pyspark.sql.dataframe import DataFrame
from sqlglot import parse_one

logger = logging.getLogger("dlh_ai")


@dataclass
class SparkEngine:
    """Spark-backed data access and persistence engine.

    Parameters
    ----------
    app_name_prefix : str
        Prefix used while constructing the Spark application name during
        session initialization.
    """

    app_name_prefix: str

    def __post_init__(self):
        """Initialize the Spark session for the engine instance.

        Notes
        -----
        The Spark application name is created by combining
        ``app_name_prefix`` with the current timestamp in the
        ``Asia/Kolkata`` timezone.
        """
        # FIXME - Below logic of creating spark session logic will work with
        # Notebook session because it can access default-spark.conf but not
        # with CML Jobs
        logger.debug("creating new spark session")
        sess_name = f"{self.app_name_prefix}-{datetime.now(ZoneInfo('Asia/Kolkata')).isoformat()}"
        self.spark = SparkSession.builder.appName(sess_name).getOrCreate()
        logger.debug(f"successfully created new spark session: {sess_name}")

    def read_table(self, name: str) -> DataFrame:
        """Read a table from the Spark catalog.

        Parameters
        ----------
        name : str
            Fully qualified table name to read.

        Returns
        -------
        DataFrame
            Spark DataFrame loaded from the requested table.
        """
        return self.spark.read.table(name)

    def read_csv(self, path: str) -> DataFrame:
        """Read a CSV dataset from the provided path.

        Parameters
        ----------
        path : str
            Filesystem/Ozone path from which the CSV data should be loaded.

        Returns
        -------
        DataFrame
            Spark DataFrame created from the CSV input.
        """
        return self.spark.read.format("csv").option("path", path).load()

    def read_parquet(self, path: str) -> DataFrame:
        """Read a Parquet dataset from the provided path.

        Parameters
        ----------
        path : str
            Filesystem/Ozone path from which the Parquet data should be loaded.

        Returns
        -------
        DataFrame
            Spark DataFrame created from the Parquet input.
        """
        return self.spark.read.format("parquet").option("path", path).load()

    def save_table(
        self,
        df: DataFrame,
        name: str,
        path: str,
        mode: Literal["overwrite", "append", "ignore", "error"] = "append",
    ):
        """Persist a DataFrame as an Iceberg table.

        Parameters
        ----------
        df : DataFrame
            Spark DataFrame to be written.
        name : str
            Target table name for persistence.
        path : str
            Storage path associated with the table.
        mode : {"overwrite", "append", "ignore", "error"}, default="append"
            Write mode to use while saving the table.
        """
        # TODO - extract table path automatically
        df.write.mode(mode).format("iceberg").option("path", path).saveAsTable(name)

    def merge_table(self, df: DataFrame, merge_query: str):
        """Merge a DataFrame into a target Iceberg table using a SQL MERGE statement.

        Parameters
        ----------
        df : DataFrame
            Source Spark DataFrame that will be exposed as a temporary view for
            the merge operation.
        merge_query : str
            SQL MERGE statement used to perform the upsert or merge logic.
        """
        # parsing merge query to validate syntax & extract source name for temp view
        parsed_query = parse_one(merge_query)
        source: str = parsed_query.args.get("using").name

        # creating temp view with source table name provided in merge query
        df.createOrReplaceTempView(source)
        logger.debug(f"created {source} temp view")

        self.spark.sql(merge_query)
        logger.info(
            f"successfully merged into {parsed_query.this.db}.{parsed_query.this.name}"
        )

    def save_csv(
        self,
        df: DataFrame,
        path: str,
        mode: Literal["overwrite", "append", "ignore", "error"] = "append",
    ):
        """Write a DataFrame to CSV format.

        Parameters
        ----------
        df : DataFrame
            Spark DataFrame to be written.
        path : str
            Destination filesystem path for the CSV output.
        mode : {"overwrite", "append", "ignore", "error"}, default="append"
            Write mode to use while saving the CSV data.
        """
        df.write.mode(mode).format("csv").save(path)

    def save_parquet(
        self,
        df: DataFrame,
        path: str,
        mode: Literal["overwrite", "append", "ignore", "error"] = "append",
    ):
        """Write a DataFrame to Parquet format.

        Parameters
        ----------
        df : DataFrame
            Spark DataFrame to be written.
        path : str
            Destination filesystem path for the Parquet output.
        mode : {"overwrite", "append", "ignore", "error"}, default="append"
            Write mode to use while saving the Parquet data.
        """
        df.write.mode(mode).format("parquet").save(path)

    def close_spark_session(self):
        """Closes curent active spark session"""
        self.spark.stop()

import os

def _exists_or_abort(path: Path, label: str) -> None:
    """Exit with a clear error message if *path* does not exist.

    Parameters
    ----------
    path : Path
        File to check.
    label : str
        Human-readable name used in the error message.
    """
    if not path.exists():
        print(f" X ERROR: {label} not found at {path}")
        sys.exit(1)


def launch_yono_chatbot() -> None:
    """Launch the FastAPI backend and the Gradio UI together.

    The function blocks until either:
    * The user interrupts with Ctrl+C, or
    * One of the child processes exits unexpectedly.

    Both child processes are always terminated in the ``finally`` block.
    """

    # This file is at <project_root>/src/dlh_ai/genai/application/Launcher.py
    # so the project root is five levels up from here.
    PROJECT_ROOT: Path = Path(__file__).resolve().parent.parent.parent.parent.parent

    # src/ must be on PYTHONPATH so uvicorn can import dlh_ai as a package.
    SRC_DIR: Path = PROJECT_ROOT / "src"

    # Dotted module path used by uvicorn to locate the FastAPI app object.
    BACKEND_MODULE: str = "dlh_ai.genai.application.backend.main:app"

    # Absolute path to the Gradio UI script sitting next to this file.
    UI_FILE: Path = Path(__file__).resolve().parent / "ui.py"

    # Read ports from environment so CML / Docker can override them easily.
    BACKEND_PORT: str = os.environ.get("CB_BACKEND_PORT", "8008")
    UI_PORT: str = os.environ.get("CDSW_APP_PORT", "8100")

    # Verify both entry-point files exist before spawning any processes.
    print("\n Checking environment...")
    _exists_or_abort(
        SRC_DIR / "dlh_ai" / "genai" / "application" / "backend" / "main.py",
        "Backend (main.py)",
    )
    _exists_or_abort(UI_FILE, "UI (ui.py)")

    # Copy the current environment so child processes inherit all existing vars.
    env: dict[str, str] = os.environ.copy()

    # Tell the UI where to reach the backend over localhost.
    env["CB_BACKEND_URL"] = f"http://127.0.0.1:{BACKEND_PORT}"
    env["CDSW_APP_PORT"] = UI_PORT

    existing_pythonpath: str = env.get("PYTHONPATH", "")

def _build_html() -> str:

def _check_backend() -> bool:
    """Ping the backend health endpoint and return True if healthy."""
    try:
        with urllib.request.urlopen(_HEALTH_ENDPOINT, timeout=5) as r:
            return r.status == 200
    except Exception:
        return False


def _proxy_chat(body: bytes) -> tuple[int, bytes]:
    """Forward a chat request to the FastAPI backend and return (status, body).

    Parameters
    ----------
    body : bytes
        Raw JSON request body from the browser.

    Returns
    -------
    tuple[int, bytes]
        HTTP status code and response body bytes.
    """
    req = urllib.request.Request(
        _CHAT_ENDPOINT,
        data=body,
        headers={"Content-Type": "application/json"},
        method="POST",
    )
    try:
        with urllib.request.urlopen(req, timeout=90) as resp:
            return resp.status, resp.read()
    except urllib.error.HTTPError as exc:
        return exc.code, exc.read()
    except Exception as exc:
        payload = json.dumps({"error": True, "message": f"Network error: {exc}"}).encode()
        return 502, payload


class _Handler(BaseHTTPRequestHandler):
    """Minimal HTTP request handler.

    Serves the HTML page at ``GET /`` and proxies chat/health API calls.
    """

    def log_message(self, format: str, *args: object) -> None:  # noqa: A002
        """Suppress default access log to keep the console clean."""

    def do_GET(self) -> None:
        """Handle GET requests."""
        if self.path in ("/", "/index.html"):
            self._send(200, "text/html; charset=utf-8", _PAGE)
        elif self.path == "/api/health":
            ok = _check_backend()
            payload = json.dumps({"status": "ok" if ok else "offline"}).encode()
            self._send(200, "application/json", payload)
        else:
            self._send(404, "text/plain", b"Not found")

    def do_POST(self) -> None:
        """Handle POST requests - proxy /api/chat to the FastAPI backend."""
        if self.path == "/api/chat":
            length = int(self.headers.get("Content-Length", 0))
            body = self.rfile.read(length)
            status, response_body = _proxy_chat(body)
            self._send(status, "application/json", response_body)
        else:
            self._send(404, "text/plain", b"Not found")

    def _send(self, status: int, content_type: str, body: bytes) -> None:
        """Write status line, headers, and body to the socket."""
        self.send_response(status)
        self.send_header("Content-Type", content_type)
        self.send_header("Content-Length", str(len(body)))
        self.end_headers()
        self.wfile.write(body)


def main() -> None:
    """Start the HTTP server and block until interrupted."""
    print(f"\n YONO Retail UI starting on port {_UI_PORT}...")
    print(f" Backend target: {_BACKEND_URL}")

    for attempt in range(1, 4):
        if _check_backend():
            print(" Backend health-check: OK")
            break
        print(f" Waiting for backend... (attempt {attempt}/3)")
        time.sleep(3)
    else:
        print(" WARNING: Backend not responding - UI will start anyway.")

    server = HTTPServer(("0.0.0.0", _UI_PORT), _Handler)
    print(f" UI ready at http://0.0.0.0:{_UI_PORT}")
    print(" Press Ctrl+C to stop.\n")
    try:
        server.serve_forever()
    except KeyboardInterrupt:
        pass
    finally:
        server.server_close()


if __name__ == "__main__":
    main()

_embedding_service: EmbeddingService | None = None
_llm_service: LlmService | None = None
_retrieval_service: RetrievalService | None = None


# Lifespan: initialise heavy resources once at startup.


@asynccontextmanager
async def _lifespan(app: FastAPI) -> AsyncIterator[None]:
    """Initialise application-level singletons on startup and clean up on shutdown.

    Parameters
    ----------
    app : FastAPI
        The FastAPI application instance (unused but required by the protocol).

    Yields
    ------
    None
        Control is yielded to the running application after setup completes.

    Raises
    ------
    YonoRagError
        Raised during startup if the Elasticsearch client, embedding model,
        LLM client, or index creation fails. The process exits with a non-zero code.
    """
    global _embedding_service, _llm_service, _retrieval_service  # noqa: PLW0603

    LOGGER.info("YONO Retail RAG backend starting up...")
    settings = get_settings()

    # Build Elasticsearch client.
    LOGGER.info("Initialising Elasticsearch client...")
    es_client = build_es_client(
        host=settings.rag.elasticsearch_host,
        api_key=settings.rag.elasticsearch_api_key,
        request_timeout=settings.rag.request_timeout,
        max_retries=settings.rag.max_retries,
        verify_certs=settings.rag.verify_certs,
        connections_per_node=settings.rag.connections_per_node,
    )

    # Load embedding model from HDFS.
    LOGGER.info("Loading embedding model from HDFS...")
    _embedding_service = EmbeddingService(
        hdfs_model_path=settings.rag.hdfs_model_path,
        expected_dimension=settings.rag.embedding_dimension,
    )

    # Initialise and load the DLH LLM client.
    LOGGER.info(
        "Initialising DLH LLM client. Model: '%s' | Base URL: '%s'",
        settings.llm.model_name,
        settings.llm.base_url,
    )
    _llm_service = LlmService(
        model_name=settings.llm.model_name,
        base_url=settings.llm.base_url,
        api_key=settings.llm.api_key,
        verify_ssl=settings.llm.verify_ssl,
        temperature=settings.llm.temperature,
        max_tokens=settings.llm.max_tokens,
        request_timeout=settings.llm.request_timeout,
    )
    _llm_service.load()

    # Build the retrieval service with all dependencies injected.
    _retrieval_service = RetrievalService(
        client=es_client,
        embedding_service=_embedding_service,
        llm_service=_llm_service,
        index_name=settings.rag.index_name,
        prompt_manager=PromptManager(),
    )

    LOGGER.info("YONO Retail RAG backend ready.")
    yield

    LOGGER.info("YONO Retail RAG backend shutting down.")

# Global exception handler - never expose stack traces to clients.


@app.exception_handler(YonoRagError)
async def _rag_error_handler(request: Request, exc: YonoRagError) -> JSONResponse:
    """Handle all domain-specific RAG errors with a consistent JSON body.

    Parameters
    ----------
    request : Request
        Incoming HTTP request (used for context logging).
    exc : YonoRagError
        The domain-specific exception raised by the RAG pipeline.

    Returns
    -------
    JSONResponse
        HTTP 503 response with a sanitised error message.

    Notes
    -----
    The full exception detail is logged server-side but never exposed in the
    response body to prevent information disclosure.
    """
    LOGGER.error(
        "RAG pipeline error on %s %s: %s",
        request.method,
        request.url.path,
        exc,
    )
    return JSONResponse(
        status_code=status.HTTP_503_SERVICE_UNAVAILABLE,
        content={
            "error": "service_unavailable",
            "message": (
                "The chatbot is temporarily unavailable. "
                "Please try again in a moment or contact the YONO helpline "
                "at 1800-1234 (toll-free, 24×7)."
            ),
        },
    )

# Chat endpoint


@app.post(
    "/api/v1/chat",
    response_model=ChatResponse,
    summary="YONO Retail RAG chat",
    description=(
        "Submit a natural-language banking question and receive the top "
        "knowledge-base answer along with supporting source documents."
    ),
    tags=["Chat"],
    status_code=status.HTTP_200_OK,
)
async def chat(request: ChatRequest) -> ChatResponse:
    """Handle a user chat message and return a RAG-powered answer.

    The handler runs the blocking Elasticsearch + embedding call in a
    thread-pool executor so the asyncio event loop is never blocked,
    enabling high concurrency.

    Parameters
    ----------
    request : ChatRequest
        Validated request body containing the query and optional settings.

    Returns
    -------
    ChatResponse
        Best-match answer, category, confidence score, and supporting sources.

    Raises
    ------
    HTTPException
        HTTP 503 raised when the retrieval service is not yet initialised.
    YonoRagError
        Propagated from the RAG pipeline; converted to HTTP 503 by the
        global exception handler.

    Notes
    -----
    The retrieval call is delegated to a thread-pool executor via
    ``asyncio.get_event_loop().run_in_executor`` to prevent blocking
    the main asyncio event loop during model inference and Elasticsearch I/O.
    """
    if _retrieval_service is None:
        LOGGER.error("Retrieval service not initialised. Chat request rejected.")
        raise HTTPException(
            status_code=status.HTTP_503_SERVICE_UNAVAILABLE,
            detail=(
                "The chatbot service is not yet ready. "
                "Please retry in a moment."
            ),
        )

    LOGGER.info(
        "Chat request received — session=%s query='%s'",
        request.session_id,
        request.query[:80],
    )

    # Offload blocking work to thread pool so the event loop stays free.
    loop = asyncio.get_event_loop()
    response: ChatResponse = await loop.run_in_executor(
        None,
        _retrieval_service.answer_query,
        request,
    )

    return response


# Ingestion endpoint (admin / offline use)


@app.post(
    "/api/v1/admin/ingest",
    response_model=IngestionResult,
    summary="Re-ingest knowledge base",
    description=(
        "Triggers a full knowledge-base re-ingestion from the configured "
        "CSV file. Recreates the Elasticsearch index. "
        "This endpoint is for offline / admin use only."
    ),
    tags=["Admin"],
    status_code=status.HTTP_200_OK,
)
async def ingest_knowledge_base_endpoint() -> IngestionResult:
    """Re-ingest the YONO FAQ knowledge base into Elasticsearch.

    Returns
    -------
    IngestionResult
        Summary of total rows, successful, and failed document counts.

    Raises
    ------
    HTTPException
        HTTP 503 raised when the embedding or ES service is not ready.
    YonoRagError
        Propagated from the ingestion pipeline on any failure.
    """
    if _embedding_service is None or _retrieval_service is None:
        raise HTTPException(
            status_code=status.HTTP_503_SERVICE_UNAVAILABLE,
            detail="Services not initialised. Cannot run ingestion.",
        )

    # Capture narrowed (non-None) references for use inside lambdas so that
    # static type checkers can verify the types are not Optional.
    emb_svc: EmbeddingService = _embedding_service
    ret_svc: RetrievalService = _retrieval_service

    settings = get_settings()

    loop = asyncio.get_event_loop()

    # Step 1: recreate index (blocking).
    await loop.run_in_executor(
        None,
        lambda: create_or_update_index(
            client=ret_svc.client,
            index_name=settings.rag.index_name,
            embedding_dimension=settings.rag.embedding_dimension,
            recreate=True,
        ),
    )

    # Step 2: ingest CSV (blocking).
    result: IngestionResult = await loop.run_in_executor(
        None,
        lambda: ingest_knowledge_base(
            client=ret_svc.client,
            embedding_service=emb_svc,
            csv_file_path=settings.rag.csv_file_path,
            index_name=settings.rag.index_name,
            batch_size=settings.rag.batch_size,
        ),
    )

    LOGGER.info(
        "Knowledge base ingestion complete: %d / %d documents indexed.",
        result.successful,
        result.total_rows,
    )
    return result

async function sendMessage(queryText) {
    const query = (queryText || inputEl.value).trim();
    if (!query) return;

    suggestionsBar.style.display = "none";
    appendUserMessage(query);
    inputEl.value = "";
    inputEl.style.height = "auto";
    sendBtn.disabled = true;

    showTyping();

    try {
        const res = await fetch(CHAT_ENDPOINT, {
            method: "POST",
            headers: { "Content-Type": "application/json" },
            body: JSON.stringify({ query, top_k: TOP_K, session_id: SESSION_ID }),
        });

        removeTyping();

        if (!res.ok) {
            const body = await res.json().catch(() => ({}));
            appendErrorMessage(body.message || `Server error: HTTP ${res.status}`);
            showToast("Request failed — please try again.");
            setOnline(false);
        } else {
            const data = await res.json();
            appendBotMessage(data);
            setOnline(true);
        }
    } catch (_) {
        removeTyping();
        appendErrorMessage(
            "Unable to reach the server. Check your connection or try again shortly."
        );
        showToast("Network error.");
        setOnline(false);
    } finally {
        sendBtn.disabled = false;
        inputEl.focus();
    }
}

"""
Prompt management package for the YONO Retail GenAI module.

Provides the :class:`PromptManager` for loading and rendering Jinja2
YAML prompt templates, and re-exports the prompt file paths as
constants for convenience.

Public API
----------
>>> from dlh_ai.genai.prompt import PromptManager
>>> manager = PromptManager()
>>> system_prompt = manager.get_prompt("yono_retail_chatbot", "system")
"""

from ._manager import PromptManager

__all__ = ["PromptManager"]



####################################################################################################
FILE: src\dlh_ai\genai\prompt\_manager.py
####################################################################################################


import logging
from dataclasses import dataclass
from pathlib import Path
from typing import Any

import yaml
from jinja2 import Environment, StrictUndefined, Undefined

logger = logging.getLogger("dlh_ai")


@dataclass
class PromptManager:
    """Manages loading and rendering prompts from YAML files in the prompt directory.

    This class provides methods to get prompts by agent name and type, and to render
    them with context variables. It supports strict template rendering and caching of
    loaded prompts.

    Attributes:
    ----------
    strict_templates : bool
        Whether to enforce strict template rendering. Defaults to True.
    
    Examples:
    --------
    >>> manager = PromptManager()
    >>> prompt = manager.get_prompt("agent_name", "instructions")
    """

    strict_templates: bool = True

    def __post_init__(self) -> None:
        self._prompt_dir = Path(__file__).parent
        self._prompt_registry = {}
        self._jinja_env = Environment(
            undefined=StrictUndefined if self.strict_templates else Undefined
        )
        self._load_all_prompts()

    def _load_all_prompts(self) -> None:
        """Eagerly load all YAML prompt files from the prompt directory."""
        self._prompt_registry.clear()

        for file_path in self._prompt_dir.glob("*.yaml"):
            agent_name = file_path.stem
            try:
                with file_path.open("r", encoding="utf-8") as f:
                    prompts = yaml.safe_load(f) or {}

                if not isinstance(prompts, dict):
                    logger.error(
                        f"Prompt file for agent {agent_name} must contain a YAML mapping at root. Got: {type(prompts).__name__}"
                    )
                    prompts = {}

                self._prompt_registry[agent_name] = prompts
            except Exception:
                logger.exception(
                    f"Error loading prompts for agent {agent_name} from {file_path}"
                )
                self._prompt_registry[agent_name] = {}

    def get_prompt(self, agent_name: str, prompt_key: str, **kwargs: Any) -> str:
        """Retrieves a prompt and renders it with the provided keyword arguments.

        Parameters:
        -----------
           agent_name (str): The name of the agent. This must match the filename of the YAML file in the prompt directory.
           prompt_key (str): The key of the prompt within the agent's YAML file.
           **kwargs (Any): Keyword arguments to pass to the Jinja2 template which will replace variable with actual value during runtime.
           
        Returns:
        --------
           str: The rendered prompt string.

        Raises:
           ValueError: If the prompt is not found or the template rendering fails due missing template variables.

        Example:
        --------
            >>> pm = PromptManager()
            >>> prompt = pm.get_prompt("agent1", "system", variable="value")
            >>> prompt2 = pm.get_prompt("my_awesome_agent", "instruction", column_name=["col1", "col2", "col3"])

        Notes:
        ------
            - The `agent_name` and `prompt_key` are used to locate the prompt in the registry.
            - The `**kwargs` are used to render the Jinja2 template.
        """
        prompts = self._prompt_registry.get(agent_name, {})
        template_str = prompts.get(prompt_key, "")
        if not isinstance(template_str, str) or not template_str:
            raise ValueError(f"Prompt not found: {agent_name}.{prompt_key}")

        template = self._jinja_env.from_string(template_str)
        return template.render(**kwargs)

    def clear_cache(self, agent_name: str | None = None) -> None:
        if agent_name is None:
            self._prompt_registry.clear()
        else:
            self._prompt_registry.pop(agent_name, None)

    def reload(self) -> None:
        """Reload all prompt YAML files from disk."""
        self._load_all_prompts()

"""
Embedding service for the YONO Retail RAG pipeline.

Provides a stateless, thread-safe wrapper around the
``sentence-transformers`` ``SentenceTransformer`` model loaded from
HDFS. Designed for high-throughput scenarios (10 M+ concurrent users)
where the model is loaded **once** at application start-up and reused
for every encode request.

The service validates the embedding dimension at load time to catch
model-configuration mismatches before production traffic is served.
"""

import logging
from dataclasses import dataclass, field

import numpy as np
from sentence_transformers import SentenceTransformer

from ...utils import HDFSClient
from .exceptions import (
    EmbeddingDimensionMismatchError,
    EmbeddingEncodingError,
    EmbeddingModelError,
)

LOGGER = logging.getLogger("dlh_ai")


@dataclass
class EmbeddingService:
    """Loads and serves a SentenceTransformer model for text embeddings.

    The model is loaded from HDFS once during ``__post_init__`` and
    reused for all subsequent encode calls. The service is stateless
    with respect to individual queries, making it safe to call from
    concurrent request handlers.

    Parameters
    ----------
    hdfs_model_path : str
        Absolute HDFS path to the SentenceTransformer snapshot directory.
        Example: ``"/dev/aiml/models/sentence-transformers/
        models--sentence-transformers--all-MiniLM-L12-v2/
        snapshots/a50ef00143b4d5391434df20ae11632588ac25be"``
    expected_dimension : int
        The embedding dimension that this service must produce.
        Must match the ``dims`` value in the Elasticsearch index mapping.
        Default is 384 (all-MiniLM-L12-v2).

    Attributes
    ----------
    model : SentenceTransformer
        The loaded model instance. Populated during ``__post_init__``.

    Raises
    ------
    EmbeddingModelError
        Raised during ``__post_init__`` if the model cannot be loaded
        from HDFS.
    EmbeddingDimensionMismatchError
        Raised during ``__post_init__`` if the loaded model's output
        dimension does not match ``expected_dimension``.

    Examples
    --------
    >>> service = EmbeddingService(
    ...     hdfs_model_path="/dev/aiml/models/sentence-transformers/...",
    ...     expected_dimension=384,
    ... )
    >>> vectors = service.encode(["How do I block my ATM card?"])
    >>> assert vectors.shape == (1, 384)
    """

    hdfs_model_path: str
    expected_dimension: int = 384
    model: SentenceTransformer = field(init=False)

    def __post_init__(self) -> None:
        self.model = self._load_model()

    def _load_model(self) -> SentenceTransformer:
        """Load the SentenceTransformer model from HDFS.

        Returns
        -------
        SentenceTransformer
            Loaded and dimension-validated model.

        Raises
        ------
        EmbeddingModelError
            Raised when the HDFS download or SentenceTransformer
            constructor fails.
        EmbeddingDimensionMismatchError
            Raised when the model's output dimension does not equal
            ``self.expected_dimension``.
        """
        LOGGER.info("Initialising HDFS client for model download...")
        hdfs_client = HDFSClient()

        LOGGER.info("Loading embedding model from HDFS: %s", self.hdfs_model_path)
        try:
            model: SentenceTransformer = hdfs_client.load_model_sentence_transformer(
                self.hdfs_model_path
            )
        except Exception as exc:
            raise EmbeddingModelError(
                f"Failed to load SentenceTransformer model from HDFS path "
                f"'{self.hdfs_model_path}': {type(exc).__name__} — {exc}"
            ) from exc

        # Validate embedding dimension matches the Elasticsearch mapping.
        dimension: int | None = model.get_sentence_embedding_dimension()
        LOGGER.info("Embedding model loaded. Dimension: %s", dimension)

        if dimension != self.expected_dimension:
            raise EmbeddingDimensionMismatchError(
                f"Expected embedding dimension {self.expected_dimension}, "
                f"but the loaded model returned {dimension}. "
                f"Verify 'rag.embedding_dimension' in config.toml matches "
                f"the model at '{self.hdfs_model_path}'."
            )

        LOGGER.info("Embedding dimension validated successfully (%s).", dimension)
        return model

    def encode(
        self,
        texts: list[str],
        batch_size: int = 64,
        normalize_embeddings: bool = True,
    ) -> np.ndarray:
        """Encode a list of texts into normalised embedding vectors.

        Parameters
        ----------
        texts : list[str]
            Non-empty list of strings to encode.
        batch_size : int, optional
            Number of texts to encode in a single forward pass.
            Increase for throughput; reduce for memory constraints.
            Default is 64.
        normalize_embeddings : bool, optional
            If ``True``, the output vectors are L2-normalised so
            cosine similarity equals dot product. Default is True.

        Returns
        -------
        numpy.ndarray
            Float32 array of shape ``(len(texts), expected_dimension)``.

        Raises
        ------
        ValueError
            Raised when ``texts`` is empty.
        EmbeddingEncodingError
            Raised when the model's ``encode`` method raises any exception,
            for example due to an out-of-memory error on the target device.

        Examples
        --------
        >>> service = EmbeddingService(hdfs_model_path="...", expected_dimension=384)
        >>> vectors = service.encode(["What is my account balance?"])
        >>> vectors.shape
        (1, 384)
        """
        if not texts:
            raise ValueError(
                "EmbeddingService.encode() received an empty text list. "
                "Provide at least one text to encode."
            )

        try:
            vectors: np.ndarray = self.model.encode(
                texts,
                batch_size=batch_size,
                normalize_embeddings=normalize_embeddings,
                show_progress_bar=False,
            )
        except Exception as exc:
            raise EmbeddingEncodingError(
                f"Failed to encode a batch of {len(texts)} texts: "
                f"{type(exc).__name__} — {exc}"
            ) from exc

        return vectors

    def encode_query(self, query: str) -> list[float]:
        """Encode a single query string into a flat float list.

        This convenience method is optimised for the retrieval hot-path
        where a single user query must be encoded and used immediately
        for a kNN search.

        Parameters
        ----------
        query : str
            The user's natural-language query.

        Returns
        -------
        list[float]
            Flat list of ``expected_dimension`` floats, suitable for
            direct insertion into an Elasticsearch kNN ``query_vector``.

        Raises
        ------
        ValueError
            Raised when ``query`` is an empty string.
        EmbeddingEncodingError
            Raised when encoding fails for any reason.

        Examples
        --------
        >>> service = EmbeddingService(hdfs_model_path="...", expected_dimension=384)
        >>> vector = service.encode_query("How do I block my ATM card?")
        >>> len(vector)
        384
        """
        if not query or not query.strip():
            raise ValueError(
                "EmbeddingService.encode_query() received an empty query string."
            )

        vectors = self.encode([query.strip()])
        return vectors[0].tolist()

"""
Elasticsearch client factory for the YONO Retail RAG pipeline.

This module is responsible for creating, configuring, and verifying
the Elasticsearch client used throughout the RAG pipeline. All
connection settings are sourced from the application configuration —
never hardcoded — so secrets remain out of source control.

The factory uses a connection pool with retry logic and configurable
timeouts to handle the scale of 10 million concurrent users.
"""

import logging

from elasticsearch import Elasticsearch, ConnectionError as ESConnectionError, TransportError

from .exceptions import ElasticsearchConnectionError, RagConfigurationError

LOGGER = logging.getLogger("dlh_ai")


def build_es_client(
    host: str,
    api_key: str,
    request_timeout: int = 30,
    max_retries: int = 3,
    retry_on_timeout: bool = True,
    verify_certs: bool = False,
    connections_per_node: int = 10,
) -> Elasticsearch:
    """Create a configured Elasticsearch client instance.

    The client is constructed with a connection pool sized for high
    concurrency (``connections_per_node``), automatic retry on
    transient timeouts, and HTTPS support.

    Parameters
    ----------
    host : str
        Elasticsearch cluster URL including scheme and port,
        e.g. ``"https://host:9201"``.
    api_key : str
        API key for authenticating with Elasticsearch.
        Sourced from environment / ``.env`` — never logged or printed.
    request_timeout : int, optional
        Per-request socket timeout in seconds. Default is 30.
    max_retries : int, optional
        Number of automatic retries on transient failures. Default is 3.
    retry_on_timeout : bool, optional
        Whether to retry the request if it times out. Default is True.
    verify_certs : bool, optional
        Whether to verify the TLS certificate. Set to ``True`` in
        production environments. Default is False (UAT environment).
    connections_per_node : int, optional
        Size of the connection pool per Elasticsearch node. Increase
        for high-concurrency deployments. Default is 10.

    Returns
    -------
    Elasticsearch
        Ready-to-use Elasticsearch client instance.

    Raises
    ------
    RagConfigurationError
        Raised when ``host`` or ``api_key`` is empty or ``None``.
    ElasticsearchConnectionError
        Raised when the cluster health check fails after client creation,
        indicating the cluster is unreachable or authentication failed.

    Notes
    -----
    * TLS certificate warnings are suppressed in UAT (``verify_certs=False``).
      Enable certificate verification in production by setting
      ``ELASTICSEARCH__VERIFY_CERTS=true`` in the environment.
    * The connection pool size should match or exceed the number of
      asyncio worker tasks expected to hit Elasticsearch simultaneously.

    Examples
    --------
    >>> client = build_es_client(
    ...     host="https://es-host:9201",
    ...     api_key="<api_key_from_env>",
    ... )
    >>> info = client.info()
    >>> print(info["version"]["number"])
    """
    if not host:
        raise RagConfigurationError(
            "Elasticsearch 'host' must not be empty. "
            "Set 'rag.elasticsearch_host' in config.toml or "
            "'ELASTICSEARCH__HOST' in the environment."
        )
    if not api_key:
        raise RagConfigurationError(
            "Elasticsearch 'api_key' must not be empty. "
            "Set 'ELASTICSEARCH__API_KEY' in the .env file or environment."
        )

    LOGGER.info("Creating Elasticsearch client for host: %s", host)

    client = Elasticsearch(
        host,
        api_key=api_key,
        request_timeout=request_timeout,
        max_retries=max_retries,
        retry_on_timeout=retry_on_timeout,
        verify_certs=verify_certs,
        connections_per_node=connections_per_node,
    )

    _verify_connection(client, host)
    return client


def _verify_connection(client: Elasticsearch, host: str) -> None:
    """Verify the Elasticsearch connection by calling cluster info.

    Parameters
    ----------
    client : Elasticsearch
        The client instance to verify.
    host : str
        Host string used only for error message context.

    Raises
    ------
    ElasticsearchConnectionError
        Raised when ``client.info()`` raises a connection or transport error,
        meaning the cluster is unreachable or authentication was rejected.

    Notes
    -----
    The API key is never included in error messages to prevent secret leakage.
    """
    try:
        info = client.info()
        cluster_name = info.get("cluster_name", "unknown")
        version = info.get("version", {}).get("number", "unknown")
        LOGGER.info(
            "Elasticsearch connected — cluster: '%s', version: %s",
            cluster_name,
            version,
        )
    except ESConnectionError as exc:
        raise ElasticsearchConnectionError(
            f"Cannot connect to Elasticsearch at '{host}'. "
            "Check network connectivity, VPN settings, and cluster health."
        ) from exc
    except TransportError as exc:
        raise ElasticsearchConnectionError(
            f"Elasticsearch at '{host}' rejected the connection. "
            "Verify that the API key is valid and not expired."
        ) from exc

"""
Knowledge-base ingestion pipeline for the YONO Retail RAG chatbot.

This module reads the YONO retail FAQ CSV, generates sentence embeddings
for each row, and performs bulk ingestion into Elasticsearch. It is
designed for one-time or periodic re-ingestion and is completely
independent of the live query path.

The pipeline supports:
* Column validation before any embedding work begins.
* Configurable batch size for memory-efficient processing.
* Partial-failure accounting so the caller knows exactly how many
  documents were indexed versus dropped.
* Elasticsearch index creation / recreation with the correct mapping.
"""

import logging
from pathlib import Path

import pandas as pd
from elasticsearch import Elasticsearch, helpers

from ._embedding_service import EmbeddingService
from ._models import IngestionResult
from .exceptions import (
    ElasticsearchIndexError,
    ElasticsearchIngestionError,
    KnowledgeBaseIngestionError,
)

LOGGER = logging.getLogger("dlh_ai")

# Columns that MUST be present in the knowledge-base CSV.
_REQUIRED_COLUMNS: list[str] = ["Sno", "Category", "Question", "Answer", "Type"]

# Elasticsearch mapping for the knowledge-base index.
_INDEX_MAPPINGS: dict = {

        },
        # Metadata fields for faceting and display.
        "category": {"type": "keyword"},
        "type": {"type": "keyword"},
        "question": {"type": "text"},
        "answer": {"type": "text"},
        "sno": {"type": "integer"},
    }
}


# Index management


def create_or_update_index(
    client: Elasticsearch,
    index_name: str,
    embedding_dimension: int = 384,
    recreate: bool = True,
) -> None:
    """Create the Elasticsearch index with the correct vector mapping.

    If ``recreate=True`` and the index already exists it will be deleted
    first. All existing documents will be lost in that case.

    Parameters
    ----------
    client : Elasticsearch
        Active Elasticsearch client instance.
    index_name : str
        Target index name.
    embedding_dimension : int, optional
        Number of dimensions for the dense_vector field. Must match the
        embedding model output. Default is 384.
    recreate : bool, optional
        If ``True``, delete and recreate the index if it already exists.
        If ``False``, leave the existing index untouched. Default is True.

    Raises
    ------
    ElasticsearchIndexError
        Raised when the index creation or deletion operation fails,
        for example due to a mapping conflict or insufficient permissions.

    Notes
    -----
    The ``dims`` value in the mapping is set from ``embedding_dimension``
    at call time, making this function reusable for any vector dimension.

    Examples
    --------
    >>> create_or_update_index(client, "yono_retail_knowledge_base", recreate=True)
    """
    # Build mapping dynamically so embedding_dimension is always in sync.
    mappings: dict = {
        "properties": {
            "combined_text": {"type": "text"},
            "combined_text_embedding": {
                "type": "dense_vector",
                "dims": embedding_dimension,
                "index": True,
                "similarity": "cosine",
            },
            "category": {"type": "keyword"},
            "type": {"type": "keyword"},
            "question": {"type": "text"},
            "answer": {"type": "text"},
            "sno": {"type": "integer"},
        }
    }

    try:
        index_exists: bool = client.indices.exists(index=index_name)
    except Exception as exc:
        raise ElasticsearchIndexError(
            f"Failed to check existence of Elasticsearch index '{index_name}': "
            f"{type(exc).__name__} — {exc}"
        ) from exc

    if index_exists:
        if recreate:
            LOGGER.warning(
                "Elasticsearch index '%s' already exists and will be deleted (recreate=True).",
                index_name,
            )
            try:
                client.indices.delete(index=index_name)
                LOGGER.info("Existing index '%s' deleted.", index_name)
            except Exception as exc:
                raise ElasticsearchIndexError(
                    f"Failed to delete existing Elasticsearch index '{index_name}': "
                    f"{type(exc).__name__} — {exc}"
                ) from exc
        else:
            LOGGER.info(
                "Elasticsearch index '%s' already exists. Keeping existing index (recreate=False).",
                index_name,
            )
            return

    LOGGER.info("Creating Elasticsearch index '%s' ...", index_name)
    try:
        client.indices.create(index=index_name, mappings=mappings)
    except Exception as exc:
        raise ElasticsearchIndexError(
            f"Failed to create Elasticsearch index '{index_name}': "
            f"{type(exc).__name__} — {exc}"
        ) from exc

    LOGGER.info(
        "Index '%s' created successfully with %s-dimensional vectors.",
        index_name,
        embedding_dimension,
    )


# Text helpers


def build_combined_text(row: pd.Series) -> str:
    """Build the text string that will be converted into an embedding vector.

    The combined text concatenates the category, question, and answer so
    that the embedding captures all contextual signals in a single vector.

    Parameters
    ----------
    row : pandas.Series
        A single row from the knowledge-base DataFrame. Must contain
        ``"Category"``, ``"Question"``, and ``"Answer"`` keys.

    Returns
    -------
    str
        Combined text of the form:
        ``"Category: <cat>. Question: <q> Answer: <a>"``.

    Examples
    --------
    >>> import pandas as pd
    >>> row = pd.Series({
    ...     "Category": "ATM/Debit Card Service",
    ...     "Question": "How do I activate my card?",
    ...     "Answer": "Use the YONO app.",
    ... })
    >>> build_combined_text(row)
    'Category: ATM/Debit Card Service. Question: How do I activate my card? Answer: Use the YONO app.'
    """
    category: str = str(row.get("Category", "")).strip()
    question: str = str(row.get("Question", "")).strip()
    answer: str = str(row.get("Answer", "")).strip()
    return f"Category: {category}. Question: {question} Answer: {answer}"


# Ingestion pipeline


def ingest_knowledge_base(
    client: Elasticsearch,
    embedding_service: EmbeddingService,
    csv_file_path: str | Path,
    index_name: str,
    batch_size: int = 100,
) -> IngestionResult:
    """Read the YONO FAQ CSV, generate embeddings, and bulk-ingest into Elasticsearch.

    The function processes the CSV in configurable batches to bound memory
    usage. Partial batch failures are counted and reported, but they do not
    abort the overall ingestion so that the maximum number of documents are
    indexed even when individual rows fail.

    Parameters
    ----------
    client : Elasticsearch
        Active Elasticsearch client instance.
    embedding_service : EmbeddingService
        Loaded and validated embedding service.
    csv_file_path : str or pathlib.Path
        Path to the knowledge-base CSV file. Must contain columns:
        ``Sno``, ``Category``, ``Question``, ``Answer``, ``Type``.
    index_name : str
        Name of the target Elasticsearch index.
    batch_size : int, optional
        Number of rows to embed and index per bulk request. Default is 100.

    Returns
    -------
    IngestionResult
        Summary containing ``total_rows``, ``successful``, and ``failed`` counts.

    Raises
    ------
    KnowledgeBaseIngestionError
        Raised when the CSV file cannot be read or does not contain
        the required columns.
    ElasticsearchIngestionError
        Raised when all batches fail to ingest (i.e., ``successful == 0``
        and ``total_rows > 0``).

    Notes
    -----
    * The ``Category`` column is forward-filled (``ffill``) before ingestion
      to handle merged cells from spreadsheet exports.
    * ``helpers.bulk`` is called with ``raise_on_error=False`` so partial
      batch failures are counted rather than raising an exception.

    Examples
    --------
    >>> result = ingest_knowledge_base(
    ...     client=es_client,
    ...     embedding_service=emb_service,
    ...     csv_file_path="yono_retail_knowledge_base_fill_category.csv",
    ...     index_name="yono_retail_knowledge_base",
    ...     batch_size=100,
    ... )
    >>> print(f"Indexed {result.successful}/{result.total_rows} documents.")
    """
    csv_path = Path(csv_file_path)
    LOGGER.info("Reading knowledge-base CSV from: %s", csv_path.resolve())

    if not csv_path.is_file():
        raise KnowledgeBaseIngestionError(
            f"Knowledge-base CSV file not found at '{csv_path.resolve()}'. "
            "Verify 'rag.csv_file_path' in config.toml or the DATA_CSV_PATH "
            "environment variable."
        )

    try:
        df = pd.read_csv(csv_path)
    except Exception as exc:
        raise KnowledgeBaseIngestionError(
            f"Failed to read knowledge-base CSV from '{csv_path}': "
            f"{type(exc).__name__} — {exc}"
        ) from exc

    LOGGER.info("CSV loaded. Total rows: %d", len(df))

    # Validate required columns before any embedding work.
    missing_columns: list[str] = [
        col for col in _REQUIRED_COLUMNS if col not in df.columns
    ]
    if missing_columns:
        raise KnowledgeBaseIngestionError(
            f"Knowledge-base CSV '{csv_path}' is missing required columns: "
            f"{missing_columns}. Available columns: {df.columns.tolist()}"
        )

    # Normalise missing values before embedding.
    df["Category"] = df["Category"].ffill().fillna("")
    df["Question"] = df["Question"].fillna("")
    df["Answer"] = df["Answer"].fillna("")
    df["Type"] = df["Type"].fillna("")

    total_rows: int = len(df)
    successful: int = 0
    failed: int = 0

    # Process and ingest in batches.
    for batch_start in range(0, total_rows, batch_size):
        batch_df: pd.DataFrame = df.iloc[batch_start : batch_start + batch_size]
        batch_num: int = (batch_start // batch_size) + 1
        total_batches: int = (total_rows + batch_size - 1) // batch_size

        LOGGER.info(
            "Processing batch %d / %d  (rows %d–%d)...",
            batch_num,
            total_batches,
            batch_start,
            batch_start + len(batch_df) - 1,
        )

        # Build combined text for each row in this batch.
        texts: list[str] = [
            build_combined_text(row) for _, row in batch_df.iterrows()
        ]

        # Generate embeddings for the entire batch at once.
        try:
            embeddings = embedding_service.encode(texts)
        except Exception as exc:
            LOGGER.error(
                "Embedding failed for batch %d / %d — skipping %d documents. "
                "Error: %s",
                batch_num,
                total_batches,
                len(texts),
                exc,
            )
            failed += len(texts)
            continue

        # Build Elasticsearch bulk actions.
        actions: list[dict] = []
        for (_, row), embedding, combined_text in zip(
            batch_df.iterrows(), embeddings, texts
        ):
            doc: dict = {
                "sno": int(row["Sno"]),
                "category": str(row["Category"]).strip(),
                "question": str(row["Question"]).strip(),
                "answer": str(row["Answer"]).strip(),
                "type": str(row["Type"]).strip(),
                "combined_text": combined_text,
                "combined_text_embedding": embedding.tolist(),
            }
            actions.append({"_index": index_name, "_source": doc})

        # Bulk insert – partial failures are counted, not raised.
        try:
            success_count, errors = helpers.bulk(
                client,
                actions,
                raise_on_error=False,
            )
            successful += success_count

            if errors:
                error_count = len(errors)
                failed += error_count
                LOGGER.warning(
                    "Batch %d / %d: %d documents failed to index. "
                    "First error: %s",
                    batch_num,
                    total_batches,
                    error_count,
                    errors[0] if errors else "unknown",
                )
        except Exception as exc:
            LOGGER.error(
                "Bulk ingestion failed for batch %d / %d — %d documents lost. "
                "Error: %s",
                batch_num,
                total_batches,
                len(actions),
                exc,
            )
            failed += len(actions)

    LOGGER.info(
        "Ingestion complete. Total: %d | Successful: %d | Failed: %d",
        total_rows,
        successful,
        failed,
    )

    if total_rows > 0 and successful == 0:
        raise ElasticsearchIngestionError(
            f"Ingestion of '{csv_path}' into index '{index_name}' produced "
            f"zero successful documents out of {total_rows}. "
            "Check Elasticsearch cluster health and index mapping."
        )

    return IngestionResult(
        total_rows=total_rows,
        successful=successful,
        failed=failed,
    )

"""
LLM provider service for the YONO Retail RAG chatbot.

Uses the DLH self-hosted vLLM OpenAI-compatible inference endpoint
(e.g. Gemma-4-26b-a4b-it) via the standard ``openai`` Python client.

The service is responsible for:

1. Constructing a valid :class:`openai.OpenAI` client pointed at the DLH
   base URL with the configured API key and optional TLS settings.
2. Sending a fully-composed RAG prompt (system + user context + query) to
   the model and collecting the completion.
3. Returning the synthesised answer as a plain string for the chat response.

All secrets (API keys) are read from :class:`~dlh_ai.config.LlmSettings`
which is populated exclusively from environment variables or the ``.env``
file — never from source code or ``config.toml``.

Design notes
------------
* The :class:`LlmService` is stateless between calls. The ``OpenAI`` client
  is created once in :meth:`load` and then reused, making the service safe
  to share across concurrent request handlers.
* TLS verification can be disabled via ``verify_ssl = false`` for
  UAT environments that use self-signed certificates.
* ``temperature`` and ``max_tokens`` are exposed as configuration so the
  calling layer can tune verbosity without code changes.
"""

import logging
from dataclasses import dataclass, field

import httpx
from openai import APIConnectionError, APIStatusError, OpenAI

from .exceptions import LlmGenerationError, LlmLoadError

LOGGER = logging.getLogger("dlh_ai")

# Sentinel value for the DLH self-hosted endpoint that uses no real key.
_DLH_EMPTY_KEY: str = "EMPTY"


@dataclass
class LlmService:
    """Manages the lifecycle of the DLH self-hosted LLM client.

    Uses the DLH vLLM OpenAI-compatible endpoint. The client is
    initialised once via :meth:`load` and then reused for all
    subsequent :meth:`generate` calls.

    Parameters
    ----------
    model_name : str
        Model identifier sent in every completion request.
        Example: ``"gemma-4-26b-a4b-it"``.
    base_url : str
        Base URL for the DLH vLLM OpenAI-compatible inference server.
        Example: ``"http://10.190.236.15:9000/api/v1"``.
    api_key : str
        API key for the DLH endpoint. Use ``"EMPTY"`` for unauthenticated
        endpoints. Must be supplied via ``LLM__API_KEY`` env variable.
    verify_ssl : bool
        Whether to verify the TLS certificate of the endpoint.
        Set to ``False`` for UAT self-signed certificates. Default is ``False``.
    temperature : float
        Sampling temperature for the completion. Range [0.0, 2.0].
        Lower values produce more deterministic output. Default is 0.2.
    max_tokens : int
        Maximum number of tokens in the generated response. Default is 1024.
    request_timeout : float
        HTTP request timeout in seconds for each LLM call. Default is 60.0.

    Attributes
    ----------
    _client : openai.OpenAI or None
        Internal OpenAI client. ``None`` until :meth:`load` is called.
    _send_sampling_params : bool
        Whether to include ``temperature`` in the request.
        Set to ``False`` for models that reject sampling parameters.

    Raises
    ------
    LlmLoadError
        Raised by :meth:`load` if the base URL is empty or the ``OpenAI``
        constructor raises an exception.

    Examples
    --------
    >>> from dlh_ai.config import get_settings
    >>> settings = get_settings()
    >>> service = LlmService(
    ...     model_name=settings.llm.model_name,
    ...     base_url=settings.llm.base_url,
    ...     api_key=settings.llm.api_key,
    ...     verify_ssl=settings.llm.verify_ssl,
    ...     temperature=settings.llm.temperature,
    ...     max_tokens=settings.llm.max_tokens,
    ...     request_timeout=settings.llm.request_timeout,
    ... )
    >>> service.load()
    >>> answer = service.generate(system_prompt="You are a banking assistant.", user_prompt="...")
    """

    model_name: str
    base_url: str
    api_key: str
    verify_ssl: bool = False
    temperature: float = 0.2
    max_tokens: int = 1024
    request_timeout: float = 60.0
    _client: OpenAI | None = field(default=None, init=False, repr=False)
    _send_sampling_params: bool = field(default=True, init=False, repr=False)

    # Public lifecycle

    def load(self) -> None:
        """Initialise the DLH OpenAI-compatible client.

        Must be called once before any :meth:`generate` call. Safe to call
        multiple times — subsequent calls replace the existing client.

        Raises
        ------
        LlmLoadError
            Raised when ``base_url`` is empty or the ``OpenAI``
            constructor raises an exception (e.g. invalid URL format).

        Examples
        --------
        >>> service.load()
        """
        self._load_dlh_client()

    def generate(self, system_prompt: str, user_prompt: str) -> str:
        """Send a prompt to the LLM and return the generated text.

        Constructs a two-message conversation (system + user) and calls the
        configured OpenAI-compatible completion endpoint. The generated text
        is returned as a stripped plain string.

        Parameters
        ----------
        system_prompt : str
            The system-role instruction that sets the assistant's behaviour
            and persona. Should be rendered by :class:`~dlh_ai.genai.prompt.PromptManager`.
        user_prompt : str
            The user-role message that contains the RAG context and the
            customer's question. Should be rendered by :class:`~dlh_ai.genai.prompt.PromptManager`.

        Returns
        -------
        str
            The generated answer text, stripped of leading/trailing whitespace.

        Raises
        ------
        LlmLoadError
            Raised when :meth:`load` has not been called before :meth:`generate`.
        LlmGenerationError
            Raised when the LLM endpoint returns an error status, the network
            connection fails, or the response structure is unexpected.

        Notes
        -----
        * The ``temperature`` parameter is passed only when
          ``_send_sampling_params`` is ``True``. Some vLLM-served models
          reject ``temperature`` in the payload and require it to be omitted.
        * The full error detail from the LLM endpoint is logged server-side
          but never forwarded to the client to prevent information disclosure.

        Examples
        --------
        >>> answer = service.generate(
        ...     system_prompt="You are a YONO banking assistant.",
        ...     user_prompt="Context: ...\\nQuestion: How do I block my ATM card?",
        ... )
        >>> print(answer)
        You can block your ATM/Debit card via YONO app under Service Requests...
        """
        if self._client is None:
            raise LlmLoadError(
                "LlmService.generate() called before LlmService.load(). "
                "Call load() once during application startup."
            )

        LOGGER.debug(
            "Sending completion request to model '%s' (base_url=%s).",
            self.model_name,
            self.base_url,
        )

        messages: list[dict[str, str]] = [
            {"role": "system", "content": system_prompt},
            {"role": "user",   "content": user_prompt},
        ]

        completion_kwargs: dict = {
            "model": self.model_name,
            "messages": messages,
            "max_tokens": self.max_tokens,
        }
        if self._send_sampling_params:
            completion_kwargs["temperature"] = self.temperature

        try:
            response = self._client.chat.completions.create(**completion_kwargs)
        except APIConnectionError as exc:
            raise LlmGenerationError(
                "LLM endpoint is unreachable. "
                f"Check the base URL '{self.base_url}' and network connectivity."
            ) from exc
        except APIStatusError as exc:
            raise LlmGenerationError(
                f"LLM endpoint returned HTTP {exc.status_code}. "
                "Verify the API key and model name are correct."
            ) from exc
        except Exception as exc:
            raise LlmGenerationError(
                f"Unexpected error during LLM generation for model '{self.model_name}': "
                f"{type(exc).__name__} — {exc}"
            ) from exc

        try:
            answer: str = response.choices[0].message.content or ""
        except (IndexError, AttributeError) as exc:
            raise LlmGenerationError(
                f"LLM response from model '{self.model_name}' had an unexpected structure. "
                "Expected at least one choice with a message content field."
            ) from exc

        LOGGER.debug(
            "LLM generation complete. Response length: %d chars.", len(answer)
        )
        return answer.strip()

    # Private loader

    def _load_dlh_client(self) -> None:
        """Initialise the DLH self-hosted vLLM OpenAI-compatible client.

        Raises
        ------
        LlmLoadError
            Raised when ``base_url`` is empty or the ``OpenAI``
            constructor raises an exception.
        """
        if not self.base_url:
            raise LlmLoadError(
                "DLH base URL is empty. "
                "Set 'LLM__BASE_URL' in the environment or config.toml."
            )

        # Build an httpx client with TLS verification disabled for UAT.
        http_client: httpx.Client | None = None
        if not self.verify_ssl:
            LOGGER.warning(
                "LLM client: TLS certificate verification is DISABLED. "
                "Enable LLM__VERIFY_SSL=true in production."
            )
            http_client = httpx.Client(verify=False)

        try:
            self._client = OpenAI(
                api_key=self.api_key or _DLH_EMPTY_KEY,
                base_url=self.base_url,
                timeout=self.request_timeout,
                **({"http_client": http_client} if http_client is not None else {}),
            )
            LOGGER.info(
                "DLH LLM client initialised. Model: '%s' | Base URL: '%s'",
                self.model_name,
                self.base_url,
            )
        except Exception as exc:
            raise LlmLoadError(
                f"Failed to initialise DLH OpenAI-compatible client "
                f"at '{self.base_url}': {type(exc).__name__} — {exc}"
            ) from exc

"""
Vector search and retrieval service for the YONO Retail RAG chatbot.

Provides a concurrency-safe ``RetrievalService`` class that handles:
* kNN vector search against Elasticsearch
* Hybrid search (kNN + BM25 combined via Elasticsearch multi-query)
* Result mapping from raw Elasticsearch hits to typed ``SearchHit`` objects
* LLM-powered answer synthesis via :class:`~dlh_ai.genai.rag._llm_service.LlmService`

The LLM receives the top-k retrieved knowledge-base passages as context
(rendered through :class:`~dlh_ai.genai.prompt.PromptManager`) and
generates a coherent, concise answer for the user.

Designed to serve 10 million concurrent users via stateless instances
backed by an Elasticsearch cluster with appropriate replicas and shards.
"""

import logging
from dataclasses import dataclass, field

from elasticsearch import Elasticsearch

from dlh_ai.genai.prompt import PromptManager

from ._embedding_service import EmbeddingService
from ._llm_service import LlmService
from ._models import ChatRequest, ChatResponse, SearchHit, VectorSearchResponse
from .exceptions import ElasticsearchSearchError, LlmGenerationError, RetrievalError

LOGGER = logging.getLogger("dlh_ai")

# Elasticsearch source fields returned for every hit.
_SOURCE_FIELDS: list[str] = [
    "sno",
    "category",
    "question",
    "answer",
    "type",
    "combined_text",
]

# Prompt agent name — must match the YAML filename in the prompt directory.
_PROMPT_AGENT: str = "yono_retail_chatbot"


@dataclass
class RetrievalService:
    """Stateless RAG service: vector retrieval + LLM answer synthesis.

    Combines kNN Elasticsearch search with the DLH Gemma-4 LLM to
    produce a synthesised, context-aware answer for each user query.

    All public methods are safe to call concurrently from multiple asyncio
    tasks or threads because they hold no mutable state between calls.
    All dependencies are injected at construction time.

    Parameters
    ----------
    client : Elasticsearch
        Active Elasticsearch client with a connection pool sized for the
        expected concurrency level.
    embedding_service : EmbeddingService
        Loaded and dimension-validated sentence-transformer embedding model.
    llm_service : LlmService
        Loaded DLH LLM client. Must have :meth:`~LlmService.load`
        called before any :meth:`answer_query` call.
    index_name : str
        Name of the Elasticsearch index that holds the knowledge base.
    prompt_manager : PromptManager
        Loaded prompt template manager used to render system and user prompts.

    Examples
    --------
    >>> service = RetrievalService(
    ...     client=es_client,
    ...     embedding_service=emb_service,
    ...     llm_service=llm_service,
    ...     index_name="yono_retail_knowledge_base",
    ...     prompt_manager=PromptManager(),
    ... )
    >>> from dlh_ai.genai.rag._models import ChatRequest
    >>> req = ChatRequest(query="How do I block my debit card?", top_k=5)
    >>> response = service.answer_query(req)
    >>> print(response.answer)
    """

    client: Elasticsearch
    embedding_service: EmbeddingService
    llm_service: LlmService
    index_name: str
    prompt_manager: PromptManager = field(default_factory=PromptManager)

    # Public search methods

    def search(self, query: str, top_k: int = 5) -> VectorSearchResponse:
        """Perform a kNN vector search and return ranked knowledge-base hits.

        The query is embedded using the same SentenceTransformer model used
        during ingestion so the query vector lives in the same semantic space
        as all document vectors.

        Parameters
        ----------
        query : str
            User's natural-language question.
        top_k : int, optional
            Maximum number of results to return. Must be >= 1. Default is 5.

        Returns
        -------
        VectorSearchResponse
            Typed response containing the query, total hit count, and a
            ranked list of :class:`SearchHit` objects.

        Raises
        ------
        ValueError
            Raised when ``query`` is empty or ``top_k`` < 1.
        ElasticsearchSearchError
            Raised when the Elasticsearch search call fails due to a network
            error or non-2xx HTTP response.
        RetrievalError
            Raised when the Elasticsearch response structure is unexpected.

        Notes
        -----
        ``num_candidates`` is set to ``max(top_k * 10, 50)`` per Elasticsearch
        kNN best-practice guidance for accuracy vs. latency trade-off.

        Examples
        --------
        >>> result = service.search("How do I transfer money via YONO?", top_k=5)
        >>> for hit in result.hits:
        ...     print(f"[{hit.score:.4f}] {hit.question}")
        """
        if not query or not query.strip():
            raise ValueError(
                "RetrievalService.search() received an empty query string. "
                "Provide a non-empty question."
            )
        if top_k < 1:
            raise ValueError(f"'top_k' must be at least 1, but received {top_k}.")

        LOGGER.debug("Encoding query for kNN search: '%s'", query[:100])
        query_vector: list[float] = self.embedding_service.encode_query(query)

        LOGGER.debug(
            "Executing kNN search on index '%s' (top_k=%d).", self.index_name, top_k
        )

        try:
            raw_response = self.client.search(
                index=self.index_name,
                knn={
                    "field": "combined_text_embedding",
                    "query_vector": query_vector,
                    "k": top_k,
                    "num_candidates": max(top_k * 10, 50),
                },
                source=_SOURCE_FIELDS,
            )
        except Exception as exc:
            raise ElasticsearchSearchError(
                f"kNN search on index '{self.index_name}' failed: "
                f"{type(exc).__name__} — {exc}"
            ) from exc

        return self._parse_response(query=query, raw_response=raw_response)

    def search_hybrid(
        self,
        query: str,
        top_k: int = 5,
        bm25_boost: float = 0.3,
        vector_boost: float = 0.7,
    ) -> VectorSearchResponse:
        """Perform a hybrid kNN + BM25 search for improved recall.

        Combines dense vector similarity with sparse BM25 keyword matching.
        This improves recall for queries containing uncommon keywords not
        well-captured by semantic embeddings alone.

        Parameters
        ----------
        query : str
            User's natural-language question.
        top_k : int, optional
            Maximum number of results to return. Default is 5.
        bm25_boost : float, optional
            Boost factor for the BM25 ``multi_match`` sub-query. Default is 0.3.
        vector_boost : float, optional
            Boost factor for the kNN sub-query. Default is 0.7.

        Returns
        -------
        VectorSearchResponse
            Combined ranked results from both retrieval strategies.

        Raises
        ------
        ValueError
            Raised when ``query`` is empty or ``top_k`` < 1.
        ElasticsearchSearchError
            Raised when the Elasticsearch search call fails.
        RetrievalError
            Raised when the response structure is unexpected.

        Examples
        --------
        >>> result = service.search_hybrid("YONO UPI PIN reset", top_k=5)
        """
        if not query or not query.strip():
            raise ValueError(
                "RetrievalService.search_hybrid() received an empty query string."
            )
        if top_k < 1:
            raise ValueError(f"'top_k' must be >= 1, but received {top_k}.")

        query_vector: list[float] = self.embedding_service.encode_query(query)

        LOGGER.debug(
            "Executing hybrid search on index '%s' (top_k=%d).", self.index_name, top_k
        )

        try:
            raw_response = self.client.search(
                index=self.index_name,
                size=top_k,
                knn={
                    "field": "combined_text_embedding",
                    "query_vector": query_vector,
                    "k": top_k,
                    "num_candidates": max(top_k * 10, 50),
                    "boost": vector_boost,
                },
                query={
                    "multi_match": {
                        "query": query,
                        "fields": ["question^2", "answer", "category"],
                        "boost": bm25_boost,
                    }
                },
                source=_SOURCE_FIELDS,
            )
        except Exception as exc:
            raise ElasticsearchSearchError(
                f"Hybrid search on index '{self.index_name}' failed: "
                f"{type(exc).__name__} — {exc}"
            ) from exc

        return self._parse_response(query=query, raw_response=raw_response)

    # Primary RAG answer method

    def answer_query(self, request: ChatRequest) -> ChatResponse:
        """Execute the full RAG pipeline: retrieve → prompt → LLM → respond.

        Steps:

        1. Run kNN vector search to retrieve the top-k knowledge-base passages.
        2. Render the ``system`` and ``rag_chat`` prompt templates with the
           retrieved context using :class:`~dlh_ai.genai.prompt.PromptManager`.
        3. Call :meth:`~LlmService.generate` to synthesise a coherent answer.
        4. Return a :class:`ChatResponse` with the LLM answer and all
           source documents for transparency.

        Parameters
        ----------
        request : ChatRequest
            Validated incoming chat request from the API layer.

        Returns
        -------
        ChatResponse
            Response containing the LLM-synthesised answer, top-hit metadata
            (category, doc_type, score), and all retrieved source documents.

        Raises
        ------
        RetrievalError
            Raised when no knowledge-base documents are found for the query,
            or when the Elasticsearch search call fails.
        LlmGenerationError
            Raised when the LLM endpoint fails to generate a completion, for
            example due to a network failure or an authentication error.

        Notes
        -----
        * The ``system`` prompt sets the YONO Assistant persona and policies.
        * The ``rag_chat`` prompt injects the retrieved context passages and
          the user's question for the LLM to answer.
        * The LLM answer replaces the raw ``top_hit.answer`` so the response
          is synthesised across all retrieved passages rather than returning
          a single verbatim FAQ entry.

        Examples
        --------
        >>> from dlh_ai.genai.rag._models import ChatRequest
        >>> req = ChatRequest(query="How do I activate my debit card?", top_k=5)
        >>> response = service.answer_query(req)
        >>> print(response.answer)
        To activate your ATM/Debit card, you can use the YONO app...
        """
        LOGGER.info(
            "Processing chat query (session=%s): '%s'",
            request.session_id,
            request.query[:100],
        )

        # ── Step 1: Retrieve knowledge-base passages ────────────────────
        try:
            result: VectorSearchResponse = self.search(
                query=request.query,
                top_k=request.top_k,
            )
        except ElasticsearchSearchError as exc:
            raise RetrievalError(
                f"Retrieval failed for query '{request.query[:80]}': {exc}"
            ) from exc

        if not result.hits:
            raise RetrievalError(
                f"No knowledge-base documents found for query: '{request.query[:80]}'. "
                "The index may be empty or the query does not match any document."
            )

        top_hit: SearchHit = result.hits[0]

        LOGGER.info(
            "Retrieved %d hit(s). Top score: %.4f | Category: '%s'",
            result.total_hits,
            top_hit.score,
            top_hit.category,
        )

        # ── Step 2: Render prompts ──────────────────────────────────────
        system_prompt: str = self.prompt_manager.get_prompt(
            _PROMPT_AGENT, "system"
        )

        # Build context_items list for the rag_chat template.
        context_items: list[dict] = [
            {
                "rank": rank,
                "score": hit.score,
                "category": hit.category,
                "doc_type": hit.doc_type,
                "question": hit.question,
                "answer": hit.answer,
            }
            for rank, hit in enumerate(result.hits, start=1)
        ]

        user_prompt: str = self.prompt_manager.get_prompt(
            _PROMPT_AGENT,
            "rag_chat",
            query=request.query,
            context_items=context_items,
        )

        # ── Step 3: Generate LLM answer ─────────────────────────────────
        LOGGER.debug("Sending context + query to LLM for synthesis...")
        try:
            llm_answer: str = self.llm_service.generate(
                system_prompt=system_prompt,
                user_prompt=user_prompt,
            )
        except LlmGenerationError:
            # Re-raise so the FastAPI handler can return a clean 503.
            raise

        LOGGER.info(
            "LLM answer generated. Length: %d chars.", len(llm_answer)
        )

        # ── Step 4: Build response ──────────────────────────────────────
        return ChatResponse(
            query=request.query,
            answer=llm_answer,
            category=top_hit.category,
            doc_type=top_hit.doc_type,
            score=top_hit.score,
            sources=result.hits,
            session_id=request.session_id,
        )

    # Internal helpers

    def _parse_response(
        self,
        query: str,
        raw_response: dict,
    ) -> VectorSearchResponse:
        """Parse a raw Elasticsearch search response into typed objects.

        Parameters
        ----------
        query : str
            Original query string for context in the response.
        raw_response : dict
            Raw dictionary returned by ``client.search()``.

        Returns
        -------
        VectorSearchResponse
            Typed and validated search response.

        Raises
        ------
        RetrievalError
            Raised when the expected ``hits.hits`` key is missing from the
            raw response, indicating an unexpected Elasticsearch API structure.
        """
        try:
            outer_hits: dict = raw_response.get("hits", {})
            raw_hits: list[dict] = outer_hits.get("hits", [])
        except AttributeError as exc:
            raise RetrievalError(
                "Failed to parse Elasticsearch response: unexpected structure. "
                f"Expected a dict with 'hits.hits', got: {type(raw_response).__name__}"
            ) from exc

        hits: list[SearchHit] = []
        for raw_hit in raw_hits:
            source: dict = raw_hit.get("_source", {})
            score: float = float(raw_hit.get("_score", 0.0))
            hit = SearchHit(
                score=score,
                sno=int(source.get("sno", 0)),
                category=str(source.get("category", "")),
                question=str(source.get("question", "")),
                answer=str(source.get("answer", "")),
                doc_type=str(source.get("type", "")),
            )
            hits.append(hit)

        return VectorSearchResponse(
            query=query,
            total_hits=len(hits),
            hits=hits,
        )

"""
Custom exceptions for the YONO Retail RAG chatbot pipeline.

This module defines a domain-specific exception hierarchy for all
failure scenarios that can occur during RAG pipeline execution:
embedding, ingestion, retrieval, Elasticsearch operations, and
configuration validation.

All exceptions preserve the original cause via exception chaining
so the full traceback is always available without exposing secrets.
"""

import logging

LOGGER = logging.getLogger("dlh_ai")


# Base


class YonoRagError(Exception):
    """Base exception for all YONO RAG pipeline errors.

    All domain-specific exceptions inherit from this class so callers
    can catch the entire hierarchy with a single ``except YonoRagError``.

    Parameters
    ----------
    message : str
        Human-readable description of the failure.

    Examples
    --------
    >>> raise YonoRagError("Unexpected RAG pipeline failure.")
    """


# Configuration


class RagConfigurationError(YonoRagError):
    """Raised when the RAG pipeline configuration is invalid or incomplete.

    Parameters
    ----------
    message : str
        Description of which configuration field is invalid and why.

    Examples
    --------
    >>> raise RagConfigurationError(
    ...     "elasticsearch.host must not be empty."
    ... )
    """


# Elasticsearch


class ElasticsearchConnectionError(YonoRagError):
    """Raised when the Elasticsearch cluster cannot be reached.

    Parameters
    ----------
    message : str
        Context about the host and port that failed to respond.

    Examples
    --------
    >>> raise ElasticsearchConnectionError(
    ...     "Cannot connect to Elasticsearch at 'https://host:9201'. "
    ...     "Check network connectivity and cluster health."
    ... )
    """


class ElasticsearchIndexError(YonoRagError):
    """Raised when creating, deleting, or querying an Elasticsearch index fails.

    Parameters
    ----------
    message : str
        The index name and operation that failed.

    Examples
    --------
    >>> raise ElasticsearchIndexError(
    ...     "Failed to create index 'yono_retail_knowledge_base': "
    ...     "mapping conflict on field 'combined_text_embedding'."
    ... )
    """

    message : str
        Number of failed documents and reason for failure.

    Examples
    --------

    ... )

    "def ingest_csv_with_embeddings(\n",
    "    client: Elasticsearch,\n",
    "    model,\n",
    "    csv_file_path: str,\n",
    "    index_name: str,\n",
    "    batch_size: int = 100,\n",
    "):\n",
    "    \"\"\"\n",
    "    Read CSV, generate embeddings and bulk ingest\n",
    "    documents into Elasticsearch.\n",
    "\n",
    "    tqdm is used to show ingestion progress.\n",
    "    \"\"\"\n",
    "\n",
    "    logger.info(\n",
    "        \"Reading CSV: %s\",\n",
    "        csv_file_path,\n",
    "    )\n",
    "\n",
    "    df = pd.read_csv(\n",
    "        csv_file_path\n",
    "    )\n",
    "\n",
    "    logger.info(\n",
    "        \"CSV loaded. Total rows: %s\",\n",
    "        len(df),\n",
    "    )\n",
    "\n",
    "    # Validate required columns\n",
    "\n",
    "    required_columns = [\n",
    "        \"Sno\",\n",
    "        \"Category\",\n",
    "        \"Question\",\n",
    "        \"Answer\",\n",
    "        \"Type\",\n",
    "    ]\n",
    "\n",
    "    missing_columns = [\n",
    "        column\n",
    "        for column in required_columns\n",
    "        if column not in df.columns\n",
    "    ]\n",
    "\n",
    "    if missing_columns:\n",
    "\n",
    "        raise ValueError(\n",
    "            f\"Missing CSV columns: \"\n",
    "            f\"{missing_columns}\"\n",
    "        )\n",
    "\n",
    "    # Fill missing values\n",
    "\n",
    "    df[\"Category\"] = (\n",
    "        df[\"Category\"]\n",
    "        .ffill()\n",
    "        .fillna(\"\")\n",
    "    )\n",
    "\n",
    "    df[\"Question\"] = (\n",
    "        df[\"Question\"]\n",
    "        .fillna(\"\")\n",
    "    )\n",
    "\n",
    "    df[\"Answer\"] = (\n",
    "        df[\"Answer\"]\n",
    "        .fillna(\"\")\n",
    "    )\n",
    "\n",
    "    df[\"Type\"] = (\n",
    "        df[\"Type\"]\n",
    "        .fillna(\"\")\n",
    "    )\n",
    "\n",
    "    # Process in batches\n",
    "\n",
    "    total_rows = len(df)\n",
    "\n",
    "    successful = 0\n",
    "    failed = 0\n",
    "\n",
    "    for start in tqdm(\n",
    "        range(\n",
    "            0,\n",
    "            total_rows,\n",
    "            batch_size,\n",
    "        ),\n",
    "        desc=\"Ingesting CSV\",\n",
    "        unit=\"batch\",\n",
    "    ):\n",
    "\n",
    "        batch_df = df.iloc[\n",
    "            start : start + batch_size\n",
    "        ]\n",
    "\n",
    "        # Create combined text\n",
    "\n",
    "        texts = [\n",
    "            create_combined_text(row)\n",
    "            for _, row in batch_df.iterrows()\n",
    "        ]\n",
    "\n",
    "        # Generate embeddings\n",
    "\n",
    "        embeddings = model.encode(\n",
    "            texts,\n",
    "            normalize_embeddings=True,\n",
    "            show_progress_bar=False,\n",
    "        )\n",
    "\n",
    "        # Create Elasticsearch bulk actions\n",
    "\n",
    "        actions = []\n",
    "\n",
    "        for (_, row), embedding, combined_text in zip(\n",
    "            batch_df.iterrows(),\n",
    "            embeddings,\n",
    "            texts,\n",
    "        ):\n",
    "\n",
    "            # Clean category\n",
    "\n",
    "            category = str(\n",
    "                row[\"Category\"]\n",
    "            ).strip()\n",
    "\n",
    "            # Elasticsearch document\n",
    "\n",
    "            doc = {\n",
    "                \"sno\": int(row[\"Sno\"]),\n",
    "                \"category\": category,\n",
    "                \"question\": str(\n",
    "                    row[\"Question\"]\n",
    "                ).strip(),\n",
    "                \"answer\": str(\n",
    "                    row[\"Answer\"]\n",
    "                ).strip(),\n",
    "                \"type\": str(\n",
    "                    row[\"Type\"]\n",
    "                ).strip(),\n",
    "                \"combined_text\": combined_text,\n",
    "                \"combined_text_embedding\": (\n",
    "                    embedding.tolist()\n",
    "                ),\n",
    "            }\n",
    "\n",
    "            actions.append(\n",
    "                {\n",
    "                    \"_index\": index_name,\n",
    "                    \"_source\": doc,\n",
    "                }\n",
    "            )\n",
    "\n",
    "        # Bulk insert\n",
    "\n",
    "        try:\n",
    "\n",
    "            success, errors = helpers.bulk(\n",
    "                client,\n",
    "                actions,\n",
    "                raise_on_error=False,\n",
    "            )\n",
    "\n",
    "            successful += success\n",
    "\n",
    "            if errors:\n",
    "                failed += len(errors)\n",
    "\n",
    "        except Exception as e:\n",
    "\n",
    "            logger.exception(\n",
    "                \"Bulk ingestion failed: %s\",\n",
    "                e,\n",
    "            )\n",
    "\n",
    "            failed += len(actions)\n",
    "\n",
    "    # Final statistics\n",
    "\n",
    "    logger.info(\n",
    "        \"Ingestion completed.\"\n",
    "    )\n",
    "\n",
    "    logger.info(\n",
    "        \"Successfully indexed: %s\",\n",
    "        successful,\n",
    "    )\n",
    "\n",
    "    logger.info(\n",
    "        \"Failed: %s\",\n",
    "        failed,\n",
    "    )\n",
    "\n",
    "    return successful, failed\n"
   ]

    "def vector_search(\n",
    "    client: Elasticsearch,\n",
    "    model,\n",
    "    index_name: str,\n",
    "    query: str,\n",
    "    top_k: int = 5,\n",
    "):\n",
    "    \"\"\"\n",
    "    Perform simple Elasticsearch kNN vector search.\n",
    "    \"\"\"\n",
    "\n",
    "    # Generate query embedding\n",
    "\n",
    "    query_embedding = model.encode(\n",
    "        query,\n",
    "        normalize_embeddings=True,\n",
    "    ).tolist()\n",
    "\n",
    "    # Elasticsearch kNN search\n",
    "\n",
    "    response = client.search(\n",
    "        index=index_name,\n",
    "        knn={\n",
    "            \"field\": \"combined_text_embedding\",\n",
    "            \"query_vector\": query_embedding,\n",
    "            \"k\": top_k,\n",
    "            \"num_candidates\": max(\n",
    "                top_k * 10,\n",
    "                50,\n",
    "            ),\n",
    "        },\n",
    "        source=[\n",
    "            \"sno\",\n",
    "            \"category\",\n",
    "            \"question\",\n",
    "            \"answer\",\n",
    "            \"type\",\n",
    "            \"combined_text\",\n",
    "        ],\n",
    "    )\n",
    "\n",
    "    return response"
   ]

import logging
from datetime import datetime
from zoneinfo import ZoneInfo

import cmlapi
from cmlapi import CMLServiceApi, CreateJobRequest, models

logger = logging.getLogger("dlh_ai")

RUNTIME_IDENTIFIER = [
    "hadoop-cli-7.3.1.200-90",
    # This equals to spark 3.5.1; to change spark version probably create dummy job with
    # respective spark version & then use CML Job api to fetch details
    "spark351-7218800-1240-b711",
]
DEFAULT_TIMEOUT = 60 * 10


class CAIClient:
    """Client for interacting with Cloudera AI (CAI) API.

    Parameters
    ----------
    project_id : str
        The CML project identifier.

    Examples
    --------
    >>> client = CAIClient(project_id="my-project-123")

    >>> job_config = client.job_config_template(
    ...     job_prefix_name="data-processing",
    ...     batch_no=1,
    ...     job_script="src/jobs/process_data.py"
    ... )
    >>> job = client.create_job(job_config)
    >>> job_run = client.create_job_run(job.id)
    """

    project_id: str

    @property
    def client(self) -> CMLServiceApi:
        """Get the CML service API client.

        Returns
        -------
        CMLServiceApi
            The default CML API client instance.

        Examples
        --------
        >>> cai = CAIClient()
        >>> api_client = cai.client
        """
        _ = cmlapi.default_client()
        return _

    def job_config_template(
        self,
        job_prefix_name: str,
        batch_no: int | None,
        job_script: str,
        cpu: int = 2,
        memory: int = 8,
        env: dict | None = None,
        runtime_identifier: str = "nexus.dlhdevuat.sbi.bank.in:9443/clouderadataservices/cloudera/cdsw/ml-runtime-jupyterlab-python3.11-ml:2026.03.03.v1",
    ) -> CreateJobRequest:
        """Create a CML job configuration template.

        Generates a job configuration with specified resources and runtime settings.
        If batch_no is provided, it will be included in the job name along with
        the current timestamp.

        Parameters
        ----------
        job_prefix_name : str
            Prefix for the job name.
        batch_no : int or None
            Batch number to include in job name. If None, only prefix is used.
        job_script : str
            Path to the script file to execute (e.g., "src/jobs/process_data.py").
        cpu : int, optional
            Number of CPU cores to allocate, by default 2.
        memory : int, optional
            Memory in GB to allocate, by default 8.
        env : dict or None, optional
            Environment variables as key-value pairs, by default None.
        runtime_identifier : str, optional
            Docker image identifier for the runtime environment.

        Returns
        -------
        CreateJobRequest
            Configured job request object ready for submission.

        Examples
        --------
        >>> client = CAIClient(project_id="proj-123")
        >>> # Create job config without batch number
        >>> config = client.job_config_template(
        ...     job_prefix_name="etl-pipeline",
        ...     batch_no=None,
        ...     job_script="src/jobs/etl.py",
        ...     cpu=4,
        ...     memory=16
        ... )
        >>>
        >>> # Create job config with batch number
        >>> config = client.job_config_template(
        ...     job_prefix_name="data-processing",
        ...     batch_no=5,
        ...     job_script="src/jobs/process.py",
        ...     env={"ENV": "production", "LOG_LEVEL": "INFO"}
        ... )

        Notes
        -----
        - The job timeout is set to 10 minutes (600 seconds).
        - Jobs are configured to be killed on timeout.
        - Spark runtime addons are automatically included for Spark 3.5.1.
        """
        # If there are batches then only we'll have batch name in job name
        name = (
            f"{job_prefix_name}-batch-{batch_no}-{str(datetime.now(tz=ZoneInfo('Asia/Kolkata')))}"
            if batch_no
            else job_prefix_name
        )

        return cmlapi.CreateJobRequest(
            name=name,
            project_id=self.project_id,
            script=job_script,
            cpu=cpu,
            memory=memory,
            environment=env,
            # NOTE - runtime should match with intended runtime docker image
            runtime_identifier=runtime_identifier,
            runtime_addon_identifiers=RUNTIME_IDENTIFIER,
            timeout=DEFAULT_TIMEOUT,
            kill_on_timeout=True,
        )

    def create_job(self, job_config: CreateJobRequest) -> models.job.Job:
        """Create a new CML job.

        Submits a job configuration to CML and creates the job in the project.

        Parameters
        ----------
        job_config : CreateJobRequest
            Job configuration object created by job_config_template().

        Returns
        -------
        models.job.Job
            The created job object with job ID and metadata.

        Examples
        --------
        >>> client = CAIClient(project_id="proj-123")

        >>> config = client.job_config_template(
        ...     job_prefix_name="ml-training",
        ...     batch_no=1,
        ...     job_script="src/jobs/train_model.py"
        ... )
        >>> job = client.create_job(config)
        >>> print(f"Job created with ID: {job.id}")
        Job created with ID: job-abc-123

        See Also
        --------
        job_config_template : Create job configuration
        create_job_run : Execute a created job
        """
        job = self.client.create_job(job_config, project_id=self.project_id)
        logger.info(f"successfully created job with {job.id}")
        return job

    def create_job_run(self, job_id: str) -> models.job_run.JobRun:
        """Execute a CML job by creating a job run.

        Creates and starts a new run for an existing job.

        Parameters
        ----------
        job_id : str
            The unique identifier of the job to run.

        Returns
        -------
        models.job_run.JobRun
            The created job run object with run ID and status.

        Examples
        --------
        >>> client = CAIClient(project_id="proj-123")
        >>> # First create a job
        >>> config = client.job_config_template(
        ...     job_prefix_name="data-pipeline",
        ...     batch_no=None,
        ...     job_script="src/jobs/pipeline.py"
        ... )
        >>> job = client.create_job(config)
        >>>
        >>> # Then execute the job
        >>> job_run = client.create_job_run(job.id)
        >>> print(f"Job run started with ID: {job_run.id}")
        Job run started with ID: run-xyz-456

        See Also
        --------
        create_job : Create a new job
        _job_run_template : Generate job run configuration
        """
        job_run_config = self._job_run_template(job_id=job_id)
        run = self.client.create_job_run(
            job_run_config, job_id=job_id, project_id=setting.common.project_id
        )
        logger.info(f"successfully created job run {run.id}")
        return run

    def _job_run_template(self, job_id: str):
        """Create a job run configuration template.

        Internal method to generate the configuration for executing a job.

        Parameters
        ----------
        job_id : str
            The unique identifier of the job to run.

        Returns
        -------
        cmlapi.CreateJobRunRequest
            Job run request configuration object.

        Examples
        --------
        >>> client = CAIClient(project_id="proj-123")
        >>> run_config = client._job_run_template(job_id="job-abc-123")
        """
        return cmlapi.CreateJobRunRequest(project_id=self.project_id, job_id=job_id)

    host : str, default="default"
        HDFS host connection string. Use "default" to connect to the default
        filesystem configured in Hadoop settings.


    Examples
    --------

    >>> # Initialize HDFS client with default host
    >>> client = HDFSClient()

    >>> # Initialize with specific host (rarely needed)
    >>> client = HDFSClient(host="hdfs://namenode:8020")

    >>> # List files in a directory
    >>> files = client.list_files("/user/some_folder/data")

    >>> # Upload a file to HDFS
    >>> client.upload("local_file.csv", "/user/data/remote_file.csv")

    >>> # Download a file from HDFS
    >>> client.download("/user/data/remote_file.csv", "local_file.csv")

    >>> # Read parquet data
    >>> dataset = client.read_parquet_table("/user/data/parquet_files")
    """

    host: str = "default"

    def __post_init__(self):
        # configuring env variable
        logger.debug("setting env variable for hdfs client")
        os.environ["CLASSPATH"] = os.popen("hdfs classpath").read().strip()
        # TODO - Below line is for cloudera cluster & needs to be handle in better way
        os.environ["HADOOP_OPTS"] = (
            "-Djavax.net.ssl.trustStore=/var/lib/cloudera-scm-agent/agent-cert/cm-auto-global_truststore.jks -Djavax.net.ssl.trustStorePassword=Sbi@123"
        )

    @property
    def hdfs_filesystem(self) -> fs.HadoopFileSystem:
        """Get PyArrow HadoopFileSystem instance.

        Returns
        -------
        fs.HadoopFileSystem
            Configured HadoopFileSystem instance for HDFS operations.

        Examples
        --------
        >>> client = HDFSClient()
        >>> filesystem = client.hdfs_filesystem
        >>> file_info = filesystem.get_file_info("/user/data")
        """
        config = {
            "ssl.client.truststore.location": "/var/lib/cloudera-scm-agent/agent-cert/cm-auto-global_truststore.jks",
            "ssl.client.truststore.password": "Sbi@123",
            "ssl.client.truststore.type": "jks",
            "hadoop.rpc.socket.factory.class.default": "org.apache.hadoop.net.StandardSocketFactory"
        }
        _ = fs.HadoopFileSystem(host=self.host, extra_conf=config)
        return _

    def list_files(self, path: str) -> list[fs.FileInfo]:
        """List all files in the specified HDFS path recursively.

        Parameters
        ----------
        path : str
            HDFS path to list files from.

        Returns
        -------
        list[fs.FileInfo]
            List of FileInfo objects containing file metadata.

        Examples
        --------
        >>> client = HDFSClient()
        >>> files = client.list_files("/user/data")
        >>> for file in files:
        ...     print(f"{file.path}: {file.size} bytes")
        """
        selector = fs.FileSelector(path, recursive=True)
        files = self.hdfs_filesystem.get_file_info(selector)
        return [file for file in files]

    def upload(self, source_path: str, destination_path: str, overwrite: bool = True):
        """Upload a file from local filesystem to HDFS.

        Parameters
        ----------
        source_path : str
            Local file path to upload.
        destination_path : str
            HDFS destination path.
        overwrite : bool, optional
            Overwrite existing file if it exists. Default is True.

        Examples
        --------
        >>> client = HDFSClient()
        >>> client.upload("local_data.csv", "/user/data/remote_data.csv")
        >>>
        >>> # Upload without force overwrite
        >>> client.upload("model.pkl", "/user/models/model.pkl", overwrite=False)

        Notes
        -----
        Uses HDFS CLI command with -f flag to force overwrite if file exists.
        PyArrow filesystem is not used due to authentication issues.
        """
        # TODO - Ideally pyarrow.fs should be used but currently there is
        # a issue with auth & only hdfs cli is working
        if overwrite:
            subprocess.run(["hdfs", "dfs", "-put", "-f", source_path, destination_path])
        else:
            subprocess.run(["hdfs", "dfs", "-put", source_path, destination_path])

    def download(self, source_path: str, destination_path: str):
        """Download a file from HDFS to local filesystem.

        Parameters
        ----------
        source_path : str
            HDFS file path to download.
        destination_path : str
            Local destination path.

        Examples
        --------
        >>> client = HDFSClient()
        >>> client.download("/user/data/remote_data.csv", "local_data.csv")
        >>>
        >>> # Download to specific directory
        >>> client.download("/user/models/model.pkl", "./models/model.pkl")

        Notes
        -----
        Uses HDFS CLI command for downloading.
        PyArrow filesystem is not used due to authentication issues.
        """
        # TODO - Ideally pyarrow.fs should be used but currently there is
        # a issue with auth & only hdfs cli is working
        subprocess.run(["hdfs", "dfs", "-get", source_path, destination_path])

    def read_parquet_table(self, source_path: str) -> ds.FileSystemDataset:
        """Read parquet files from HDFS as a PyArrow dataset.

        Parameters
        ----------
        source_path : str
            HDFS path to parquet file or directory containing parquet files.

        Returns
        -------
        ds.FileSystemDataset
            PyArrow FileSystemDataset for the parquet data.

        Examples
        --------
        >>> client = HDFSClient()
        >>> dataset = client.read_parquet_table("/user/data/parquet_files")
        >>>
        >>> # Convert to pandas DataFrame
        >>> df = dataset.to_table().to_pandas()
        >>>
        >>> # Read with filters
        >>> table = dataset.to_table(filter=ds.field("year") == 2024)
        >>> df = table.to_pandas()
        """
        return ds.dataset(
            source=source_path, filesystem=self.hdfs_filesystem, format="parquet"
        )

    def read_csv_file(self, source_path: str) -> ds.FileSystemDataset:
        """Read CSV files from HDFS as a PyArrow dataset.

        Parameters
        ----------
        source_path : str
            HDFS path to CSV file or directory containing CSV files.

        Returns
        -------
        ds.FileSystemDataset
            PyArrow FileSystemDataset for the CSV data.

        Examples
        --------
        >>> client = HDFSClient()
        >>> dataset = client.read_csv_file("/user/data/csv_files")
        """
        return ds.dataset(
            source=source_path, filesystem=self.hdfs_filesystem, format="csv"
        )

    def load_model_sentence_transformer(self, model_path: str, **kwargs):
        """Load a SentenceTransformer model from HDFS.

        Downloads the model from HDFS to a temporary directory and loads it
        using the sentence-transformers library.

        Parameters
        ----------
        model_path : str
            HDFS path to the SentenceTransformer model directory.
        **kwargs : dict
            Additional keyword arguments to pass to SentenceTransformer constructor.

        Returns
        -------
        SentenceTransformer
            Loaded SentenceTransformer model instance.

        Raises
        ------
        ImportError
            If sentence-transformers library is not installed.
        ValueError
            If model requires trust_remote_code=True (automatically handled).

        Examples
        --------
        >>> client = HDFSClient()
        >>> model = client.load_model_sentence_transformer(
        ...     "/dev/aiml/models/google/embeddinggemma4"
        ... )
        >>> embeddings = model.encode(["Hello world", "How are you?"])

        >>> # Load with onnx device backend
        >>> model = client.load_model_sentence_transformer(
        ...     "/dev/aiml/models/google/embeddinggemma4",
        ...     backend="onnx"
        ... )

        Notes
        -----
        The model is downloaded to a temporary directory which is automatically
        cleaned up after loading. If the model requires trust_remote_code=True,
        it will be automatically enabled with a warning.
        """
        try:
            from sentence_transformers import SentenceTransformer
        except ImportError:
            raise ImportError(
                "`sentence-transformers` library is not installed, please install it"
            )

        with tempfile.TemporaryDirectory() as temp_dir:
            local_model_path = f"{temp_dir}/model_dir"
            logger.debug("downloading the model from hdfs")
            self.download(model_path, local_model_path)
            logger.debug(
                f"successfully downloaded model temporarily to: {local_model_path}"
            )
            try:
                logger.info(f"loading model from {local_model_path}")
                model = SentenceTransformer(local_model_path, **kwargs)
            except ValueError as e:
                if "trust_remote_code=True" in str(e):
                    logger.warning(
                        "the model need to trust & execute custom code, enabling it"
                    )
                    model = SentenceTransformer(
                        local_model_path, trust_remote_code=True, **kwargs
                    )
                else:
                    raise e

        return model
